# TLT — iShares 20+ Year Treasury Bond ETF｜基本面分析
**分析基準日：2026-05-16**

---

## 1. ETF 概覽

| 項目 | 內容 |
|------|------|
| 發行商 | BlackRock（iShares） |
| 類型 | 長期美國國債 ETF（20 年以上到期） |
| 追蹤標的 | ICE U.S. Treasury 20+ Year Bond Index |
| Expense Ratio | 0.15%／年（低費率） |
| AUM | ~$42.9B |
| 主要持倉 | 美國財政部發行 20–30 年期國債 |
| 存續期間（Duration） | ~17 年（高利率敏感度） |
| 交易所 | Nasdaq |

TLT 持有到期日超過 20 年的美國政府公債，是最廣泛使用的長債利率方向性工具。由於存續期間約 17 年，每當殖利率上升 100bps，TLT 價格約下跌 17%（反之亦然）。這使得 TLT 在升息環境中成為**最高風險的固定收益工具之一**。

## 3. 殖利率環境分析

TLT 的基本面核心是**30 年期美債殖利率走向**。

當前殖利率環境：
- 殖利率因通膨（3.5% YoY）+ Fed 緊縮預期（Warsh 接任）而上升
- TLT 價格走勢：**低於所有移動平均線（MA20/MA50/MA200）**，殖利率長期高企確認
- 若 30 年期殖利率站上 5.0–5.5%，TLT 可能進一步下跌至 $75–$78

**殖利率 vs TLT 價格的估算**：
| 30Y 殖利率情境 | TLT 估算價格 |
|--------------|------------|
| 4.5% | ~$88–$90 |
| 4.8%（當前估算） | ~$83–$85 |
| 5.2% | ~$77–$80 |
| 5.5%（壓力情境） | ~$73–$76 |

## 4. 配息分析

TLT 每月配息，當前年化殖利率約 3.5–4.0%（視殖利率水準而定）。在絕對收益面，此配息水準相對於其 -6% 的 5 年年化價格損失，**收益無法彌補資本虧損**。

## 6. 關鍵風險

1. **升息風險（最大風險）**：Warsh 接任可能代表更激進緊縮，30 年殖利率繼續上行
2. **通膨結構性高企**：油價 $100+，PCE 能源 +11.56% MoM，通膨預期難以快速降溫
3. **「大遷徙」敘事（Great Migration）**：部分策略師認為 60-40 組合失效，資金從長債流出
4. **財政赤字風險**：美國聯邦赤字持續高企，國債供給增加，壓低債券價格
5. **流動性風險**：極端環境下（如 2020 年 3 月）TLT 可能出現大幅折價
6. **機會成本**：短期美債殖利率（3–6 個月）目前提供類似或更高殖利率，且無利率風險
