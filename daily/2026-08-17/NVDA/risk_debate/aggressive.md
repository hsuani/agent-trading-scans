# 積極風險觀點 — NVDA

## 交易員過度保守之處
- trade_proposal 選擇「新資金 AVOID、完全不新開倉」，但 investment_plan 自己列出的訊號並非中性：三項 Phase-1 訊號（基本面、新聞、情緒）PASS，唯一缺的是技術面資料，而技術面缺失是**資料源問題**，不是空頭訊號本身。把「資料真空」直接等同於「零曝險」，是把資訊缺口的風險錯誤地放大成方向性風險。
- investment_plan 的 position-sizing guidance 其實已經留了口子：「若選擇財報前建倉，應以最低倉位（quarter size 以下）」——但 trade_proposal 最終選擇完全不用這個口子，直接降級為 HOLD/AVOID，等於把研究部門自己給出的彈性空間主動放棄。
- 財報前的不確定性正是 alpha 所在：CoreWeave backlog $104.2B、SMCI 大幅上修指引都是近兩週內的新鮮訊號，且 BofA 預期 $107-108B vs 共識 $91-95B 有明顯落差。等財報公布後才進場，等於放棄在資訊尚未完全反映到共識前的進場機會——這正是「等待抹殺 alpha」的典型案例。

## 建議調整
- Size：不新開倉 → 財報前以 quarter size（研究部門自己認可的上限）建立起始部位，而非完全零曝險。
- Stop：無實際止損可設（技術面資料缺失屬實），但可用**部位規模本身**作為風控替代——quarter size 意味著即使財報結果落入 bear 情境（指引僅符合共識、估值壓縮至 20x Forward P/E），組合層級的最大回撤也僅是該倉位的一部分，非全倉曝險。
- Entry：現在（財報前）分批建立 quarter size，而非等 8/26 財報結果與技術面資料同時恢復後才行動——兩個條件都要滿足才進場，等於把進場窗口壓縮到財報後的擁擠交易時段，屆時利多已部分price in。
- 可考慮：財報前用 8/26 到期附近的 call spread（例如平值偏上履約價 vs 更高履約價），把最大損失鎖定在權利金，同時保留指引突破 $100B 情境下的上檔參與度，避免技術面止損缺失導致的裸倉曝險問題。

## 不對稱性論證
若以 quarter size 建倉：下檔情境（指引僅符合共識、倍數壓縮至 20x）造成的組合曝險為「一個 quarter size 部位的估值倍數修正幅度」；上檔情境（指引破 $100B，conviction 上修至 HIGH）則對應完整倉位（full size）的重估空間，且投資組合的可交易上檔一般大於下檔壓縮幅度（bull 與 bear 情境相差逾 40 個百分點）。用選擇權變體（call spread）則可將最大損失鎖定為權利金，進一步壓縮下檔曝險，同時保留同等上檔參與。

## 我會爭取的調整
在技術面資料真空、無法設定實體止損的前提下，完全零曝險是矯枉過正——research_manager 自己都認可 quarter size 以下的財報前建倉是合理選項，交易員應把這個彈性用起來，而非默認退回 HOLD。我會主張以 quarter size 現金部位分批進場，並搭配 8/26 到期附近的 call spread 作為槓桿變體，把下檔鎖定在權利金與部位規模之內，同時不放棄 CoreWeave/SMCI 這類已經在市場上發酵、財報前就可能推動股價的新鮮催化劑。
