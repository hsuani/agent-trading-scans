# 基本面分析 — 2301.TW（光寶科技）2026年8月18日

## 執行摘要

光寶科技2025年營收創三年來最高，達166.1億元，年成長21.1%，驅動因素為數據中心電源、EV充電及光電子產品需求回升。淨利率10.5%、ROE 21.9%，表現穩健。然而，2026年Q1出現營運現金流轉負、存貨大幅上升至43.9億元，且Q1 EPS 較預估低40.8%，顯示成長動能轉弱。目前本益比38.98倍偏高，但淨現金position強勁（56.6億元），股利發放穩定。公司處於成長調整期，需觀察後續季度能否恢復現金流健康度。

### 業務動能觀察點
1. **數據中心週期**：Meta、Google、Microsoft等CSP持續投資，預期2026年數據中心電源需求維持高檔；公司電源系統毛利率已從21%升至24%，供不應求情形若緩解，利率恐承壓。
2. **EV充電滲透率**：全球EV銷售趨緩，EV充電設備需求增速放緩；2301.TW在AC充電領域份額高，但需求能見度下降。
3. **光電子產品**：LED、光耦合器應用於汽車（ADAS）及工業物聯網，市場競爭激烈，價格下行壓力存在。
4. **庫存調整**：Q1存貨飆升至43.9億元，若無法在Q2-Q3快速出貨，恐拖累現金流與利潤率。

## 紅旗清單

1. **現金流惡化**：Q1 2026營運現金流與自由現金流轉負，FCF/淨利比僅0.5，遠低於健康水位；需觀察是否為季節性或結構性問題。

2. **季度利潤波動**：
   - Q1 2026淨利率8.7%，較全年10.5%下滑
   - EPS驚喜度高度不穩定（Q1 -40.83%、Q2 +47.71%），顯示獲利預測難度大

3. **存貨囤積**：Q1存貨43.9億元創新高，季末應為清庫期反而上升，暗示：
   - 下游需求預期轉弱
   - 供應鏈主動囤貨（備貨對沖風險）
   - 產品組合偏向低週轉率品項

4. **資本支出激增**：2025年資本支出69.5億元較2024年翻倍，Q1續投26.9億元；若營收成長無法配合，ROI可能下滑。

5. **追蹤本益比高檔**：38.98倍本益比對應2025年基期，留給2026年成長空間有限；需要年增15%以上才能兌現估值。

6. **利率環境敏感**：高利息支出2025年年增至14.3億元（較2024年10.5億元升36%），未來若升息持續，財務成本恐進一步拖累淨利。

7. **機構集中度高**：46.76%機構投資者浮動股持有比，單一機構減持恐引發股價波動。

## 結論

**財務健康度：中等**

光寶科技2025年營運表現亮眼，營收與利潤雙位數成長，淨現金position充足，股利政策穩定，顯示基本面扎實。惟2026年初季顯著轉弱——現金流轉負、存貨異常囤積、EPS大幅低於預估——暗示成長動能減速或為季節性擾動仍需確認。

**估值吸引度：中等**

前瞻本益比18.76倍屬合理區間，但追蹤本益比38.98倍反映高基期，給予2026年盈利成長有限空間。PEG 0.86倍具相對價值，惟建立在8-10%增速預期之上，而近季表現難以確保此預期。

**投資適宜性：需待改善信號**

建議下一階段關注：
1. Q2季報確認Q1是否為淡季異常或成長動能轉變
2. 庫存是否在Q2-Q3迅速消化
3. 管理層對2026全年盈利與現金流的指引調整
4. 數據中心客戶需求能見度能否延續
