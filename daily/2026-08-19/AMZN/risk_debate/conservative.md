# Conservative risk view — AMZN

## Where trader is too aggressive

- **止損過寬，掩蓋跳空致命缺口**：止損 $210 距入場中點 $234 達 -10.3%（每股 $24 風險）。1.5% NAV 倉位觸及止損之帳面損失約 0.154% NAV，數字上看似保守。但 FTC 廣告剝離裁定、AWS 季度大幅遜色等事件均可造成隔夜跳空 -20% 至 -40%，直接穿越 $210，止損形同虛設。真實尾部損失遠超止損所承諾的數字。

- **PRICE_DATA_UNAVAILABLE 令所有錨點失效**：$234「現價」與 $210 止損均為分析師目標反推估算，非實際市場報價。若真實成交價落在入場區間上端 $240，止損距離擴至 $30（-12.5%）；且無 ATR、無技術支撐確認，無從判斷 $210 是否為真實有效的市場結構位。在此執行環境下，1.5% NAV 是過度積極的配置。

- **92% 分析師 BUY = 擁擠交易，邊際買家耗盡**：僅剩 8% 非買入評級，樂觀情境已高度計入。一旦 AWS 出現任何執行偏差，集體目標下修動能將系統性放大跌幅，缺乏對沖機制。

- **內部人士財報高峰後大量出脫**：高層在 Q2 創歷史新高後 7–8 月集中賣出 $346.97M，12 個月零買入。這是知情人在最有利時機進行分配，與多頭敘事形成顯著背離。

## Tail scenarios

- **Scenario A（概率 20%）**：AWS Q3 成長降至 25% 以下（基期走高 + Google Cloud 搶佔份額）→ 股價跌至 $150，較入場中點損失 -35.9%。1.5% NAV 倉位損失 ~0.54% NAV（止損因跳空無法執行）。

- **Scenario B（概率 10%）**：FTC 2027-02-09 庭審出現廣告業務強制剝離中期裁定 → 股價跌至 $88 極端熊市情境，1.5% NAV 損失高達 ~0.93% NAV，且大概率以跳空方式體現，止損無從捕捉。

- **Scenario C（概率 15%）**：CapEx 再上調至 $240B+，FCF 轉負，市場重訂 FCF 折現模型 → 股價跌至 $185，NAV 損失 ~0.32%。

- **Scenario D（概率 20%）**：Fed 9–10 月傳遞鷹派信號（通膨反彈），成長股估值壓縮 10–15%，AMZN 跌至 $200 → NAV 損失 ~0.22%。

## Recommended adjustments

- **Size**：1.5% NAV → **0.75% NAV（Small）**。理由：PRICE_DATA_UNAVAILABLE 使執行基礎薄弱；內部人士淨賣出 $346.97M 且零買入；跳空風險使止損失效；應保留加倉空間留待 Q3 財報驗證後動用。

- **Stop**：$210 → **$220**（距入場中點 -6.0%，略低於分析師目標低端 $230 的緩衝區，同時縮小跳空損失窗口）。

- **Entry**：嚴格以 **2026-08-30 前期業績預告**作為唯一建倉觸發點——AWS 指引 ≥35% 方可建倉 0.75% NAV；指引 30–35% 降至 0.5% NAV 試水；低於 30% 或 CapEx 再上調，取消建倉。在此之前，禁止建立任何倉位。

- **Consider**：配置 AMZN 價外 PUT（行使價 $200，到期 2027-03，涵蓋 FTC 庭審視窗）對沖廣告剝離尾部風險；成本可用倉位縮減節省出的風險預算承擔。

## Position-level $ risk

以 0.75% NAV、入場中點 $234、止損 $220 計算（以 NAV = $1,000,000 為例）：

| 情境 | 計算 | NAV 損失 |
|---|---|---|
| 正常止損觸發（$220） | $14 × 32 股 = $448 | **0.045% NAV** |
| AWS 跳空至 $150（Scenario A） | $84 × 32 股 = $2,688 | **0.269% NAV** |
| FTC 跳空至 $88（Scenario B） | $146 × 32 股 = $4,672 | **0.467% NAV** |

在縮倉後，Scenario A 與 B 的損失均為原計畫的一半，尾部損失可控性顯著改善。可接受性：在 PRICE_DATA_UNAVAILABLE 環境下，任何止損均應視為「方向性參考」而非精確執行保障；尾部風險需通過倉位控制而非止損精度管理。

## What I'd push for

此交易論文方向合理，但三大執行缺陷使 1.5% NAV 配置過於積極：一、所有價位均為估算，無真實技術錨點；二、內部人士在財報高峰後以 $346.97M 集中分配，是有意義的反向信號；三、92% 分析師 BUY 代表擁擠交易，邊際下修風險遠大於上修空間。我的明確要求是：倉位從 1.5% NAV 削減至 **0.75% NAV**，止損從 $210 收緊至 **$220**，並嚴格以 2026-08-30 前期業績預告的 AWS 指引作為唯一建倉觸發條件——任何提前建倉均屬違反風控紀律。同步配置小規模 AMZN PUT 以對沖 FTC 廣告剝離的 Scenario B 尾部；Q3 財報驗證 AWS 成長持穩且 FCF 軌跡改善後，方考慮加倉至原計畫的 1.5% NAV。
