# 基本面報告 — CBRS（2026年5月25日）

## 執行摘要

Cerebras Systems 於2026年5月14日剛上市，推出 Wafer-Scale Engine (WSE) 晶片，在生成式AI計算基礎設施市場中定位獨特。然而公司處於極早期階段，2025年虧損-$1.46億營業淨收入、自由現金流淨流出-$3.93億、債務/權益比達19.5x，淨權益為負$5.79億。上市融資$11億優先股和股票發行撐起現金部位至$7.02億，但高燒錢速度和客戶集中風險（G42等）令估值異常拉高：P/E 626倍、EV/EBITDA -136倍、P/FCF 負值。訂單信號強勁（2025年營收+75% YoY），但獲利路徑模糊。

## 營收與獲利性

**營收軌跡與成長**

- 2022：$24.6M → 2023：$78.7M (+220%YoY) → 2024：$290.3M (+268%YoY) → 2025：$510.0M (+75%YoY)
- 三年CAGR（2022-2025）：**+179%**，高度成長，但基數小
- 最新12個月營收$510.0M，成長減速至75% YoY（前年268%），暗示市場早期階段、訂單集中化

**毛利與營業虧損**

- 毛利率：2025年39.0%（$199M毛利），相對健康，表示產品售價遠高於邊際成本
- 毛利率趨勢：2022年11.7% → 2023年33.5% → 2024年42.3% → 2025年39.0%
- 營業利益（EBIT）：-$1.453億（營業虧損-28.5%營運利率）
- 營業虧損主因：R&D支出$243.3M（+53% YoY）、銷售與市場$60.7M（+395% YoY 爆升）、一般管理$40.9M
- 營運支出$344.3M（+53% YoY），成長快於營收增速，反映IPO後激進擴張

**淨利與特殊項目**

- 淨利：$237.8M（正數）
- 關鍵：「其他收入-支出」$363.3M 收益來自**投資證券收益**，與營運無直接關係
- 若扣除投資收益，營運淨損約-$125M；此為私募融資輪次（G42、OpenAI投資者）的持股解禁或倍數增值體現
- 正淨利掩蓋核心業務虧損本質

**淨利潤率：**46.6%（由特殊項目主導，不可持續）

## 現金流與資產負債表

**自由現金流危機**

- FCF 2025：-$392.8M（燒錢）vs 營收$510M，FCF/NI = -165% （高度不健康）
- 2024年FCF +$428.5M（受益於客戶預付與延遲庫存削減），2023年FCF -$85.6M
- 營運現金流（OCF）：-$10.1M，主要被營運損失與工作資本變動抵銷
- 資本支出（CapEx）：-$382.7M（激進基礎設施建投），佔營收75%，堆積晶圓廠資產與製造設備
  - 對照：2024年CapEx -$23.4M，2025年8x爆升，反映上市融資流向製造擴產

**資產與負債惡化**

- 總資產：$232.6B → $111.3B（2024年），但淨PPE激增至$686M（2025年），遠高於2024年$79.7M
  - 淨PPE漲幅反映資本密集型晶圓廠投資（營造與機械$302.8M、在建工程$163.5M）
- 總負債：$290.5M（已編制資本租賃負債佔大部份）
- **淨權益：-$5.787B（負值）**，2024年-$9.668B，IPO融資縮小虧損但仍為負
- 工作資本：$824.1M（2025年），2024年負$147.7M，反轉源於IPO現金
- 流動比率：2.145（良好短期流動性），速動比率：1.643（健康）

**現金與債務**

- 現金及短期投資：$1.108B
  - 現金$701.7M（核心營運現金，高於2024年$220.2M）
  - 短期投資$406.5M（國庫券或高評級債券）
- 受限現金：$228.7M（客戶保證金或融資契約限制）
- 總債務：$261.8M （資本租賃，含$215.9M長期+$45.9M短期）
- **淨債務 = 債務-現金 = $261.8M - $1.108B = -$846M**（淨現金部位）

**債務與權益比率**

- 債務/權益：19.498x（負權益下此指標無意義，但凸顯高槓桿體質：債務固定，權益為負）
- 債務/EBITDA：不適用（EBITDA -$110.8M）
- 資本租賃激增：2024年$40.7M → 2025年$261.8M，反映融資設備購置

## 資本配置與內部人信號

**資本配置優先順序**

1. **CapEx：** -$382.7M（總融資的35%投入重資產）
   - 晶圓廠建置與生產線擴充（格局上與台積電、三星製造夥伴合作，WSE晶片代工）
   - 供應鏈庫存堆積：2025年庫存$63.6M vs 2024年$174.5M，輕微改善但仍高於成本基數

2. **股票回購：** -$38.1M（2025年優先股償付$16.7M，普通股回購-$21.4M）
   - 微弱回購信號，優先級低於現金燃燒

3. **融資：** $1.1B優先股發行（2025年IPO新融資）
   - 2024年優先股融資$85M（pre-IPO輪次，如G42/OpenAI參投）

4. **派息：** $0（無派息，現金優先用於營運虧損補償）

**內部人交易（近6個月）**

- 內部人：**Steven Vassallo**（董事）
  - 交易日期：2026年5月15日（IPO 次日）
  - 交易：衍生證券轉換行使，價格$279.72/股
  - 股份數：12.59M股，價值$3.521B
  - 性質：期權/認股權行使（IPO鎖定期釋放信號），非減持

**內部人信號評價：** 
- Vassallo行使選擇權以$279.72鎖定成本，顯示對公司長期信心
- CEO Feldman（未編制行使）持股184.7M選擇權（$937.5k薪資基礎），高度aligned
- 無減持信號（IPO後常見的創辦人套現），暗示內部人看好需求前景

## 估值

**絕對估值倍數**

- 當前股價：$256.78（截至2026年5月25日）
- 市值：$564億美元（$563.9B）
  - 淨IPO融資：$1.1B（優先股+普通股），融資估值約$350-400B（根據IPO定價）
  - 當前估值較IPO上漲，反映市場熱情 YTD +35% from IPO （IPO後11天）

- **P/E = 626倍**（基於2025年淨收入$87.9M，含投資收益）
  - 調整後P/E（扣除投資收益）= 負值（營運虧損）
  - 不可持續的估值倍數，反映投機性質

- **EV/EBITDA = -136倍**（EBITDA -$110.8M，負數）
  - 無意義指標，但視覺化負EBITDA的深度

- **EV/Revenue = 29.8倍**
  - 企業價值$151.8B（市值$563.9B - 淨現金$846M）
  - 行業對標：高端AI加速器製造商
    - NVDA (GPU)：EV/R ~ 17-20倍（獲利2025 P/E 75倍）
    - ASML (光刻機)：EV/R ~ 12-15倍（2024 P/E ~60倍）
  - CBRS 高 47-170% 相對NVDA/ASML，反映極高成長與稀有性溢價

- **P/FCF：** 負值（FCF -$392.8M）
  - 市場完全忽視現金燒速，押注未來轉正

- **P/B = -25.3倍**（負權益下無意義）

**前瞻估值假設**

- 若2026年營收$750-900M（+50-75%YoY），EBITDA margin達-5% to +5%
  - 調整後EV/EBITDA 仍為50-∞倍，溢價存續（假設獲利端改善慢）
  - 若2027年達20% EBITDA margin，當前估值對應P/EV ~25倍，為高科技新創正常範圍

**估值風險**

- 倍數異常拉高，市場定價已納入樂觀增長假設
- 任何CapEx 延遲或客戶延期將觸發估值回調

## 主要催化劑

**近期亮點**

1. **2025年財報發佈**（預計2026年5月底前發佈10-K）
   - 下一個市場焦點：2026年Q1 guidance 與客戶簽署合約數量公開
   - 預期集中在大客戶（G42、OpenAI）續約率與新客戶開拓

2. **OpenAI x Cerebras 合作夥伴關係**
   - 已公開簽署協議，部署WSE於數據中心推理工作負載
   - 後續催化：成本降低數據公開、性能基準刷新、合同擴展

3. **G42（阿聯酋主權AI基金）客戶集中風險**
   - G42為主要客戶，估計佔2025年營收30-40%（未官方確認）
   - 催化：任何G42 訂單削減或地緣政治風險升高將直接衝擊
   - 管制風險：美國對阿聯酋晶片出口管制變化

4. **製造/CapEx 進展**
   - $382.7M CapEx於2025年投入（年率），預期2026年續投$200-300M
   - 催化：晶圓廠容量利用率達成（目標50%+）、代工伙伴（如TSMC合作深化）宣佈

5. **競爭格局**
   - NVIDIA H100/H200持續優化降成本
   - Custom AI chip 新進者（AMD MI-series、Google TPU、Intel Gaudi）
   - WSE 獨特的全晶圓統一架構短期內難複製，但長期面臨客製化晶片競爭

**獲利轉折點**

- 當營收達$800M+、CapEx 穩定於$250M 年率水準時，營運虧損縮小
- 預期2026-2027年為虧損轉損益關鍵期（不確定性高）

## 紅旗與風險

1. **現金燒速加速**
   - 2025年FCF -$392.8M，年化燒速為營收77%
   - CapEx 在營收中佔比75%，年率$300M+ 的投資下，無新融資情況下現金耗盡時間線為24-30個月
   - 風險：若2026年營收未達$700M+ 或CapEx 控制不力，將需再融資或削減CapEx

2. **客戶集中化風險**
   - G42 估計為單一最大客戶（基於公開評論與上市路演），客戶集中度>30%
   - 地緣政治敏感：美國制裁風險或客戶減退直接衝擊營收20-40%

3. **淨權益為負$5.79B**
   - 異常的財務槓桿體質（無形資產與研發支出難以資本化致權益侵蝕）
   - IPO融資部分補償但未根治；若營運虧損持續，權益惡化風險存在

4. **CapEx 有效性未驗證**
   - $382.7M 投入晶圓廠與生產設備，但產能利用率、良率、成本競爭力均未公開披露
   - 若晶圓廠延誤或良率低於預期，CapEx 成為沉沒成本

5. **高估值下的回調風險**
   - P/E 626倍、EV/R 29.8倍 完全依賴市場對AI晶片需求樂觀預期
   - 任何營收增速放緩（如2025年75% YoY 進一步回落）或CapEx 效率不彰，將觸發估值重新定價（下行30-50%）

6. **技術路線競爭**
   - WSE 全晶圓架構獨特但難擴展至邏輯運算密集應用
   - NVIDIA 與高通等大廠的客製化晶片逐漸優化，長期蠶食市場份額

7. **IPO 後融資與攤薄風險**
   - 當前股本：215.2M 普通股（已發行）+ 4.0B隱含流動股份（未稀釋），顯示期權池龐大
   - 股份發行軌跡：2023年207.5M → 2024年207.5M → 2025年215.2M（稍微增加），未來若需融資將面臨攤薄

## 結論

Cerebras 以其創新的 Wafer-Scale Engine 晶片在AI基礎設施市場中佔據獨特位置，2025年營收增長75%、毛利率39%，顯示產品市場適配與定價權。然而，公司處於極早期商業化階段，營運虧損-$1.46億、FCF 燒錢-$3.93億、淨權益為負，其驚人的高估值（P/E 626倍、EV/R 29.8倍）完全源於市場對AI基礎設施需求的樂觀押注。

IPO 融資$11億提供充足的現金跑道（淨現金$846M），足以支持18-24個月的CapEx 擴張與運營虧損，但若營收成長未達70%+YoY 或CapEx 效率不彰，現金危機將於2027-2028年浮現。客戶集中化風險（G42）、製造規模經濟未驗證、競爭加劇等因素皆為重大不確定性。

財務健康評級：**C+**（虧損、燒錢、高槓桿、負權益）
估值吸引力：**D+**（歷史高倍數，市場定價已納入樂觀預期，下行風險大）
