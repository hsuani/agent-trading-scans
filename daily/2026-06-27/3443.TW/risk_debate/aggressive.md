# Aggressive risk view — 3443.TW (創意電子 / Global Unichip Corp)

## Where trader is too cautious

**1. 等待回調是在拱手讓出動能 alpha**
現價估計 NT$4,600–4,800，交易員要求回落至 NT$4,400–4,550 才入場——距離現價約 5–9% 的下行。問題是：Q1 EPS 超預估 44%、5 月月營收 YoY +132%、6–12 個月訂單能見度已確認、MediaTek 合作消息剛剛發酵——這種基本面密度的標的在觸媒密集期往往不給回調。等待 NT$4,400 入場，極有可能等到的是 Q2 財報（7–8 月）業績再超預期，股價已在 NT$5,500+ 起跳，完全踏空本輪最肥厚的收益段。ASIC 超級週期「初段」的特徵就是動能股不等人。

**2. 1.5% NAV 在信心分配上被嚴重低估**
交易計畫給多方信心 8/10、空方 6/10，但倉位規模設定 Medium (1.5% NAV)，等同於把一個接近 High-conviction 的設定用 Medium 的子彈去打。若對業績周期、產業結構、競爭護城河的判斷是對的，1.5% 的上行貢獻對組合淨值影響微乎其微——T2 (NT$6,200) 達到時，僅貢獻組合 +5.6%（以 NT$4,450 進場計算 R:R 3.8×）。這個數字對應如此強烈的結構性論點，是不成比例的謹慎。

**3. Stop NT$3,900 有被洗倉的結構性風險**
Stop 距 mid-entry NT$4,550 達 14.3%（NT$650）。台股 AI ASIC 族群估計日均 ATR 80–120 元（1.7–2.6%），14% 的停損空間看似寬鬆，但若以現價 NT$4,700 進場，Stop 距離縮至 17%——在一個高波動標的，這個位置反而容易被情緒性賣壓觸及後快速反彈，造成被洗出局後再追更高的雙重損失。

## Recommended adjustments

- **Size：Medium 1.5% NAV → Large 3.0% NAV**（理由：多方信心 8/10 + ASIC 超級週期早段 + 六大催化劑落點清晰，應由子彈大小反映真實信念強度。絕對損失上限：若以 NT$4,700 進場、Stop NT$3,900，最大損失 = NT$800 / NT$4,700 = 17%，對 3% NAV 倉位造成 -0.51% NAV 衝擊，可承受）
- **Stop：NT$3,900 → NT$3,700**（給予波動空間，避免在 NT$3,900 被 intraday 洗盤；NT$3,700 對應 P/E ~77×，此水準才是基本面論點真正崩解的邊界）
- **Entry：等待回調 → 現價分批立即入場**（以估計現價 NT$4,700 起建 1.5% NAV，不等 NT$4,400–4,550；剩餘 1.5% NAV 保留於 Q2 財報驗證後）
- **Consider（選擇權增強）：買入 call spread，行使價 NT$5,000 / NT$6,000，到期 2026 年 9 月**（以有限權利金捕捉 Q2 財報驚喜 + 雲商 H2 CapEx 指引雙催化劑，最大虧損為權利金，向上槓桿倍數顯著）

## Asymmetry argument

| 情境 | 倉位 3% NAV，NT$4,700 進場 |
|------|--------------------------|
| Worst case（Stop NT$3,700 觸發） | 損失 NT$1,000 / NT$4,700 = -21.3%，組合 NAV -0.64% |
| Base case T1（NT$5,500） | 獲利 NT$800 / NT$4,700 = +17%，組合 NAV +0.51% |
| Bull case T2（NT$6,200） | 獲利 NT$1,500 / NT$4,700 = +31.9%，組合 NAV +0.96% |

**R:R（T2 基準）：+NT$1,500 ÷ -NT$1,000 = 1.5×**（以現價計算，仍為正期望值；若等到 NT$4,400 進場 R:R 升至 2.6×，但入場概率大幅下降）

現實加權後的 EV：Bull 論點事件概率約 60%（信心 8/10 折讓後），損失概率 20%——**期望值為正，且 worst-case 絕對損失僅 -0.64% NAV，可接受。**
