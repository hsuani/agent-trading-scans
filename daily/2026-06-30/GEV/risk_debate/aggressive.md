# Aggressive risk view — GEV

## Where trader is too cautious

- **倉位低估非對稱性**：交易員以 ATR 高波動為由將倉位壓至 Medium（1.5% NAV），初始切入僅 0.75% NAV。但高 ATR 本身是刀刃兩面——波動大，代表當趨勢確立後的 Alpha 捕捉窗口也更寬。1,502 億美元積壓訂單、book-to-bill 2.0 倍、FERC 結構性利多同時存在的個股，現在用 0.75% 半倉進場，實際上是用養老金思維對待一個火箭燃料主題。
- **進場條件過於縛手縛腳**：計畫要求等待 MA50 $1,106.75 放量突破才補滿倉位。現價 $1,087 距 MA50 不過 $19.75（不足 2%）。若明日量能推升至 $1,107 才入場，相對於現在進場，額外付出的成本已接近半個 ATR。等待最終確認，等同將 Alpha 拱手讓給早進者。
- **止損過緊，必遭洗盤**：$1,038 止損距 Entry 中點 $1,072 僅 $34，在 ATR14 = $54.42 的環境下，止損幅度不足一個 ATR。GEV 在 6 月 23 日單日曾跌 8.21%，正常波動即可觸及 $1,038，隨後反彈，結果只是讓多頭白白踢出場。止損設計必須吸收至少 1.0–1.2 倍 ATR 的雜訊。

## Asymmetry argument

- **Worst case（全倉股票止損 $993）**：損失 = $1,087 − $993 = $94/股，以 2.5% NAV 倉位計算，最大絕對損失約 **$216,000（組合 $100M 基準下 0.22%）**。
- **Realistic upside T2 $1,182**：獲利 = $1,182 − $1,087 = $95/股，倉位收益約 **$218,000**。
- **Bull case（估值重評 + FCF 加速 → $1,300）**：獲利 = $213/股，倉位收益約 **$490,000**。
- **R:R（現實情境）：$218K / $216K ≈ 1.0**，看似平庸——但加上 Call Spread 的 4.5–5.5 倍槓桿催化，整體組合的非對稱性顯著改善。真正的論點在於：若 Q2 財報超標，市場重估估值框架，$1,300 並非天方夜譚，此時 R:R 升至 **$490K / $216K = 2.3**，已超越中等信心所要求的門檻。
