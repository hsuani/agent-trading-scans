# Aggressive risk view — VRT

## Where trader是too cautious
- 完全零倉位（AVOID/HOLD不加碼）等於把 MEDIUM conviction 的訊號當作 LOW conviction 處理。investment_plan.md 自己承認「基本面成長動能雙方無實質分歧」，戰場只在估值倍數，而估值分歧本身就是財報後最容易被單一數字（EPS $1.43 共識、全年指引措辭）瞬間收斂的那種不確定性——這正是該下小注、而非空手等待的教科書情境。
- 「等 7/29 財報確認後在 MA20 $316.61 之上重建支撐才進場」這個 trigger 假設市場會給你時間反應。實際上財報後跳空是常態——VRT 連四季財報超預期，若第五次再超預期，開盤可能直接跳空穿越 MA20、MA50 甚至前高 $358.54，屆時進場價已比現價高 15-20%，alpha 被等待吃光。
- GEV 7/22 財報是免費的領先指標，卻只被寫成「觀察」而非「觸發小倉位試探」的依據——同業若確認液冷/電力基礎設施需求延續，VRT 財報前就有理由建立 scout position。

## Recommended adjustments
- Size: 無倉位 → Small（1-1.5% 組合曝險）財報前試探倉位，而非等待財報後才決定要不要進場。
- Stop: 不用單純技術停損 $275.12（-9.3%，ATR14 $20.81 波動下容易被財報前雜訊洗出場），改用選擇權定義風險，把「停損」轉成「權利金上限」，徹底消除財報跳空穿破停損價的滑價風險。
- Entry: 現在小倉位進場，不要等財報後確認——確認的代價是錯過跳空。
- Consider：買進 8/21 到期 call spread（Long $310 / Short $360，貼近現價與局部高點 $358.54），最大損失=權利金（假設約 $8-10/張），若財報如預期超標且指引維持，股價挑戰 base case $388.67 甚至 bull case $500，價差可接近滿額獲利。

## Asymmetry argument
現貨小倉位情境：進場 $303.58，停損 $275.12 → 最大損失約 -9.3%（若組合曝險 1.5%，實際虧損約組合的 0.14%）；上檔看 base case $388.67（+28%）至 bull case $500（+64%）。B/A（以 base case 計）≈ 28/9.3 ≈ 3:1，若達 bull case 則 ≈ 7:1。
選擇權情境：最大損失=權利金（假設 $9/張，占組合可控在 0.3-0.5%），若股價達 $360 以上價差滿額，報酬可達權利金 5-6 倍以上，屬於財報催化劑型的高凸性下注，即使錯，虧損金額本身就已經是完全已知且極小的固定數字。

## What I'd push for
不要求貿然重倉正股，但主張用選擇權把「等財報確認」的保守立場，轉換成「用權利金買財報波動」的小額不對稱下注——財報前用 $9/張左右成本建立 $310/$360 call spread，把最大損失鎖在權利金本身（占組合曝險 <0.5%），既保留 trader 對估值分歧未收斂的謹慎，又不放棄連四季超預期紀錄所隱含的跳空上行機率；若財報確認利空、股價跌破 $275.12，選擇權自然歸零，虧損金額早已知曉且遠小於現貨停損被跳空滑價擴大的情境。
