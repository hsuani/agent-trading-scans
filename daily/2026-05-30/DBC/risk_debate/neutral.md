# Neutral risk view — DBC

## 辯論裁定

兩方在「停火 binary event 跳空風險為當前最大尾部來源」上完全一致，這是最可信的共識。分歧集中在 Sizing 與止損設計，以下逐點裁定。

---

## 各方論點評分

### 共識（兩方同意）
- 霍爾木茲停火落地可觸發 DBC 單日 -5% 至 -8%，技術止損有被跳空穿越的現實風險。
- 觸發前進場的 R:R T1 1.6x 在 35% Conviction 下確為負期望值（期望值 ≈ -0.09）。
- OTM put 或 call spread 等選擇權結構在 binary event 前有其合理性。

### 激進方：哪裡過度主張
- **倉位 8–10% NAV 嚴重失據**：35% Conviction 是 LOW 評級，不論鋁缺口多獨立，一個低把握度方向配 10% NAV 意味著最壞情境損失可達 NAV 0.88%（$26.80 止損）。這與 Conviction 分級的整體風控架構根本矛盾。
- **「今日市價直接建 5% NAV」**：BB %B 0.049 的壓縮型態確實存在，但壓縮不指示方向，停火消息隨時可讓 %B 繼續往零靠攏。忽視事件方向性主張即刻重倉，屬反射性激進偏誤。
- **止損放寬至 $26.80（2 ATR）**：2 ATR 緩衝的理由充分，但激進方自相矛盾——一邊說「技術止損會被跳空穿越」、另一邊還加大倉位依賴技術止損保護。

### 保守方：哪裡過度主張
- **止損1 建議縮至 $27.60（進場附近 0.43 ATR 緩衝）**：這等同主動設計一個「稍微震盪即被甩出」的止損。DBC ATR $0.556，$27.84 進場下沿到 $27.60 僅 $0.24，不足半個 ATR，日內噪音必然觸發。縮緊止損的本意是降低損失，結果卻是頻繁被洗出後重新進場，交易成本累積反而侵蝕組合。
- **1.5% NAV 上限過於框架化**：若停火明確破裂，鋁與能源雙催化劑確認，將倉位硬壓在 1.5% 是過度偏向不作為。保守方本身也說「三重觸發成立後加至 2.5%」，這承認了催化劑清晰後倉位可以提升，只是拉的幅度太保守。

## 平衡調整建議

**核心邏輯**：二元事件未落地前，倉位應小到「不依賴止損保護也能接受損失全額實現」；觸發後，依催化劑強度分階段擴倉。止損設計依 ATR 合理緩衝，但不作為主要風控手段——選擇權結構才是 binary event 前的正確對沖工具。

| 參數 | 最終建議 | 裁定理由 |
|------|---------|---------|
| 事件前倉位（現況） | **2% NAV** | 高於保守方 1.5%：鋁缺口確有獨立性；低於原提案 3%：35% Conviction 不支持 Medium 倉 |
| 觸發後上限 | **4% NAV** | 採保守方「2.5%」與激進方「10%」的中間偏保守值；停火破裂確認後方可觸及 |
| 止損設計 | **$26.80（2 ATR 緩衝），採激進方建議** | 保守方 $27.60 緩衝不足半個 ATR，必然被洗出；2 ATR 是技術上更合理的噪音邊界 |
| 進場 | **$27.84–$28.50 支撐區間確認後分批**，不在事件結果前全倉進場 | 採原提案邏輯；激進方「今日直接 5%」在事件方向不明前不合理 |
| 選擇權對沖 | **DBC OTM put，行權價 $27.00，1 個月期，成本 ≈ 0.2–0.3% NAV** | 採保守方建議，作為跳空保險；激進方 call spread 可在停火破裂確認後作為加倉工具 |
| 停火落地緊急出場 | **停火備忘錄正式簽署當日收盤前清除全部多頭，不等技術確認** | 兩方一致；原提案已正確設計，維持不變 |
| 持有期 | **事件驅動 1–4 週；鋁缺口催化劑延至 2–3 個月** | 維持原提案 |

## Net $ 風險（止損觸發）

假設 NAV $100,000：

- 倉位 2% NAV = $2,000，進場 $28.17，止損 $26.80（差距 $1.37，-4.86%）
- 止損觸發損失 = $2,000 × 4.86% = **$97（= NAV 0.10%）**
- 加計 put 保費 0.25% NAV = $250
- **最大已知損失 = $347（= NAV 0.35%）**——在 35% Conviction 下可接受

觸發後加至 4% NAV，若打到止損：4,000 × 4.86% = $194 + 保費 $250 = **$444（= NAV 0.44%）**。

## Net $ 上行（T1 / T2）

- T1 $29.76：$2,000 × ($29.76 - $28.17) / $28.17 = **+$113（= NAV 0.11%）**
- T2 $31.79（4% NAV 觸發後）：$4,000 × ($31.79 - $28.17) / $28.17 = **+$514（= NAV 0.51%）**
- T2 情境 R:R（扣除保費）：$514 / $444 ≈ **1.16x**（淨）；若 put 到期歸零（停火未落地）損失保費後 R:R 回到 **1.6x+**
