# Conservative risk view — GOOGL

## Where trader is too aggressive

- **定倉在無價格數據下執行**：ATR、年化波動率均顯示 PRICE_DATA_UNAVAILABLE，代表 1.5% NAV 的定倉完全沒有 vol-adjusted sizing 依據。依常規，未能計算 R:R ≥ 1.5 前不應啟動任何倉位，更遑論 0.75–0.9% NAV 的「初始配置」。
- **Stop 實質上不存在**：Trade proposal 將 Stop 設為「技術面設於 DOJ 判決或財報後跌破關鍵支撐」，這是描述性語言而非可執行的硬性止損價位。在無硬性 Stop 的情況下，最大虧損額度無法量化，風控框架形同虛設。
- **DOJ 尾部風險被低估**：預設搜尋協議（Apple / Samsung）貢獻年收入超過 $200B，佔搜尋廣告收入比例極高。法院已裁定壟斷成立，補救措施裁決仍懸而未決。此為**不對稱的存在性風險**，一旦判決偏向結構性補救，即時影響無法以技術面 Stop 容納。
- **FCF 首次轉負的信號強度不足以支撐中型倉位**：Capex 從 $52B 暴增至 $195–205B（近 4 倍），FCF 轉負期間財務彈性遭實質壓縮。Cloud backlog $514B 是未來數年的敘事，而 FCF 虧損是當下的財報現實。

## Tail scenarios

- **Scenario A — DOJ 結構性補救（機率約 20%）**：法院強制終止 Apple / Samsung 預設搜尋分潤協議 → 年收入缺口 $200B+ → 市場重新定價 GOOGL 核心商業模式 → 參考價 ~$346 跌至 $230–260 區間，跌幅 -25% 至 -35%。以 1.5% NAV 持倉計算，帳面虧損約為 NAV 之 0.4%–0.5%（假設 Stop 在 -30% 執行，實際虧損倍增若無硬性 Stop）。
- **Scenario B — $84.75B 股權融資確認（機率約 30%）**：鉅額稀釋使 EPS 增長故事崩解，31 Buy / 0 Sell 的過度擁擠共識觸發集中多頭平倉 → 股價下跌 -15% 至 -20%，跌至 $277–294 區間。
- **Scenario C — FY2027 Capex 再度大幅上調（機率約 35%）**：FCF 轉正時程延後至 2028 年後，估值重估壓低倍數 → 股價回測 $300 以下，中期 LONG 論點時間結構崩解。

## Recommended adjustments

- **Size**：Medium（1.5% NAV）→ **Small（0.5% NAV）**；理由：三重不確定性（DOJ、FCF 轉負、$84.75B 融資）中任一事件皆可致使 1.5% NAV 倉位遭受超出預算的虧損，且 ATR 不可得使 vol-adjusted sizing 無從計算。
- **Stop**：待即時報價恢復後，**必須設硬性 Stop 於 $320 或以下**（低於財報後技術支撐），不可以敘事性語言替代執行價位。
- **Entry**：**全面暫停建倉**，等待下列其中一個條件成立：(1) DOJ 補救措施確定為行為限制而非結構拆分；(2) $84.75B 融資細節公開且稀釋幅度可接受；(3) 即時報價恢復、可計算 ATR 並確認 R:R ≥ 1.5。
- **Hedge**：若維持現有倉位，考慮以 XLC 或 QQQ 的 Put（距到期 60–90 天，delta ~-0.25）對沖 DOJ 事件風險，成本約為倉位價值的 0.5–1%。

## Position-level $ risk

在 PRICE_DATA_UNAVAILABLE 且無硬性 Stop 的狀況下，**最大虧損額度無法計算**，這本身就是最嚴重的風控警訊。以最悲觀情境（Scenario A，-30%）估算：若 NAV = $1,000,000，1.5% NAV = $15,000 倉位，-30% 跌幅 = 虧損 $4,500 = NAV 之 0.45%。表面可接受，但若無 Stop，持有至 -50% 以上的路徑風險是真實存在的。**0.5% NAV 上限下，同樣情境虧損 = $1,500 = NAV 之 0.15%，方為合理的尾部暴露。**

## What I'd push for

在 DOJ 補救措施裁決明朗化之前，GOOGL 持有的最大正當倉位上限是 **0.5% NAV**，且須附帶即時報價恢復後可執行的硬性 Stop 價位。當前三重不確定性（DOJ 結構性風險、FCF 轉負、$84.75B 未確認融資）的聯合尾部風險，已超出 Medium sizing 的風險預算，Trade proposal 的「初始配置 0.75–0.9% NAV」應縮減至 0.5% 以下或完全暫停，直至 (1) DOJ 裁定方向明確，且 (2) 即時 ATR 可計算並驗證 R:R ≥ 1.5 後，方可恢復建倉計畫。
