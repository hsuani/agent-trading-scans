# Aggressive risk view — ARM

## Where trader is too cautious

**HOLD/0% NAV 的核心謬誤：把「二元事件」等同於「必須空手」**

交易員的邏輯是：財報二元風險 → 不可建倉。這個推論對**股票現貨**成立，對**定義風險的選擇權倉位**並不成立。以下是被保守立場忽略的結構性優勢：

1. **資料中心版稅翻倍是已確認的歷史數據，不是預測**：Q4 FY2026 資料中心版稅 YoY >100%，超大規模廠商市占率達 50%，$20B AGI CPU 訂單簿橫跨 FY2027-2028。這不是分析師建模出來的假設情境——它是已入帳的合約現實。

2. **CSS 21 份授權的遞延兌現效應被完全低估**：CSS 授權費率為標準 v9 的兩倍。21 份合約中絕大多數將在 FY2027-FY2028 轉為特許權費收益，且**這批收益尚未在股價中完整計入**，因為市場仍聚焦於眼前的季環比下滑 ($1.49B → 預期 $1.27B)，而非未來 4~6 季的費率結構升級。

3. **觀望的機會成本：入場窗口只剩 36-48 小時**：若 7/29 財報數據強勁（資料中心版稅維持 >100% YoY、全年指引上修），股價可能在盤後或隔日開盤跳空 15-25%。此時以「財報後再確認」為由進場的交易員，將以更差的價位追高，且追高本身帶來更大的下行風險——諷刺地比財報前的定義風險倉位更危險。

4. **超大規模廠商 $600B CapEx 尾風被當作背景噪音**：2026 年全年超大規模廠商資本支出達 $600B（YoY +70%）。ARM 的 Neoverse 授權是這條支出管道的直接受益人。此數字不是預測，是已公告的資本計畫。保守立場將此視為「已知利多、已充分定價」，但 CSS 遞延兌現機制意味著**並未充分定價**。

## Recommended adjustments

- **Size**：0% NAV → **1~2% NAV 定義風險期權倉位**（最大虧損鎖定於權利金，與持股現貨完全不同的風險結構）

- **Stop**：選擇權模式下無傳統止損需求——權利金即最大損失上限，到期歸零即全額虧損 1~2% NAV，這是可接受的代價

- **Entry**：**現在進場（非等待）**，但透過選擇權結構限制下行；若堅持現貨則維持 0% NAV 不變

- **Consider — 期權結構**：買入 **Call Spread**，到期日選 **2026-08-01 或 2026-08-15**（覆蓋財報後首週波動窗口），低履約價設於當前市價附近，高履約價參考 Susquehanna 目標 $320 至 Wells Fargo 修正後目標 $350 區間（*注意：PRICE_DATA_UNAVAILABLE，具體履約價須待市場報價確認，不在此指定*）。此結構將最大虧損封頂於權利金，同時完整參與財報後的上行跳空

- **財報後觸發進場（若不採預期期權）**：一旦資料中心版稅確認 >100% YoY 且全年指引上修，**立刻執行 3% NAV 進場**，而非「觀察數週後再評估」——強勁財報後的跳空走勢往往在 24~48 小時內完成，緩慢的確認流程將錯失大部分 alpha

## Asymmetry argument

**最壞情形（1% NAV 期權倉位）**：
- 財報不達預期，股票跌 30-50%，期權到期歸零
- 最大絕對損失：**1% NAV**（已完全定義）

**現實上行（強勁財報情境）**：
- 資料中心版稅持續翻倍 + CSS 費率升級 + 全年指引上修
- 分析師高端目標 Mizuho $500 意味自當前 $302.71 有 **+65% 上行空間**
- Call Spread 在此情境下的回報倍數：**3x~5x 權利金**（視履約價結構而定）
- 等效於：最大損失 $A（1% NAV），現實上行 $B（3~5% NAV）；**R:R = 3:1 至 5:1**

若完全不建倉而財報強勁，追高成本不僅更高，且在跳空後建倉的下行保護更少——此為保守立場的隱性風險，保守者未曾計入。
