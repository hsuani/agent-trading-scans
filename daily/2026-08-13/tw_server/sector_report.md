## 6. 板塊風險

- **CSP capex 週期反轉**：全族群估值均建立在 CSP 持續高 capex 的假設上。若 Microsoft、Meta、Google 任一大廠削減 2027 預算，6669 與 3231 客戶集中度高的特性將導致跳空而非滑價，止損設計面臨失效風險。
- **台灣地緣政治**：台海局勢突變可能觸發外資同步撤離，全族群相關性在此情境下趨近 1.0，分散部署無效。
- **記憶體（HBM/GDDR7）短缺**：TW server ODM 四檔均受記憶體成本壓力影響，2376.TW 已被迫上調 GPU 售價 20–40%，6669 毛利率緩衝極薄（9.3%），成本漲價即壓穿淨利率。
- **NVIDIA 定價權與客戶佔比**：6669.TW 客戶集中度 80%+（Microsoft/Meta），3231.TW AI 伺服器佔伺服器營收逾 95%，任何平台切換或定價調整均影響全年 EPS 假設。
- **外資籌碼擁擠**：6669 與 3231 均出現 8 月外資獲利了結跡象，短期超買後若月營收不及預期，修正幅度可能超過止損帶。
