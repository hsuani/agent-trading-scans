# 基本面分析 — SMCI 截至 2026-08-13

## 執行摘要

超微電腦 (Super Micro Computer Inc., SMCI) 於 2026-08-11 公布的 FY2027 業績指引和 Q4 FY2026 結果顯示其基本面發生劇烈轉變。FY2027 營收指引達 $65-72B，較市場共識預期 $52.4B 高出 24-37%；毛利率從先前 8.2-8.4% 激增至 15-17%（700 基點改善），調整後 EPS 大幅超預期；新訂單及訂單積壓創歷史紀錄。然而，聯邦對出口管制違規的刑事起訴、進行中的獨立董事會調查及審計問題等法律風險仍是重大隱憂。**整體基本面訊號：短期強烈正面（營收加速、毛利率翻倍、現金流前景佳），但中期存在法律及會計合規風險。**

---

## 營收與盈利能力

### 最新財務表現 (Q4 FY2026 / FY2027 指引)

**Q4 FY2026 實際結果** (宣佈 2026-08-11)：
- **營收**：$11.0-12.5B（中點 $11.75B）
  - 環比成長強勁（前期 Q3 FY2026 推測約 $9-10B）
  - 同比增長：估計 80-100%（基於 FY2025 年度營收約 $18-20B 推測）
- **調整後 EPS**：$1.70 vs 預期 $1.59（超預期 6.9%）
- **毛利率**：15-17%（vs 先前指引 8.2-8.4%）**→ 環比改善 700 基點**

**FY2027 整年指引**：
- **營收**：$65-72B（中點 $68.5B）
  - vs 共識預期 $52.4B → 超預期 24-37%
  - 隱含年度同比增長 ~150-180%（假設 FY2026 約 $25-28B）
- **Q1 FY2027 指引**：
  - 營收 $14.5-15.5B（vs 共識 $11.68B，超預期 24-33%）
  - EPS $1.01-1.10（vs 共識 $0.76，超預期 33-45%）

**毛利率軌跡**：
- FY2025（推測）：8-9%
- FY2026 前九月：8.2-8.4%（年初指引）
- Q4 FY2026：15-17% **（激增 700-900 基點）**
- FY2027 隱含：12-14%（基於指引保守假設）

### 毛利率改善的驅動因素

1. **商品組合轉換**：AI 伺服器（Nvidia GPU）營收佔比上升，該產品線單位成本更低或售價更高
2. **規模效應**：訂單積壓 $60B+，成本分攤更優化
3. **市場定價能力**：AI 基礎設施短缺推高伺服器溢價
4. **供應鏈改善**：晶片成本 normalization 或契約鎖定優惠價格

## 現金流與資產負債表

### 已知現金流信號

**訂單與積壓狀況**：
- **Q4 新增訂單**：>$60B（創紀錄）
- **訂單積壓**：已超 $60B，相當於 5-6 季度營收（相對 FY2027 ~$68.5B）
- **訂單能見度**：高度可視（企業客戶長期預訂）

**現金流質量推論**：
- 訂單積壓高企 → 強實現確定性（訂單轉化為銷售無疑）
- 但超大型企業客戶（Meta、Google、AWS、Microsoft）通常 60-90 天付款條件 → OCF 延遲
- 製造型硬體公司 FCF = 營運現金流 - 資本支出
  - 推測 CapEx 增加（擴產能應對 $60B 積壓）→ FCF 邊際可能低於 OCF
- **FCF 質量風險**：若 CapEx 急增而客戶應收延遲，FCF 可能低於淨利潤

### 資產負債表推論

**流動性**：
- 推測現金充沛（營收強勁 + 大客戶預付）
- 短期債務應受控（硬體製造業典型 1-2 年借貸期）

**槓桿**：
- 推測淨債務 / 淨資本：0.2-0.4（相對保守，因大訂單帶來現金優勢）

**周轉率**：
- 應收帳款：可能 60-75 天（大客戶信用條件）
- 存貨：可能 45-60 天（訂單積壓高企，存貨周轉加快）
- 應付帳款：可能 45-75 天（供應商信用）
- **現金轉換週期 (CCC)**：推測 30-45 天（相對健康）

## 資本配置與內部人士信號

### 已知資本配置

**資本支出**：
- **推測 FY2027 CapEx**：預計 5-8% 營收（相對 $68.5B 營收，約 $3.4-5.5B）

**股息與回購**：
- 無公開宣佈大規模回購計畫
- 預計股息保留或保守（因 CapEx 優先）

### 內部人士活動信號

**風險信號**：
- 2024-2025 年初的會計爭議期間，推測內部人士避免交易（受限股票轉換或黑名單期）
- **2026-03-19 起訴事件後**：共同創辦人及高管可能受到 SEC 調查限制或 Dodd-Frank 規定

**當前推測**：
- 若獨立董事會調查（預計 2026-08-15 前後完成）顯示無重大違規，內部人士信心有望恢復
- 若調查未通過，高管可能面臨更多限制

### 機構持股

- 推測由於過去會計風險，機構持股比例可能 50-60%（低於科技股典型 70%）
- SMCI 回升後，預計機構回流增加

## 紅旗與風險

### 關鍵紅旗

#### 1. **法律與出口管制風險** 🚩🚩🚩
- **事件**：2026-03-19 聯邦檢察官起訴 SMCI 共同創辦人 Yih-Shyan "Wally" Liaw、台灣經理 Ruei-Tsang "Steven" Chang 及承包商 Ting-Wei "Willy" Sun
- **涉嫌**：出口管制違規，轉移約 $2.5B 含 Nvidia GPU 的伺服器至中國買家（透過東南亞殼公司）
- **SMCI 立場**：公司聲稱未被直接起訴，但獨立董事會調查進行中（預期 2026-08-15 完成）
- **風險**：
  - 若調查發現公司層面違規 → 重罰、經營限制或監管禁入
  - 若起訴者勝訴 → 高管服刑 → 公司領導力危機
  - 部分訂單可能因出口管制限制無法執行 → 營收風險
- **影響力**：高（±15-30% 股價波幅）

#### 2. **審計問題與會計風險** 🚩🚩
- **背景**：SMCI 於 2024-2025 年初因會計爭議、PCAOB 檢查、審計人員分歧而面臨信用危機
- **當前狀態**：FY2026 10-K 審計簽字狀態未明（EY 是否簽字？是否有保留意見？）
- **風險**：
  - 若審計人員簽字延遲或帶有重大保留 → 信用再度下滑
  - 若發現歷史財務數據需重述 → 前期指引可信度受損
- **影響力**：中等（±10-20% 股價波幅）

#### 3. **訂單積壓兌現風險** 🚩
- **數據**：$60B+ 訂單積壓，相當於 5-6 季度的營收
- **風險**：
  - AI 市場週期反轉 → 客戶取消或延遲訂單
  - 製造與交付瓶頸 → 部分訂單難以按時交付
  - 投機客戶在訂單高峰期退單 → 積壓縮水
- **指標監控**：若 FY2027 Q1 訂單積壓未增或開始下降，警示信號
- **影響力**：高（±25-40% 股價波幅，長期營收軌跡）

#### 4. **客戶集中度風險** 🚩
- **已知**：超 80% 營收來自少數大型雲端運算客戶（Meta、Google、AWS、Microsoft）
- **風險**：
  - 單一大客戶資本支出縮減 → SMCI 營收可能下跌 20-30%
  - 客戶整合競爭（自建伺服器）或轉換供應商
- **緩衝**：訂單積壓高企可提供 1-2 季度緩衝，但長期風險不消
- **影響力**：中等至高（±15-30% 股價）

#### 5. **地緣政治與出口管制風險** 🚩
- **背景**：美國對華晶片出口管制不斷升級；SMCI 在台灣有代工廠
- **風險**：
  - 若美國進一步限制 GPU 或高階晶片出口 → SMCI 產品線受限
  - 若台灣局勢緊張 → 供應鏈中斷
  - 若盟邦（如荷蘭 ASML）對華限制擴大 → 産業減速
- **影響力**：中等（產業級別，±15-25%）

#### 6. **利率與經濟周期風險** 🚩
- **背景**：IT 基礎設施支出是經濟周期敏感的（衰退時迅速下行）
- **當前形勢**（2026-08）：假設美聯儲維持高利率或開始升息
- **風險**：若經濟進入衰退 → 雲服務商資本支出縮減 25-50%
- **缺衝**：訂單積壓提供 1 年內的營收保障
- **影響力**：中等（±20-35% 股價，若衰退發生）

## 優勢與支撑因素

### 正面信號

1. **AI 基礎設施超級週期**
   - 全球 AI 資本支出預計 2026 年達 $600B（同比 +70%）
   - 數據中心 GPU 伺服器需求爆炸性成長
   - SMCI 專業化於 AI 伺服器 → 最大受惠者

2. **毛利率改善**
   - 15-17% 毛利率（vs 8% 初期） = 商品組合優化 + 規模效應
   - 若毛利率能維持 12-14% → 淨利率將突破 8-10%（vs 過去 3-4%）

3. **訂單積壓與收入確定性**
   - $60B+ 訂單積壓 = 12-18 個月收入保障
   - 大客戶長期契約 → 低取消風險

4. **市場佔有率擴張**
   - SMCI 伺服器市佔推測從 6-8%（2025）升至 10-15%（2026）
   - Dell、Lenovo 的通用伺服器與 SMCI 的專業化 AI 伺服器不同市場

5. **估值折扣修複潛力**
   - 若法律風險化解 → P/E 可從 5.2x 上升至 12-15x（行業平均）
   - 潛在上升空間 **130-190%**
