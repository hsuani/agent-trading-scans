# Conservative risk view — CRDO

## Where trader is too aggressive

**1. 以未驗證價格觸發進場，風險不可接受**
trade_proposal.md 明確標示 PRICE_DATA_UNAVAILABLE，卻同時設立「股價 ≤ $252 可建立半倉」的觸發條件。這是自相矛盾的邏輯：若報價無法驗證，$252 支撐位本身就是無根據的參考值，等同於閉眼入場。任何依賴未驗證報價計算的 R:R（如 T1 R:R 0.61x、T2 R:R 2.55x）都缺乏可執行基礎，不應納入決策。

**2. 內部人賣出訊號被嚴重低估**
90 天內淨賣出 $136.4M（1.27M 股）、零買入，CEO 額外將 30 萬股轉入家族信託——此絕非「例行分散」，而是系統性出脫。bull 方將此歸類為 Rule 10b5-1 計劃，但完全無新的公開市場買入作為對沖，在成長拐點前高位清倉與歷史警示型態完全吻合。交易計劃將此列為「警示」，實際上應提升為進場前的阻斷條件。

**3. QoQ 增速結構性放緩，動能已失**
Q2 FY2026 QoQ +20.2% → Q4 FY2026 QoQ +7.4% → Q1 FY2027 指引隱含 QoQ ~8–9%：三季連續遞減，動能趨勢向下。以 P/S 33.2x 的估值，市場需要 40%+ CAGR 才能正當化，而當前數據顯示的是個位數 QoQ 增速正在固化，而非反彈。

**4. Microsoft 單客戶集中度是結構性炸彈**
30–40% 營收依賴單一客戶，且無官方揭露多元化進展。若 Microsoft Q2 CY2026 資本支出節奏轉為「最佳化模式」，CRDO 單季即可出現雙位數營收缺口，而 R&D 佔營收 20.9% 的費用基礎無法即時收縮，EPS 崩塌速度將遠超股價隱含的安全邊際。

## Tail scenarios

- **Scenario A（機率 20%）：Microsoft 拉貨放緩或自研替代** → Q1 FY2027 營收落在 $445–460M（低於指引低端 $465M），管理層保守展望 → 股價重估至 $190–210，較 $252 入場虧損約 $42–62/股，$ 損失 = 虧損幅度 × 持股數 ≈ **NAV -0.8% 至 -1.2%（以 0.5% NAV 倉位計）**。
- **Scenario B（機率 12%）：競爭壓縮毛利率 + EPS 低預期** → 毛利率跌破 65%，FY2027 EPS 錯失至 ~$6.50，市場給予 20x P/E → 目標價 $130，較 $252 入場虧損 $122/股 ≈ **NAV -2.4%（持倉槓桿放大下行）**。
- **Scenario C（機率 15%）：Fed 鷹派意外或宏觀流動性收緊** → 高估值成長股倍數壓縮 15–20%，CRDO 隨板塊同步下跌至 $200–220，止損若設 $235 則觸發，$ 損失 = ($252 − $235) × 持股數 = **$17/股 × 持股數**，尚屬可控；但若止損未紀律執行則下穿空間達 $65+。

## Recommended adjustments

- **Size：Small（0.5% NAV）→ 0（暫不持倉）**
  理由：PRICE_DATA_UNAVAILABLE 使所有入場價格均屬盲估，且內部人賣出 + QoQ 放緩兩項根本性風險仍未解除。
- **Stop：維持 $235 概念止損，但在價格可驗證前無法設定**
  建議改為「財報後確認基本面再設止損」，避免在黑盒價格下錯估損失。
- **Entry：放棄「≤ $252 半倉」觸發，僅保留「2026-09-01 財報後確認」條件**
  財報前完全不建倉，消除報價盲區與事件前夕的最高不確定性。
- **Consider：若財報後強勢確認，以 0.5% NAV 為絕對上限，不因分析師目標上調而追加倉位**

## Position-level $ risk

以 $252 入場、止損 $235 計：
- 風險幅度：$252 − $235 = **$17/股**
- 0.5% NAV 持倉（設 NAV = $1,000,000）：持倉市值 = $5,000，持股數 ≈ 19.8 股
- **止損觸發虧損 = $17 × 19.8 ≈ $337 = 0.034% NAV**

數字本身可接受，但前提是入場報價真實可驗證。若報價有偏差（上下 5%），止損位可能錯誤設定，實際損失將超出計算值。目前 PRICE_DATA_UNAVAILABLE 狀態下，此計算僅為理論值，**不具執行可靠性**。

## What I'd push for

完全支持「等待 2026-09-01 財報」作為唯一觸發條件，並棄用「≤ $252 即建倉」的價格觸發。理由是：三項高風險因素（內部人 $136.4M 淨賣出、QoQ 增速連三季遞減、Microsoft 單客戶集中度無改善數據）在財報前無法解除，而 PRICE_DATA_UNAVAILABLE 更使所有支撐位失去驗證基礎。我主張持倉歸零直至 2026-09-01 財報揭示：① Q1 FY2027 營收 ≥ $470M（超越指引中值且加速），② 毛利率 ≥ 67%，③ 管理層明確揭露 Microsoft 以外客戶佔比正在提升，三項同時成立方可以最高 0.5% NAV 建立初始倉位，財報後首個交易日回調時進場，不追高。
