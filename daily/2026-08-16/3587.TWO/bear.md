# Bear Case Round 1 — 3587.TWO (閎康科技 / HMT)

> 報告日期：2026-08-16 | 作者角色：Bear Researcher

---

## 1. Bear Thesis Statement

閎康科技在AI矽光子情緒泡沫驅動的基本面敘事之下，月度成長動能已明顯折半、財務透明度極度匱乏（資產負債表/FCF/毛利率全數 DATA_UNAVAILABLE）、客戶集中台積電造成單點脆弱性，加上 OTC 小型股流動性劣勢，現階段持有或進場的風險遠大於潛在報酬，應列為「避開或做空觀察」標的。

---

## 2. Bear Arguments（附數據佐證）

### 論點 1：成長動能已明顯減速，趨勢向下

| 月份 | YoY 成長率 |
|------|-----------|
| 2026年4月 | +22.53% |
| 2026年6月 | +11.01% |
| H1累計 | +17.47% |

從4月到6月短短兩個月，YoY增速幾乎**腰斬**。5月數據未在報告中揭露（本身即為警訊）。若7至8月延續此下滑斜率，全年增速可能跌入個位數。在市場仍按高成長股定價之際，增速崩落將帶來估值重評。

### 論點 2：Q1 EPS +194.74% 極可能反映低基期效應，非結構性護城河

- Q1 2026 EPS：2.24元，YoY +194.74%
- 換算：Q1 2025 EPS 約僅 0.76元（半導體景氣谷底期）
- **毛利率、營業利益率、淨利率：DATA_UNAVAILABLE**

+194.74%的增速聽起來驚人，但若底數為半導體景氣循環低谷，則只是均值回歸，而非商業模式質的躍升。在毛利率完全不透明的情況下，無法區分：真正的定價能力提升 vs. 一次性業務高峰 vs. 費用遞延造成的帳面EPS膨脹。

### 論點 3：財務黑盒子——核心指標全數 DATA_UNAVAILABLE

以下關鍵財務指標均無法取得：

| 指標 | 狀態 |
|------|------|
| 毛利率 / 營業利益率 | DATA_UNAVAILABLE |
| 自由現金流（FCF） | DATA_UNAVAILABLE |
| 現金部位 | DATA_UNAVAILABLE |
| 負債結構 / 淨債務 | DATA_UNAVAILABLE |
| 流動比率 | DATA_UNAVAILABLE |
| 應收帳款周轉天數 | DATA_UNAVAILABLE |
| 資本支出趨勢 | DATA_UNAVAILABLE |
| P/E / EV/EBITDA | DATA_UNAVAILABLE（股價不可得） |

對於一家財務不透明的OTC小型股，任何進場行為本質上是**盲目押注**，而非有依據的投資決策。台積電付款週期通常拉長，應收帳款膨脹風險不可忽視。

### 論點 4：客戶集中度風險——台積電依賴症

- 業務描述中台積電為「主要客戶」，推估佔營收比重 ≥70%
- 閎康的成長故事直接捆綁台積電CPO/矽光子製程量產時程
- **單點風險**：若台積電
  1. 延後CPO量產（業界已有前例——矽光子商用化一再延期）
  2. 主動引入大型設備商（KLA、AMAT）替代在地服務商
  3. 削減測試外包、強化內部FA能力
  
  閎康營收將承受結構性衝擊，且幾乎無其他客戶緩衝。

### 論點 5：OTC 小型股流動性陷阱

- 在台灣 OTC（櫃買中心）掛牌，成交量遠低於上市股
- H1 2026 估計營收 NT$400-500M，市值規模有限
- 機構投資人因市值門檻無法重倉，造成：
  - 出售時缺乏買盤承接，滑點風險高
  - 題材退燒時，散戶為主的股東結構將加速下跌
  - 賣壓難以消化，個股跌幅可能遠超大盤

### 論點 6：矽光子測試市場並非藍海，競爭壓力被嚴重低估

市場敘事將閎康定位為矽光子測試的稀缺受益者，但忽略了：

- **KLA Corporation**：擁有專用光學計量工具，正積極佈局先進製程晶圓廠
- **Applied Materials (AMAT)**：在材料分析與製程監控的資源投入遠超閎康
- **日本廠商（Accretech、Lasertec）**：具備同等材料分析能力，在日台間的半導體供應鏈具有技術公信力

跨國大廠可以用規模優勢、更低邊際成本、更完整的技術生態系，直接在台積電供應鏈中排擠閎康的利基空間。

### 論點 7：估值風險——下行空間無法量化但邏輯清晰

- 股價：PRICE_DATA_UNAVAILABLE（不捏造數字）
- 若 FY2026 EPS 因成長放緩回落至 4.0 元（假設全年雙位數成長）
- 若市場情緒轉向，P/E 從景氣高峰的 30-40x 壓縮至循環底部的 10-15x
- **估值壓縮 + EPS 下修的雙殺情境**，下行幅度可達 40-60%（情境估算，非精確預測）

**Worst case**：CPO商用延後一年 + 半導體景氣下行 → EPS 回到 1.5-2.0 元 → P/E 10x → 較目前估值腰斬以上

### 論點 8：半導體景氣週期風險——AI需求可能峰迴路轉

- AI晶片資本支出熱潮具高度週期性（參考2022-2023年記憶體崩跌教訓）
- 若超大規模雲端業者（CSP）削減AI基礎設施投資，台積電訂單下行 → 閎康測試需求連動萎縮
- 情感報告中亦承認：「AI週期波動——如晶片需求回調，成長可能急速放緩」

## 3. Counter to Bull Arguments

**Bull論點 A：「EPS +194.74% 證明獲利能力強勁，商業模式升級。」**
反制：+194.74%的基數為2025年半導體景氣谷底的極低EPS（約0.76元），增速主要反映均值回歸與景氣循環，並非競爭優勢提升。在毛利率DATA_UNAVAILABLE的情況下，無法排除成本轉嫁困難、費用遞延或一次性項目貢獻等可能性。

**Bull論點 B：「矽光子/CPO結構性需求確定，3-5年成長週期穩固。」**
反制：矽光子商用量產時程在業界長期一再延後，台積電CPO量產爬坡本身存在技術不確定性。更關鍵的是，即使需求成真，KLA、AMAT等大廠已預先佈局此領域，閎康能分得的市場份額仍屬未知。

**Bull論點 C：「台積電合作關係形成護城河、客戶黏性高。」**
反制：「主要客戶即護城河」是典型的集中度風險偽裝。台積電一旦決定引入規模更大的設備商、或建立內部失效分析能力，閎康既無合約保障也無替代客戶緩衝，護城河瞬間變懸崖。

**Bull論點 D：「H1累計營收年增17.47%，成長動能強勁。」**
反制：累計數字掩蓋了月度趨勢的惡化方向。4月+22.53% → 6月+11.01%，若以此斜率外推，Q3增速可能跌至個位數，成長故事將快速瓦解，而市場通常提前6-9個月反應。

**Bull論點 E：「情感分析顯示機構輕度買超，市場支撐穩固。」**
反制：情感報告自承：「無法存取」外資、投信、自營商實際數據，所有機構買盤均為「推理依據」而非實測數字。基於推論的看漲情感，是最脆弱的多頭依據。

## 4. Conditions That Would Break the Bear Case

以下條件若實現，應重新評估看空立場：

1. **毛利率公開且達 ≥50%**：代表真正的定價能力，EPS品質獲確認
2. **7至9月月營收 YoY 增速重新加速至 +20% 以上**：扭轉減速趨勢
3. **FCF轉換率 ≥80%**：排除盈利品質疑慮
4. **客戶多元化確認**：台積電佔比降至 ≤50%
5. **大型外資機構（持股 ≥5%）進場**：提供流動性並確認估值合理
6. **競爭壁壘數據揭露**：如專屬技術授權、長期供應合約等具體護城河證明

---

## 5. Bear Signal Conviction

**整體評級：M（Medium，中等）**

**理由：**
- **支持看空的論點清晰且具數據支撐**：成長動能減速（4月→6月腰斬）、財務黑盒子（多項核心指標 DATA_UNAVAILABLE）、客戶集中度風險、OTC 流動性劣勢等均為可驗證風險
- **限制看空信心到中等的因素**：
  - 股價 PRICE_DATA_UNAVAILABLE，無法計算精確 R:R 比率或量化下行目標
  - 矽光子需求確實存在結構性正面因素，不可完全否認
  - 大量財務數據缺失意味著看空論點同樣缺乏完整量化基礎
  - 情境分析依賴假設，非硬數據

**結論**：在數據補全（尤其是毛利率、FCF、客戶集中度）之前，本標的應列為**「觀察避開」**而非積極放空，等待更清晰的財務訊號確認後再行決策。
