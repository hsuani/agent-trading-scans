### 為何 Yahoo Finance 無法提供資料？

1. **台灣小型股覆蓋有限**: Yahoo Finance 對台灣上市公司（尤其是中小型上市股）的財務資料覆蓋遠不如美國、香港上市公司
2. **國際 API 限制**: yfinance 庫主要針對國際股票，對本地台灣交易所數據支援有限
3. **代理連線問題**: 某些端點面臨 HTTP 403 連線被阻擋
