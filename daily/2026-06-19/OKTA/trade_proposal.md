## 判斷依據

現價 $117.81 已充分反映 Q1 FY27 超預期財報與 UBS 目標價調升（$150）的利好消息，但 R:R 不對稱偏空：

- **上行空間**：至分析師共識目標 $133.38，僅約 +13.2%
- **下行風險**：若 Q2 FY27 AI Agents ARR 披露不及預期，P/E 向成熟軟體 20–22x 壓縮，股價目標 $84，跌幅達 -28.7%
- **DCF 公允值**：$80–$95（隱含現價溢價 25–47%）
- **R:R**（至T1 vs 下行）：0.46 — 遠低於 LONG 入場門檻 1.5，不符合交易紀律

**技術面**：一個月暴漲 +37.47% 後，MACD 柱狀轉負（-1.57），832.8 萬股放量（均量 2.24 倍）出現在高位，符合 climactic move 結構，短線追高賠率差。BB %B 0.57，距 Bollinger 上軌 $142.35 尚有空間，但 MACD 動能已先行衰退。

**情緒面**：CEO McKinnon + CFO Tighe 於 $116–$137 區間同步高位套現，累計金額逾 $200M。Mizuho 同期由「優於大盤」降至「中立」，分析師共識目標價 $133.38 較 3 個月前 $133.87 微幅下修。三角背離（散戶看多 vs 分析師軟化 vs 內部人賣出）在機構主導市場中常預示短期修正。

## 等待入場條件（條件成立才考慮 LONG）

**場景一：技術回調進場**
- 入場區間：$100.00 – $107.00
  - $107 ≈ Forward P/E 25x × EPS $4.28（基本面 Fair Value 上緣）
  - $100 ≈ DCF 公允值上緣 + MA50 $91.43 的中間緩衝支撐
- Stop：$91.43（MA50 跌破視為中期趨勢反轉）；若跌破再確認止損 $87.22（MA200）
- Target 1：$133.38（分析師共識目標，R:R ≈ 1.7–2.0）
- Target 2：$150.00（UBS 目標，AI Agents ARR 驗證情景，R:R ≈ 2.9–3.3）
- 於此區間 R:R 達門檻，Size band：Small（0.5% NAV）

**場景二：Q2 FY27 財報基本面觸發（預期 2026-08-25）**
- 觸發條件：AI Agents ARR 首次披露 >$50M 或 調整後 EPS 超預期 >10%
- 於財報後隔日開盤確認後入場，若股價仍在 $107–$120 之間
- Stop：$107 以下收盤（跌回 Fair Value 以下視為論點失效）
- Size band：Medium（1.5% NAV），信心升至高
