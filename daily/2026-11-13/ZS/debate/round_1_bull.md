# Bull case round 1 — ZS

## Thesis (1 句話)
ZS 是零信任安全的平台級龍頭，在毛利率 76.8%、遞延收入 +20.8%、連續 24 季 EPS 擊敗預期的基本面支撐下，股價已自高點回落 42.8%、跌至分析師最低目標價附近，提供風險報酬不對稱的逢低布局機會。

## 成長動能
- FY26 營收 USD 3.35B，YoY +25.4%，三年 CAGR 27.5%，四年來成長未明顯減速（fundamentals.md）。
- 遞延收入（流動）USD 2,480.5M，YoY +20.8%，顯示訂閱續約與新單動能與營收成長同步，非靠一次性收入撐場（fundamentals.md）。
- 2026-10-06 Investor Day 重申 FY27 指引，並給出 FY31 長期框架：基準情境 ARR 超過 USD 8B，agentic AI 加速採用可再帶來約 USD 2B 上行，上看 USD 10B；Data Security ARR 已達約 USD 410M、Security for AI ARR 約 USD 70M，為平台內新的擴張引擎（news.md）。
- OCF FY26 USD 1,129.7M，YoY +16.2%，現金生成能力持續擴大（fundamentals.md）。

## 護城河
平台單一化（SASE / ZIA / ZPA / Data Security / Security for AI）創造高轉換成本，客戶一旦接入零信任架構即難以更換；毛利率連續四年維持 76.8%–78.0% 區間，顯示定價權穩固，未因 Fortinet、Palo Alto 等同業競爭而被侵蝕（fundamentals.md）。機構持股 53.4%、1,231 家機構，BlackRock（6.07%）、Vanguard（合計逾 6.7%）為前兩大持股人，顯示長期資本對平台地位的信任（fundamentals.md）。
