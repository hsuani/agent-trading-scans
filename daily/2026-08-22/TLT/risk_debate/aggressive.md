# Aggressive risk view — TLT

## Where trader is too cautious

- **倉位嚴重偏小**：0.5–1% NAV 在如此明確的不對稱結構下是佔位性符號而非真正的頭寸。機構資金已以實際行為投票（$12.3B 流入逆轉），散戶在門口徘徊等同把先機拱手讓人。
- **等待三重確認是在等一列已出站的列車**：NFP 9/4 → CPI 9/11 → FOMC 9/18，三項催化劑依序兌現時 TLT 早已漲過先行入場者的成本，此時才建倉是在追高、不是在把握不對稱。
- **Stop 設於 $80.50–$81.00 過緊**：TLT 在 20 年新低區間波動率極高（1 個月隱含波動率 68.3%），日內振幅足以輕鬆觸發止損再彈回，等於無謂交出持倉然後在更高價位重建。
- **忽視 options 的不對稱槓桿**：在 18.3% short interest 的軋空背景下，正股 +17% 報酬很好，但定向 call spread 可將相同觀點的資本佔用壓縮至正股的五分之一，同時保留多倍上行潛力。

## Recommended adjustments

- **Size：Small（0.5–1% NAV）→ Medium-Large（2.5% NAV）**，理由：Sahm Rule 0.38 距警戒線 0.50 僅剩一次偏弱 NFP，窗口以天計而非以週計；先發優勢的α必須在催化劑引爆前鎖定。
- **Stop：$80.50 → $79.00**（給予 $1.66 緩衝，約 2% 正股跌幅），讓倉位在高波動環境中呼吸；以 % NAV 計，額外損失僅 +0.05% 組合NAV。
- **Entry：現在建倉（8/22 開盤區間）而非等待 9/4 NFP**；若 NFP 確認衰退信號，TLT 當日跳漲幅可能直接越過原定進場點。
- **Consider：TLT call spread — 買 $84 / 賣 $96，到期 2026/10/17（FOMC +30 天）**；捕捉降息公布後軋空動能的延伸段，最大虧損鎖定於權利金（約 0.3–0.4% NAV 等值），潛在報酬 3–5×。

## Asymmetry argument

以 2.5% NAV 正股多頭計算：**Worst case max loss（止損 $79.00 成立）≈ 0.12% NAV**。**Realistic upside（25bp 降息 + 部分軋空，TLT +8%）≈ 0.20% NAV；若降息 50bp + 軋空全爆，TLT +17% → 0.43% NAV**。R:R = 最低 1.7×，樂觀情境 3.6×。加入 call spread：權利金 0.35% NAV，若軋空觸發目標價 $96，報酬約 1.1% NAV，R:R ≈ 3.1×，且下行風險已封頂。

## What I'd push for

立即以 2.5% NAV 建立 TLT 正股多頭，Stop 設於 $79.00；同步以 0.35% NAV（即組合總風險 0.47% NAV）買入 TLT $84/$96 call spread，到期 2026/10/17，作為 FOMC 二元催化劑的槓桿放大器。Sahm Rule 距觸發僅一次偏弱就業數據，$12.3B 機構流入已是方向確認的先行信號，18.3% short interest 確保降息兌現當日的爆發動能；此刻的「謹慎等待」實質上是以佔位成本換取心理安慰，而非真正的風險管理。最大可量化損失：若 $79.00 止損全數觸發 + call spread 歸零，組合總虧損約 0.47% NAV，遠在可承受範疇內。不行動的機會成本才是真正的風險。
