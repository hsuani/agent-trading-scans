## Invalidation

下列任一條件成立，立即減倉至輕倉或清倉，等待更低價位重建：

- **技術止損**：週線收盤價跌破 NT$1,800（S1 NT$1,810 有效失守）
- **財報失敗**：Q2 EPS < NT$8.5 或 GM 跌破 35%（台幣升值 + 競爭壓縮已發生）
- **籌碼惡化**：財報公布後外資仍連續賣超 5 日以上（分配出清論點獲確認）
- **訂單風險**：任一主要 CSP（Google / Microsoft / Amazon / Meta）公告削減或延後 FY2027 電源採購預算
- **出貨延宕**：HVDC 800V 出貨正式確認推遲至 2027H1 以後，且 FY2026E EPS 共識下修至 NT$30 以下
