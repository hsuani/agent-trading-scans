# Conservative risk view — OKTA

## Where trader is too aggressive

**倉位規模仍然偏大：** 交易提案建議 Small（0.5% NAV），但在 conviction 僅 45%（NEUTRAL）、AI Agent ACV 金額佔比零財務驗證的前提下，0.5% NAV 仍然過重。以 NAV $1M 計算，0.5% = $5,000 部位；以 Entry $100、Stop $83 計算，每單位損失 $17，這意味著最大虧損金額遠超出 45% conviction 等級應承受的上限。**正確上限為 0.25% NAV（$2,500）。**

**$100–$104 並非真正的技術支撐：** MA50 現為 $82.71，MA200 為 $85.79，兩者均遠低於進場目標區間。$100 進場仍較 MA50 偏離 +20.9%、較 MA200 偏離 +16.5%。所謂「整數支撐帶」的說法缺乏具體量化依據——過去均線集中於 $83–$86，意味著真正的技術支撐在 MA200 附近，而非 $100–$104。在均線完成回測之前進場，等同於在無支撐的半空中接刀。

**Stop $83 距離 Entry $100 達 -17%，單筆美元損失仍不可接受：** 以 0.5% NAV（NAV $1M 試算）、Entry $100 建半倉後，若 Stop $83 全部觸發，美元損失 = ($100 − $83) × 25 股（概念）= $425；但若加至全小倉，損失將擴大至 $850，占 NAV 0.085%，就 45% conviction 的 NEUTRAL 交易而言比例偏高。

## Tail scenarios

- **Scenario A（概率 20%）：AI Agent 敘事破滅** — Q2 FY2027 財報（2026-08）未揭露 AI Agent ACV 金額、cRPO 成長仍維持 12% 原地踏步，機構資金撤離 AI 身份安全主題。股價跌穿 MA200 $85.79，測試 $78–$80 區間。若以 $100 進場、Stop $83 未能即時執行（跳空），實際損失可達 ($100 − $78) × 持股 = 美元損失擴大 29%，超出原估。

- **Scenario B（概率 15%）：Fed 政策衝擊 + 科技股重新定價** — 通膨黏性迫使 Fed 延後降息或意外升息，高 Fwd P/E 科技股（包含 OKTA 28.9x）遭受 multiple compression。即便基本面不惡化，股價從 $100 跌至 $88–$90，Stop $83 被觸發。損失 = ($100 − $83) = $17/股 × 全倉。

- **Scenario C（概率 10%）：Microsoft Entra 大客戶滲透加速** — 具體大型客戶流失案例公開，NRR 出現可量化下滑，市場對「中立平台護城河」的溢價收縮。股價快速跌至 $85–$90，接近 MA200，論點失守，強制出場。

- **Scenario D（概率 20%）：股價從未回落至 $100** — 股價在 $108–$120 震盪，交易始終未觸發進場條件，但持有觀察成本（機會成本）累積；待 Q2 財報後若進場條件改變，須重新計算全部參數。

## Recommended adjustments

- **Size：Small（0.5%）→ 縮減為 XSmall（0.25% NAV）** — 理由：conviction 45% 為 NEUTRAL 等級，AI Agent ACV 未獲財務量化，ATR14 $7.03 代表年化波動率估計達 90%，過高波動不應以 0.5% 承接；vol-adjusted 倉位應隨 ATR 上升而降低，而非維持固定比例。

- **Stop：$83.00 維持不變（但嚴格執行，不拖延）** — Stop 設於 MA200 下方 -3.3% 具邏輯性，問題不在寬窄，而在倉位規模。Stop 不應調整，但**倉位必須縮減**以控制美元損失。

- **Entry：不接受 $104 分批建倉，等待 MA200 $85.79 回測確認** — 真正的安全進場是股價回測 MA200 附近（$85–$90）後企穩，而非在 $100 憑「整數支撐」入場。若堅持 $100 區間，最多建 0.125% NAV 試探性半倉，剩餘 0.125% 等候 MA200 確認。

- **硬性規則：OKTA 股價未跌破 $90 之前，任何加倉均不允許** — 直至 AI Agent ACV 金額佔比正式發布，否則任何 $90 以上的進場均視為追高，一律拒絕。

- **Consider：部分以 IGV PUT 對沖科技股板塊系統性風險** — 若持有 OKTA 試探性倉位，可搭配少量 IGV 3 個月 PUT 作為尾部對沖，降低 Scenario B（Fed 衝擊）下的敞口。

## Position-level $ risk

以 NAV $1M、Entry $100、Stop $83、持股 25 股（0.25% NAV = $2,500）計算：

**Stop 觸發損失 = ($100 − $83) × 25 = $425 = 0.0425% NAV**

相較原提案 0.5% NAV（$5,000，Stop 損失 $850 = 0.085% NAV），縮減後的美元風險降低 50%，在 45% conviction 的 NEUTRAL 交易中較為合理。即便 Scenario A 跳空至 $78，損失 = ($100 − $78) × 25 = $550 = 0.055% NAV，尚在可接受範圍內。

## What I'd push for

HOLD 立場正確，這點毋庸置疑；但條件式進場的門檻設定仍需再收緊。$100–$104 進場區間建立在「整數心理支撐」而非任何技術均線的依據上，而 MA50 $82.71 與 MA200 $85.79 才是唯一有量化錨點的支撐。我建議將有效進場門檻下修至「股價收盤回測 MA200 $85.79 附近（$86–$90）並出現量縮止跌」，同時將最大倉位由 0.5% NAV 硬性降至 0.25% NAV。在此之前，任何 $90 以上的進場均屬追高，不論 R:R 計算如何美化，都無法改變「在無支撐區間進場」的本質風險。若股價確實跌至 $86–$90 並伴隨 AI Agent ACV 量化披露，才是同時具備技術支撐與基本面驗證的進場時機，屆時可酌情加碼至 0.5% NAV。
