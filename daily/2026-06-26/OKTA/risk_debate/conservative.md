# Conservative risk view — OKTA

## Where trader is too aggressive

**1. AVOID 條件設定過於寬鬆，給予進場太多彈性**
交易員設計「兩個觸發條件任一即可進場」的結構，但這兩個條件本質上代表截然不同的風險情境。技術觸發（MA50 回測）在基本面未獲驗證前，純粹是在高度不確定的故事上押注低價入場時機；基本面觸發（9/2 財報 AI ARR >$50M）則是在確認後追入，但此時 Entry 被上調至 $108–$115，與當前追高本質差距不大。兩個條件應強制並存，而非任一皆可。

**2. Stop $91.50 偏寬，美元損失不可接受**
以進場中點 $97.50 計算：每股損失 = $97.50 − $91.50 = **$6.00**，跌幅 6.2%。0.5% NAV 倉位下，若以 $100K NAV 為例，部位約 $500，股數 ≈ 5 股，$ 損失 $30 — 表面可控。但若 NAV 為 $1M 規模，部位 $5,000，股數 ≈ 51 股，止損觸發損失 $306。OKTA ATR14 估計 $9–$10，止損 $6 僅 0.6–0.7 倍 ATR，正常波動即可掃掉止損後反彈，形成「噪音止損」（stop hunted by noise）。止損寬度應至少 1.0–1.2 倍 ATR，即 $88–$90，但這會使 R:R 壓縮至 2.9–3.3（仍合格，但應顯式重新計算）。

**3. 倉位 0.5% NAV 在當前環境仍偏高**
年化波動率 50–70%、PEG 3.0、YTD +62%、核心成長率下台階至 9–10%，並且 Mizuho 已正式降級。在基本面催化劑（9/2 財報）到來前，0.5% NAV 的配置實為「高波動低信心資產」的結構性超配。保守評估應壓縮至 **0.25% NAV**，財報後依結果決定是否補至 0.5–1.0%。

**4. 宏觀/板塊風險低估**
科技板塊 P/E 多重擴張在 Fed 維持高利率環境下具高度脆弱性。若 2026 年下半年通膨數據回升迫使 Fed 鷹派表態，成長股估值普遍壓縮 15–25%，OKTA 以 PEG 3.0 為起點的下行空間遠大於同期防守型資產。

## Tail scenarios

- **情境 A（概率 25%）：Microsoft Entra ID 加速蠶食**
  9/2 財報披露 Net Dollar Retention < 110%，客戶預算替換加速。市場重新以 $63–$84 的熊市倍數定價。股價目標 $84，從進場中點 $97.50 損失 **$13.50/股（-13.8%）**，止損 $91.50 被動觸發，$ 損失以 0.25% NAV（$250 per $100K）為例約 **$34**，尚可接受；若持 0.5% NAV 則 **$68**，偏高。

- **情境 B（概率 15%）：Fed 鷹派衝擊（通膨反彈）**
  2026 Q3 CPI 回升超預期，Fed 暗示暫停降息或再升息。成長股估值全面重估，OKTA Forward P/E 從 27–29x 壓縮至 20–22x，對應股價 $75–$82。持倉者在止損 $91.50 強制出場，但若跳空跌破（財報夜），實際出場可能在 $88–$90，損失擴大至每股 **$7.50–$9.50**。

- **情境 C（概率 20%）：AI ARR 無實質披露，故事推延至 FY2028–2029**
  9/2 財報 AI 代理 ARR 未單獨披露或低於 $20M，公司以「仍在部署階段」為由迴避量化承諾。市場重回 9–10% 成長率框架，股價收斂至 $90–$95。停損 $91.50 邊緣觸發，技術上視為「剛好逃出」，但在回測進場下僅為小虧。

- **情境 D（概率 10%）：地緣衝擊或企業 IT 凍結預算**
  全球衰退預期升溫，企業 IT 支出急凍，Okta 失去 SMB 和 Mid-Market 新客戶動能。ARR 成長掉至 6–7%，股價下探 $70–$75，止損遠不足以保護。此情境 0.25% NAV 倉位損失仍在可承受範圍；0.5% NAV 則傷及組合。

## Recommended adjustments

- **Size**: 0.5% NAV → **0.25% NAV**（理由：在基本面催化劑 9/2 財報前，屬高波低信心資產，遵從投資計畫自身指示「低信心環境下不逾標準倉位一半」；0.5% 已是最低標準，0.25% 才是「最低的一半」）
- **Stop**: $91.50 → **$89.00–$90.00**（理由：1.0–1.0 倍 ATR $9–$10 以下，避免正常波動觸發；同步顯式計算新 R:R：以 $97.50 進場、$89.50 止損、T1 $116 → R:R = 18.5 ÷ 8.0 = **2.3**，仍超過 1.5 門檻）
- **Entry**: 維持 $95–$100，但須兩個觸發條件**同時成立**（技術回測 + 財報 AI ARR > $50M），不可任一。若財報前無法回測 MA50，則財報後再以新止損重新計算進場
- **Consider**: 買入 OKTA 2026-10 到期 $90 Put 作為尾部對沖，成本約 $2–$3/張（估計），對應每份合約 $200–$300；此 hedge 在情境 A/B 下保護下跌，可抵消約 50% 止損損失

## Position-level $ risk

以 0.25% NAV、$100K 組合為例：

| 項目 | 數值 |
|---|---|
| 部位價值 | $250 |
| 進場中點 | $97.50 |
| 股數（約） | 2.56 股 → 取 2 股 |
| Stop（建議） | $89.50 |
| 每股損失 | $8.00 |
| 止損觸發 $ 損失 | **$16**（= 0.016% NAV） |
| 佔 NAV 比例 | 0.016% |

**結論：可接受。** 若 NAV 為 $1M，$ 損失 $160，完全在風險預算之內。但注意若財報夜跳空，實際滑點可能將損失擴大 1.5–2.0x，最壞情境 $320（$1M NAV），仍屬可控。原始方案 0.5% NAV 止損損失為 $32 per $100K / $320 per $1M，止損偏窄（$91.50）更易被噪音觸發，實際虧損次數可能更高。

## What I'd push for

**強化 AVOID 條件：不允許兩個觸發任一即進場，必須要求兩條件同時成立。** 在 9/2 財報前，OKTA 的 AI 代理故事完全是時程風險，而 Microsoft Entra ID 的替代效應每季都在悄然累積——這段「盲期」中，技術回測若發生在壞消息前夕（如 NDR 下滑），進場即套牢。即便技術回測至 $95–$100，若 9/2 財報 AI ARR 不達標，跌至 $84 的概率立刻升至 25–35%。因此，我的執行調整是：將倉位從 0.5% 壓縮至 **0.25% NAV**，止損下移至 $89.50 以避免被 ATR 噪音掃出，並以 OKTA 2026-10 $90 Put 做最低限度的尾部對沖，總成本不逾 $3/張。在兩個條件均成立前，此倉位視為「研究倉」而非「信念倉」，任何一個失效條件（NDR < 110%、AI ARR 未披露、管理層大量 10b5-1 賣出）均立即清倉而非等待反彈。
