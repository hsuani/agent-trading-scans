# 新聞彙整 — 6669.TW 緯穎科技 (Wiwynn) | 2026-06-26

## 公司特定頭條 (近14天)

- **2026-05-28** — 緯穎警示AI供應鏈短缺可能延續至2027-2028年，超越記憶體晶片的短缺範圍至網路晶片與其他元件 (Bloomberg / GuruFocus)。
  影響: **負面**。擴展的供應鏈瓶頸威脅推升硬體成本與延遲全球AI基礎設施建置進度，儘管Meta、Microsoft持續加碼資本投資。

- **2026-05-21** — AMD承諾投資超過台幣100億元於台灣AI產業，深化與ASE、SPIL的戰略合作開發電源效率更佳的AI晶片技術 (Reuters)。
  影響: **正面**。驗證台灣作為全球AI供應鏈樞紐地位；緯穎作為NVIDIA伺服器製造商受惠於AMD Helios GPU伺服器需求擴張，預期下半年放量。

- **2026-05-29** — Nvidia執行長黃仁勳領軍計算領袖齊聚台灣Computex，聚焦供應鏈瓶頸與晶片層級競爭 (Bloomberg)。
  影響: **中性/正面**。Computex為產業風向標；緯穎將展示CPO光學互連創新方案，彰顯技術領先地位。

### 財務與策略面 (近30天)

- **2026-04月底** — 緯穎Q1獲利創同期新高：合併營收新台幣2,765.08億元 (+62% YoY)，稅後淨利141.14億元 (+44.1% YoY)，EPS 75.95元。
  自4月起啟動記憶體代採購模式，4月營收82.73億元 (+29.67% YoY)，月環比下滑16.14%但伺服器機櫃出貨與毛利率環比改善 (CMoney / 經濟日報)。
  影響: **正面**。營收與獲利齐創歷史高位；商業模式轉型反映市場成熟化，有利長期毛利穩定。

- **2026-05至06月間** — 緯穎預示2026年全年伺服器出貨維持雙位數年增，預期營收挑戰新台幣1.25-1.35兆元(年增32-42%)；展示CPO與液冷、高功率配電等次世代資料中心設計方案 (Wiwynn PR / 鉅亨網)。
  影響: **正面**。確認強勁訂單韌性，技術創新持續鞏固市場地位。

### AI伺服器市場動能

- **2026-05至06月** — 全球AI伺服器市場動能不減：Meta、Microsoft、AWS、Google持續加碼資本支出；英業達預期2026年AI伺服器產能翻倍，新增台灣、泰國、墨西哥、美國生產線；仁寶預告2026年Q2後爆發性成長；廣達預估市場三位數成長 (DIGITIMES / 股感)。
  影響: **正面**。需求端確認強勁；緯穎作為全球前三大AI伺服器ODM，直接受惠。

### 台灣經濟與利率環境

- **2026-06** — 台灣央行維持政策利率不變（連八季凍結），但總裁楊金龍釋出偏向緊縮訊號，市場預估最快6月升息可能性升溫；央行同步上修2026年經濟成長率至7.28% (CBC新聞稿 / 經濟日報)。
  影響: **中性**。升息預期可能推升企業融資成本，但台灣經濟成長向上修正反映AI產業帶動效應；緯穎已於3月發行20億美元可轉債融資，進一步融資需求有限。

### 地緣政治與貿易

- **2026年Q2** — 美國對中國晶片出口管制持續，推升台灣製造商競爭優勢；台灣半導體供應鏈因而獲得優先採購地位 (市場觀察)。
  影響: **正面**。強化緯穎與其他台灣ODM廠商在美國客戶（Meta、Microsoft、Google、Amazon）心目中的戰略地位。
