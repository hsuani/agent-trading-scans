# Conservative risk view — VST

## Where trader is too aggressive

- **倉位 1.0% NAV 仍偏重**：年化波動率 54.6%、ATR $6.96，以 vol-adjusted 風險框架計算，此波動等級對應 NAV 上限約 0.5%。在 MA200 尚未收復、技術面長期動能未確認之前，滿配 1.0% 屬超前下注。
- **止損 $133.00 過寬**：從現價 $160 至 $133，跌幅 -16.9%，若以 1.0% NAV、50 股計算，每股損失 $27，單邊 $ 損失達 NAV 的 1.7%（止損本身就是超出預算的虧損）。應收緊至 $145（近期盤整低點），將最大風險壓縮於可接受範圍。
- **T1 R:R 0.60x 入場即不達標**：以現價 $160 入場、T1 $173.35，R:R 僅 0.60x，交易員卻選擇此刻建半倉，實質上是在用劣質 R:R 承擔高波動風險；MA200 未突破前入場，等同於買阻力。

## Tail scenarios

- **Scenario A（機率 20%）：Fed 維持高利率 + 信用利差擴大**
  VST 短期債 $4.23B 再融資困難，Debt/EBITDA 3.81x 超出投資級上限壓力，評級遭 S&P 下調 → 價格跌至 $125，$ 損失（$160 − $125）× 倉位股數 = NAV -2.2%。
- **Scenario B（機率 15%）：Q2 2026 FCF Miss + Cogentrix 交割延宕**
  FCF 年度指引下修，P/FCF 113x 估值無支撐，機構拋售 → 跌破 $133 技術無效，價格重測 $110，$ 損失超 NAV -3%。
- **Scenario C（機率 10%）：AI 資本支出縮減，Meta/AWS PPA 修訂**
  PPA 換約談判期延至 2028，核電稀缺性溢價被重新定價 → 壓至 $140，止損仍在外。

## Recommended adjustments

- **Size：1.0% NAV → 0.5% NAV**（理由：波動率 54.6% + 流動比率 0.78x + MA200 下方，三重風險疊加）
- **Stop：$133.00 → $145.00**（tighter；緊貼近期盤整結構低點，跌破即代表短期多頭動能消失，不需等到 52 週低才認輸）
- **Entry：等待 MA200 $173.35 收復確認後再建倉**（或至少等收盤站上 $165 量增，再以 0.5% NAV 建立初始倉位）
- **Consider：買入 VST 2026-09 $145 Put 作部分對沖**，對沖 Cogentrix 交割受阻尾部風險
