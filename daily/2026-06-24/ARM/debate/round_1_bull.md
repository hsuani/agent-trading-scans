# Bull case round 1 — ARM

## Thesis（1 句話）

ARM 已從純 IP 授權商轉型為 AI 資料中心基礎設施的核心賣鏟者，AGI CPU 超 $20 億積壓訂單、CSS V3 大客戶量產部署，加上版稅引擎的複利效應，足以支撐現有溢價倍數並在 FY2028 前大幅重估盈利水準。

---

## Growth drivers（成長驅動力）

- **AGI CPU 訂單爆發：** ARM 自製資料中心 CPU（ARM AGI CPU）推出後，跨 FY2027-2028 積壓需求已超 $20 億，較發布時 $10 億訂單翻倍，Meta 為共同開發夥伴（來源：news.md）。這不只是授權費，更是晶片銷售毛利的全新收益流。

- **資料中心授權年增逾 2 倍：** Q4 FY2026 資料中心版稅收入年增超過 200%，同期授權總收入年增 29% 至 $8.19 億（來源：news.md）。資料中心在 ARM 整體營收中佔比 35-40%，且增速 30%+，是加速整體成長的最大槓桿。

- **CSS V3 進入量產：** Microsoft Azure Cobalt 200（132 核 Neoverse V3，TSMC 3nm）成為首款公開部署的 CSS V3 矽晶；Rebellions/SK Telecom 採用 Neoverse CSS V3 進入電信 AI 主權算力（來源：news.md）。每新增一家超大規模客戶部署，版稅流即成為長達 5-7 年的遞增收入。

- **版稅 vs 授權的結構性提升：** FY2026 版稅收入占比已達 60-70%，毛利率趨近 100%；版稅依出貨量自動遞增，不需額外銷售成本。隨 AI 晶片出貨量複合增長，版稅引擎的邊際利潤率遠高於任何競爭模式（來源：fundamentals.md）。

- **營收 3 年 CAGR 22%，且加速：** FY2024/25/26 分別成長 20.6%/23.9%/22.8%，趨勢穩定（來源：fundamentals.md）；數據中心新引擎在 FY2027 起貢獻度更高，CAGR 有望加速至 25-30%。

---

## Moat（護城河）

ARM 架構護城河極深，且因 AI 週期而在加固而非削弱：

1. **生態系統鎖定：** 全球超過 2,700 億顆晶片採用 ARM 架構。蘋果 A 系列、Google TPU 周邊、Amazon Graviton、Microsoft Cobalt——一旦架構確立，重寫軟體工具鏈的轉換成本以十億美元計。RISC-V 在低端物聯網可替代，但在高效能運算核心生態遠未成熟。

2. **IP 壟斷性定價權：** ARM 對高端 v9 架構的授權費率顯著高於前代，且客戶無替代選項。每次架構升代，ARM 均可重新談判並提高授權單價，形成週期性定價提升機制。

3. **AGI CPU 的先發垂直整合：** ARM 不再只收版稅，而是直接以自製晶片切入 AI 伺服器硬體市場。相比 Intel 在資料中心 x86 的沉重遺留包袱，ARM AGI 以低功耗、高核心密度的差異優勢切入，並有 Meta 背書，形成先發壁壘。

4. **SoftBank 87% 持股穩定股權：** SoftBank 持有 86.72% 股份（來源：sentiment.md），浮動籌碼稀少，大幅降低籌碼出清的流動性衝擊，並確保長期資本支持研發投入。

## Rebuttal to bear round 0

本輪無前一輪空方論點。將預先反駁已知的市場疑慮：

- **熊方疑慮：「Forward P/E 135-140× 極度高估」**
  反駁：此倍數基於 FY2026 EPS $0.85，但市場定價的是 FY2028 EPS，而非線性外推。AGI CPU $20 億積壓訂單、資料中心版稅 200%+ 年增，意味 FY2028 EPS 重估至 $5-7 並非不可能。若以 FY2028E EPS $6 計、P/E 75-100×，現價 $416 僅為合理估值區間的下緣。高倍數本身不是賣出理由——低倍數資產在 AI 超級週期是例外，不是常態。

- **熊方疑慮：「分析師目標均值 $257，折價 38%」**
  反駁：分析師目標價反映的是 12 個月共識，而非 AGI CPU 商業化後的 FY2028 前景。Wells Fargo 已將目標從 $255 升至 $410，Bernstein/Mizuho 目標 $500，代表前沿分析師已在更新模型（來源：news.md、sentiment.md）。均值因保守舊模型拖低，不應直接作為現價錨點。

- **熊方疑慮：「高管大量出售是頂部信號」**
  反駁：高管出售共 $62M，相對市值 $445B 占比僅 0.014%（來源：fundamentals.md）。且 SoftBank 持有 86.72% 股份從未出售，才是真正的大股東意志。高管出售多為稅務規劃與員工股權兌現，不代表業務基本面轉壞。

- **熊方疑慮：「RISC-V 開源競爭蠶食市場」**
  反駁：RISC-V 僅在低端物聯網、邊緣嵌入式有實質替代性，高效能資料中心與行動旗艦領域軟體生態差距以數十億美元計。ARM v9 架構授權在 AI 晶片設計中的採用率持續上升，ARM AGI CPU 的直接競爭對手是 Intel 而非 RISC-V。

**8 / 10**

理由：AGI CPU $20 億積壓訂單、CSS V3 量產部署、資料中心版稅 200%+ 年增，三個獨立數據源均指向 FY2027-2028 EPS 大幅重估。ARM 的商業模式護城河（生態系統鎖定、IP 定價權、AGI CPU 先發優勢）均有具體事件支撐，而非投機性預測。扣除估值壓縮風險（高 Beta 3.79、MACD 轉負）後，風險/回報比仍向多方傾斜。唯一制約信心的因素是短期 MACD 動能減弱與 RSI 高位，故非滿分。
