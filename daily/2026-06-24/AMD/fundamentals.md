# 基本面分析 — AMD（截至2026年6月24日）

## 執行摘要

AMD在AI加速芯片和數據中心市場的主導地位持續推動強勁營收增長（2025年YoY +34.3%），基本面財務狀況優秀，惟估值倍數處於歷史高位帶來重大風險。公司現金流質量卓越（FCF $6.74B，占營運現金流87.4%），淨現金狀態充裕（$51.6B），但Forward P/E達35.67倍、EV/EBITDA達101.21倍反映市場過度樂觀定價。內部人士持續淨拋售信號與庫存激增38%暗示潛在需求放緩預警。

**註**：本報告基於截至2026年6月8日之最新可用緩存數據編製。實時yfinance數據因代理阻擋而無法獲取，建議交叉參照市場即時行情。

## 營收與獲利

### 營收成長動力

**年度營收軌跡**：
- 2025年營收：$346.4B（2024年：$257.9B，YoY +34.3%）
- 2024年營收：$257.9B（2023年：$226.8B，YoY +13.7%）  
- 2023年營收：$226.8B（2022年：$236.0B，YoY -3.9%，疫後庫存修正期）
- **3年CAGR（2023-2025）**：+23.4%

### 毛利率與營運效率

**毛利率演進**（反映產品組合升級與規模效應）：
- 2025年毛利率：53.1%（2024年：49.4%，+370基點）
- 2024年毛利率：49.4%（2023年：46.1%）
- 2023年毛利率：46.1%（2022年：44.9%）

毛利率續創歷史新高，反映Data Center 業務（AI加速器、EPYC伺服器處理器）高毛利貢獻佔比提升，以及Taiwan Semiconductor Manufacturing Company (台積電) 先進製程合作成本優化。

**營運利率與淨利潤**：
- 2025年營運利率：14.4%（2024年：8.1%，+630基點）
- 2025年淨利率：13.4%（2024年：6.4%，+700基點）
- 2025年淨收入：$433.5M（2024年：$164.1M，YoY +164%）

淨利潤增幅超越營收增幅，指示營運槓桿與成本控制優秀。

### 業務分部（基於長期業務摘要）

AMD營運三大核心業務部門：

1. **Data Center（數據中心）**
   - 最強增長引擎；高階AI加速器（MI300、MI325系列）、EPYC CPU平臺
   - 受惠超大規模雲服務商（Meta Platforms、Tesla、Microsoft、Google）AI基礎設施投資週期
   - 毛利率最高，通常60%以上

2. **Client and Gaming（客戶端與遊戲）**
   - Ryzen消費級CPU、Radeon獨立顯卡
   - 受景氣週期與競爭（Intel、Nvidia RTX）影響較大
   - 近年成長相對溫和

3. **Embedded（嵌入式系統）**
   - FPGA、自適應SoC、高性能數據處理單元
   - 工業、汽車、通訊應用
   - 規模較小但毛利率穩定

Q1 2026季度營收$102.5B暗示近期動能維持。

## 現金流與資產負債表

### 自由現金流品質

**FCF績效**（現金轉化效率領先業界）：
- 2025年FCF：$673.5M（2024年：$240.5M，YoY +180%）
- 2024年FCF：$240.5M（2023年：$112.1M）
- **3年CAGR（2023-2025）**：+145%

FCF增速超越營收與淨利增速，反映營運現金管理優秀。

**FCF品質指標**：
- **FCF/營運現金流（OCF）比**：673.5M / 770.9M = **87.4%**
  - 健康水準（>80%為合格，>90%為卓越；87.4%屬上游檔次）
  - 表示不到13%的營運現金用於資本支出

- **FCF占營收比**：673.5M / 346.4B = **1.94%**
  - 單位營收FCF轉化率相對低，但絕對金額龐大反映公司規模

### 營運與投資現金流

**營運現金流**：
- 2025年OCF：$770.9M（2024年：$304.1M，YoY +153%）
- 2024年OCF：$304.1M（2023年：$166.7M）

營運現金流加速成長，支持「財務狀況改善」論點。

**資本支出**（CapEx加速投資先進製程）：
- 2025年CapEx：$974.0M（2024年：$636.0M，YoY +53%）
- 2024年CapEx：$636.0M（2023年：$546.0M，YoY +16%）
- **CapEx占營收比**：2.8%（行業典型2-4%區間，中等水準）

CapEx加速反映AMD對台積電先進製程產能的長期承諾與自建設施投資（如AMD Fab 設施計畫）。未來資本強度或持續上升。

### 債務與槓桿結構

**債務組成**（2025年12月31日）：
- 短期債務：$874M
- 長期債務：$2.348B
- 資本租賃債務：$625M
- **總債務**：$3.847B（2024年：$2.212B，YoY +74%）

**淨債務與現金流動性**：
- 淨債務 = 總債務 - 現金 = $3.847B - $55.4B = **-$51.6B（淨現金狀態）**
- **淨債務/EBITDA**：-6.94x（極低，實為淨現金）

**杠桿比率**：
- 債權益比（D/E）：$3.847B / $630.0B ≈ 0.61（低，相對於行業標準）
  - 註：yfinance報稱D/E為6.01，差異可能源於會計定義差異或包含營運租賃負債
- 債務占總資產比：$3.847B / $769.3B = **0.5%**（極低）

**利息負擔**：
- 2025年利息支出：$131.0M（2024年：$92.0M，+42%）
- 淨利息收入：$84.0M（高存款與流動性投資收益）
- 利息覆蓋率（EBIT/Interest）：極高，不構成債務風險

**結論**：AMD淨現金狀態與低杠桿提供戰略靈活性與防守韌性。新發行債務反映對長期增長投資的融資需求，利率環境下仍屬可控。

### 工作資本與庫存動態

**營運資本**：
- 2025年工作資本（流動資產-流動負債）：$174.9B（2024年：$117.7B，+48.6%）
- 工作資本增幅高於營收增幅，暗示營運現金投入加大

**存貨動態（警示信號）**：
- 2025年存貨：$79.2B（2024年：$57.3B，YoY +38.2%）
- 存貨占流動資產比：29.4%（2024年：30.1%）
- **Days Inventory Outstanding (DIO)估計**：存貨 / (營收/365) ≈ 79.2B / (346.4B/365) ≈ 83天

存貨增幅38%遠超營收增幅34.3%，可能反映：
1. 前瞻性採購因應AI芯片需求（健康解釋）
2. 需求放緩導致庫存堆積（風險解釋）
3. 新產品線庫存建立（過渡性）

應收帳款增幅相對溫和（+2.1%），暗示銷售信用政策未明顯放寬，但庫存激增值得持續監控。

### EV/EBITDA異常分析

EV/EBITDA達101.21倍乃罕見現象，隱含市場假設：
- EBITDA未來年複合增長率需達20%以上（10年週期）方可合理化
- 或市場定價AI芯片週期的超長週期增長（15-20年）
- 反向推導：若EBITDA維持平穩，股價需跌90%才能達到12x EV/EBITDA

此倍數水準為「成長型泡沫」典型特徵，任何盈利預期下調將引發估值重估。

## 關鍵催化劑與風險

### 近期盈利與指引

**已報告季度**：
- Q1 2026：營收$102.5B（強勢）
- Q4 2025：基於mostRecentQuarter時間戳

**預計下次財報日期**：
- 2026年8月（基於earnings時間戳差異推估；通常Q2財報於7月底/8月初發佈）

**指引風險**：
- 如Q2 2026營收增速低於預期或毛利率未如預期擴張，估值將面臨大幅調整
- Forward EPS $13.08 假設隱含全年增速 >31%；任何修正將拖累Forward P/E

### 正面催化劑

1. **AI芯片需求續旺**
   - 超大規模雲提供商（Meta、Tesla、Microsoft、Google、Amazon）持續CAPEX投資
   - AMD MI300/MI325系列加速器市場佔有率提升
   - 預估未來3年Data Center營收可維持25-35% CAGR

2. **客戶多元化**
   - 過往Nvidia客戶（如Meta）轉向AMD以求供應多元化與成本優化
   - 新客戶導入（如Tesla自研芯片仍需外包設計方案）

3. **製程領先**
   - 台積電3nm、2nm製程合作，成本優化空間
   - 相對Nvidia搭載台積電同樣製程時，AMD設計更高效

4. **併購整合**
   - 過去Xilinx併購（$49B，2022）強化FPGA與自適應SoC組合
   - 未來可能進一步戰略併購

### 風險催化劑

#### 紅色警示（高風險）

1. **AI芯片需求週期見頂風險**
   - 超大規模商品化完成後，新增CAPEX可能放緩
   - 客戶庫存調整週期
   - 宏觀經濟衰退導致企業CAPEX削減

2. **Nvidia價格競爭激化**
   - Nvidia佔有超70%市場，掌握定價權
   - 若Nvidia降價應對，AMD邊際率將受壓
   - 次世代GPU（Blackwell vs. MI425）性能競爭

3. **庫存激增風險（警訊）**
   - 存貨同比+38.2%遠超營收+34.3%
   - DIO延長至~83天，可能預示需求放緩或過度備貨
   - 未來季度可能面臨庫存調整與應收減值風險

4. **估值重估風險**
   - EV/EBITDA 101.21x為泡沫水準
   - 任何盈利預期下調 5-10% 將導致股價 20-30% 調整
   - 利率上升加重折現率，估值承壓

5. **地緣政治風險**
   - 台灣晶圓代工供應鏈風險（中國威脅）
   - 美國出口管制對中國市場AMD銷售的限制（雖非主要收入但涉及長期戰略）

#### 黃色警示（中等風險）

1. **CapEx加速投資**
   - 2025年CapEx +53% YoY，未來資本強度可能持續上升
   - AMD計劃自建fab設施（如美國新廠），CapEx佔營收比可能升至3-4%
   - FCF增速可能放緩

2. **利息支出上升**
   - 利息支出+42% YoY，反映債務增加與借入成本上升
   - 若聯邦基金利率維持高位，未來融資成本上升

3. **短期債務增加**
   - 短期債務從$0M升至$874M，需關注到期與再融資風險

4. **競爭加劇**
   - Intel新CEO Gelsinger策略調整，Xeon CPU回檔威脅
   - ARM架構系統芯片新興競爭對手（如Ampere Computing、Marvell）

#### 綠色信號（防守優勢）

1. **現金流健康**
   - FCF $6.74B，占OCF 87.4%，現金轉化優秀
   - 每季FCF產生支持研發與回購

2. **淨現金狀態**
   - 淨現金$51.6B（淨債務-$51.6B）

## 風險旗標與情景分析

### 紅色警示（嚴重風險因子）

1. **EV/EBITDA 101.21倍 — 泡沫徵兆**
   - 同業中位數12-15倍，AMD超額600-740%
   - 隱含市場定價未來10年 >20% EBITDA CAGR
   - **風險量化**：若EBITDA增速修正為10%（實為保守），EV/EBITDA應為30-40倍，意味股價需下跌60-70%

2. **內部人士大規模拋售 — 減持信號**
   - CEO Lisa Su拋售$121M；CTO、CFO、數據中心GM等核心管理層淨拋售$210.6M
   - 傳統上管理層減持預示股價見頂或內部對估值過高的認可
   - **歷史先例**：科技泡沫(2000)、Nvidia 2021年CEO減持、Tesla CEO季度性減持前股價調整

3. **存貨激增38% — 需求放緩預警**
   - 存貨 $79.2B（2024年$57.3B），DIO達~83天
   - 應收帳款增速（+2.1%）遠低於存貨增速（+38.2%），暗示銷售轉移不順
   - **可能解釋**：過度備貨、客戶需求疲弱、或庫存周期見頂
   - **風險量化**：若未來2季庫存需調整$15-20B，FCF將受損，牽制股價

4. **估值倍數風險 — 任何利潤預期下調均觸發重估**
   - Forward P/E 35.67倍已高企，每下調1%盈利預期，P/E將升至36+倍（因分母萎縮）
   - **情景**：若Q2/Q3營收增速降至20%（相對下調40%），Forward P/E 將升至45-50倍，市場可能出現獲利拋售

5. **Nvidia競爭壓力 — 市占率蠶食**
   - Nvidia仍掌控70%以上AI芯片市場；AMD雖增長快但基數小
   - 若Nvidia推出更高性能GPU（Blackwell CUDA核心數更多），AMD可能被邊緣化
   - 價格戰將直接衝擊毛利率（目前53.1%）
