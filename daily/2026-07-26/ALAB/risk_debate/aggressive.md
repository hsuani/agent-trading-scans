# Aggressive risk view — ALAB

## Where trader is too cautious

- **財報前倉位 0.25% NAV 過於微薄**：距離 2026-08-04 財報僅 9 天，成長重加速論點（YoY +85-90% vs Q1 +60%）已有公司自行披露的指引數字支撐，不是臆測。0.25% NAV 的建倉規模即使股價財報後跳升 20%，對整體組合獲益幾乎不可見。這是「方向正確、規模無意義」的典型錯誤——在最具確定性的催化劑窗口內把自己壓縮成零。

- **財報後加倉門檻過苛（四條件全滿）**：要求 Q2 超指引上限 + Q3 指引 ≥ $400M + 毛利率 ≥ 73% + Scorpio X 設計導入公告「同時成立」，這個機率極低，即使強勁財報也難以一次觸發全部條件。屆時股價可能已跳升 20-25%，追入的 R:R 反而更差——等同強迫自己在最不利的時點才行動。

- **止損寬度邏輯不清**：ALAB 在七月中旬已有 6 個交易日 -27.3% 的先例，ATR 極高。貼近「近期顯著低點」的緊止損在財報前正常波動中極易觸損，使正確方向的部位被過早清倉。

- **完全忽略 Options 結構**：明確二元事件（9 天後財報）是 Call Spread 的理想場景，可定義最大損失、放大上行槓桿，交易者未提及任何 Options 替代方案，屬明顯遺漏。

## Recommended adjustments

- **Size（財報前）**：0.25% NAV → **0.5% NAV**（理由：催化劑時程固定、再加速有指引數字，更大規模才能讓正確方向轉化為有意義的組合回報）
- **Size（財報後）**：上限 1.0% NAV → **上限 2.0% NAV**（理由：若 Q2 beat + Q3 指引強勁，估值重評可達 +30-35%，此刻卻把自己鎖死在半倉等同放棄最佳加碼窗口）
- **加倉條件**：四條件全滿足 → **放寬為核心兩條件**（Q2 收入 > $365M + Q3 指引 ≥ $400M），Scorpio X 公告視為額外加分而非必要門檻
- **Stop**：寬度應設在建倉後 **-12% 至 -15%**（對應 ~$345-357 區間），給予財報前的正常 ATR 波動空間，避免提前洗出
- **Consider**：以 0.25% NAV 買入 Call Spread — $420 / $460，到期 **2026-08-15**（財報後一週），最大損失為 premium，bull case 報酬倍率可達 3-4x；剩餘 0.25% NAV 持正股作為基礎部位

## Asymmetry argument

以隱含股價 ~$406 計算：

| 情境 | 股價變動 | 2.0% NAV 倉位損益 |
|---|---|---|
| Worst case（財報 miss，毛利再壓縮） | -35% → ~$264 | 最大損失 **-0.70% NAV** |
| Realistic upside（beat + Q3 指引強勁） | +25% → ~$508 | 獲益 **+0.50% NAV** |
| Bull case（Scorpio X 重新評級） | +35% → ~$548 | 獲益 **+0.70% NAV** |

R:R（Realistic）≈ 0.71x — 交易者對 R:R 偏空的判斷有數字依據，因此激進觀點**不支持財報前重倉**，而是主張財報前以 0.5% NAV 建立有意義的初始敞口，財報後確認核心兩條件後果斷加至 2.0% NAV。

## What I'd push for

將財報前第一段倉位從 0.25% 提升至 0.5% NAV，其中 0.25% NAV 以 Call Spread $420/$460（到期 2026-08-15）替代正股，最大損失鎖定於 premium，上行槓桿顯著優於持股。財報後，只要 Q2 收入超指引上限且 Q3 指引 ≥ $400M 兩個核心條件成立，立即加碼至 2.0% NAV 正股，不必等待 Scorpio X 公告這一最難同期量化的條件。止損從貼近近期低點改為寬幅 -12%，避免高 ATR 環境下被過早洗出。當前計劃最大缺陷不是方向，而是在最具確定性的催化劑窗口內將規模壓縮至「即使正確也無意義」——這是信心不足的表現，而非風控紀律。
