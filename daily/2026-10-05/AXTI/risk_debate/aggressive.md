# Aggressive risk view — AXTI

## Where trader is too cautious
- Sizing 直接砍到 0%，等於把 MEDIUM conviction 當成 ZERO conviction 處理。技術面已經是教科書級多頭排列：價格站上 MA20/50/200，MACD 柱體擴張，RSI 62.71 尚未超買，BB %B 0.944 代表動能正在加速而非枯竭。完全空手，等於把 10/13-15 SEMICON West 這個管理層發言催化劑，以及財報前可能的追價行情全部讓渡出去。
- 「等財報驗證後再進場」聽起來穩健，但實際上是在財報公布瞬間的跳空缺口之外，才願意承擔風險——那時候風險報酬比往往已經惡化（追高進場），而不是現在。
- Base case 多方論點（Q2 營收 +165% YoY、OCF +$10.78M、FCF +$3.56M、淨現金 $417.2M vs 短債 $84.2M）本身已經是可驗證的「已發生」數據，不是猜測；用這些數據完全不進場，是把空方「估值已預支」的論點權重放到 100%。

## Recommended adjustments
- Size：0% → 小倉戰術倉位（投組 3-5% notional），理由：MEDIUM conviction 不該等於 0 曝險；用小尺寸換取捕捉財報前動能與 SEMICON West 催化劑的機會，同時不違背空方估值警訊。
- Stop：$78.18 維持不變（這點 trader 設計是對的，不需再收緊，ATR14 $7.09 之下再收緊只會被正常噪音洗出場）。
- Entry：不要全等財報，現在小倉位進場，財報後站穩 $97.79 再加碼確認。
- Consider：用 call spread 取代現股全曝險——買 $90/$110 Nov 2026 到期（財報後到期），用權利金上限鎖死最大虧損，同時保留財報若超預期（EPS ≥$0.32、營收 ≥$66M、毛利率 ≥42%）衝向 $97.79 甚至更高的槓桿收益。

## Asymmetry argument
以現股小倉（5% of $1M 投組 = $50,000 notional，約 582 股 @ $85.87）計算：跌破 $78.18 停損，最大虧損 ≈ $7.69/股 × 582 = **$4,470**；財報驗證成功上攻 $97.79，獲利 ≈ $11.92/股 × 582 = **$6,940**，若延伸至空方目標價區間上緣或多方 Base case 重新定價，上行可達 15-25%。保守估算 Ratio ≈ 1.55x，若用 call spread 結構（權利金通常只占股價 3-5%），槓桿後 ratio 可拉高到 3x 以上，同時最大虧損金額本身是固定、已知、可控的。

## What I'd push for
不要用 0% 放棄這個設置。保留一個小倉位（現股 3-5% 或等值 call spread），停損維持 $78.18 不變，把它當成「財報前動能 + 催化劑曝險」的戰術倉位，而非賭財報結果；一旦 10/29 財報不如預期跌破 $78.18 就乾淨出場，成本可控；若財報驗證成功則順勢加碼，這樣才不會在動能最強的這段時間完全缺席。
