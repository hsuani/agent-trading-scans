# Conservative risk view — IRM

## Where trader is too aggressive

交易員的 HOLD/AVOID 方向正確，但止損設定與對已持倉者的容忍度仍有商榷空間。

- **止損 $121.50 過寬**：從 $127.24 跌至 $121.50，風險 $5.74/股，以 ATR $3.48 計算相當於 **1.65 ATR**。對於財務基本面存在多重紅旗（FCF -$10.1B、槓桿 7.7x、CEO 淨賣出 $51.6M）的個股，設定大於 1 ATR 的止損距離在風險報酬失衡情境下難以辯護。
- **倉位 Small (0.5% NAV) 仍非零**：若投資組合 NAV 為 $500,000，0.5% = $2,500 名目，止損損失 = $2,500 × ($5.74 / $127.24) ≈ **$113**；雖然絕對金額不大，但在多重負面信號同步確認的環境下，正確倉位應為 **0%（新倉）**。交易員允許「已持倉者維持半倉」等於給既有偏誤（sunk cost）留空間。
- **R:R 1.19 被允許存在**：R:R 至 T1 僅 1.19，低於最低門檻 1.5，任何以交易紀律為優先的方法論均應拒絕此設定。

## Tail scenarios

- **Scenario A（Fed 維持高利率，prob 25%）**：2026H2 Fed 延後降息，10 年期公債殖利率維持 4.5%+，IRM 再融資成本上升。淨利息支出（2025 年 $8.3 億）若升 100bp 則年增 $1.9 億，AFFO 受壓 3–4%，倍數收縮至 P/AFFO 18–20x，目標價下修至 **$105–$115**，損失 **$12–$22/股**。若 0.5% NAV 倉位以 $127.24 進場，帳面損失約 **$118–$215**（以 NAV $500K 計）。

- **Scenario B（超大型客戶延遲/取消，prob 15%）**：AWS 或 Azure 出現合約縮減，Q2 數據中心出租量低於 40MW（全年目標 100MW），管理層被迫下調 AFFO 指引至 $1.60–$1.65/股，市場從「數據中心成長股」框架切回「高槓桿傳統 REIT」框架，P/AFFO 壓縮至 16–18x，目標價 **$26–$30**（以保守 AFFO $1.70 × 16x）或更低，下行 **75%+**。

- **Scenario C（股利削減，prob 10%）**：FCF 持續惡化（2026 預計仍 -$10B 以上），信評機構下調評等，IRM 被迫將年息從 $3.46 削減至 $2.50 左右，REIT 配息型持有人集體出走，股價跌至 **$90–$100**，對應 YTD 漲幅幾乎全數回吐。

- **Scenario D（做空機構報告，prob 8%）**：第三方機構發布報告質疑 AFFO 調整中維護性 Capex 被系統性低估（fundamentals.md 中已明確記載此爭議），觸發估值框架重評，股價短期暴跌 **20–30%**，至 **$89–$102**。

## Position-level $ risk

以 NAV $500,000、倉位 0.5%（$2,500 名目）計算：

| 參數 | 數值 |
|------|------|
| 進場參考價 | $127.24 |
| 現行止損 | $121.50 |
| 止損距離 | $5.74 |
| 持股數（估算）| $2,500 ÷ $127.24 ≈ 19 股 |
| 止損命中損失 | 19 × $5.74 = **$109** |
| 占 NAV 損失 | $109 ÷ $500,000 = **0.022%** |

絕對金額損失雖小，問題在於**賠率結構不合格**（R:R 1.19）加上**基本面脆弱**，即便損失微小，持有此倉位亦是資本配置紀律的失守。建議新倉為零。
