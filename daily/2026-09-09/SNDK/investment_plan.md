# Investment Plan — SNDK (SanDisk) | 2026-09-09

## 研究主管綜合評估

### 辯論裁決
辯論結果：**勢均力敵，輕微傾向多頭，但信念度偏低。**

多頭的企業 SSD 成長故事具有結構性支撐，但空頭對 NAND 過剩、Kioxia 合資風險及競爭格局的擔憂均有實質基礎。SNDK 是最薄弱的合格標的——勉強通過三項 Phase 1 訊號，且情緒面是弱項。

### 投資主題
**企業 SSD 分拆後低認知折讓 + AI 訓練儲存需求長期 TAM**

SNDK 的核心論點是「市場尚未給予企業 SSD 純粹標的應有的估值」，而 AI 儲存需求的持久性為 NAND 週期性提供了結構性緩衝。這是一個需要時間驗證的論點，缺乏近期強力催化劑。

### 風險調整後觀點
- **基礎情境**（機率 45%）：企業 SSD 穩健成長，整體 NAND 價格緩步回升；分析師覆蓋擴大帶來溫和估值重評（+10–20%）
- **多頭情境**（機率 25%）：Kioxia 合資解決 + 企業 SSD 市佔提升 + NAND 供需平衡改善 → 顯著上行
- **空頭情境**（機率 30%）：NAND 新一輪過剩 + Kioxia 合資摩擦 → EPS 大幅下修，高空頭比率引發追空

### 關鍵假設與監控指標
1. 企業 SSD 季度收入成長（目標 YoY +20%+）
2. Kioxia 合資廠產能分配新聞
3. 空頭比率變化（若下降為正面訊號）
4. 整體 NAND ASP 走勢（TrendForce 月報）
5. 分析師覆蓋廣度增加

### 投資結論
**BUY（輕倉，觀察性）**，信念強度：低偏中（45%）

建議配置權重低於 SK Hynix 和 WDC，作為 NAND 週期復甦的低倉期權部位。
