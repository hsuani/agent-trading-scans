# Conservative risk view — GEV

## Where trader is too aggressive
- **停損結構上過寬**：$807 自現價 $1,090 = **-26.0%** 回撤若觸發。在 1.5% NAV 倉位下，那是 **NAV 停損損失 0.39%**——算術上可接受，但對於 62.1% 年化波動、ATR 4.2%/日的標的，*跳空風險*意味著在 Q2'26 不達標下穿透 $807 的滑價是現實的（1-2 ATR 跳空 = 多出 $46-92 = 額外 0.05-0.10% NAV）。
- **估值緩衝為零**：P/E fwd 44、EV/EBITDA 84、P/B 21、P/FCF 79——皆為產業中位數 3-5×。倍數壓縮至中位（EV/EBITDA 15-18）而無盈餘成長 = 股價 $400-500。$807 停損連空方的*基本*重估區（$545-693）都尚未觸及，意味若倍數壓縮論點啟動，$807 是半山腰而非底部。
- **倉位規模假設失效機制有效**：1.5% NAV 僅在 $807 確實能作為可交易停損守住時才合理。在制度轉變下（超大規模業者 capex 暫停、Fed shock），GEV 將跳空穿透。實際尾部損失 = 大於計畫的 0.39%。
- **MACD 看跌交叉 + 價格距 52w 高點 -7.7% + 內部人處分 + FMR -5.2%/Coatue QoQ -7.3%** 是被忽略的分配訊號匯流。交易員注意到但仍於 $1,090（MA20 頂端）買入首批。
- **催化劑空窗期危險**：首批立即進場，但 7 月底 Q2'26 財報前無 GEV 個別催化劑。兩個月的純盤面風險 + 可能搶先觸發的 Siemens Energy 橫向參照（5 月底）。

## Tail scenarios
- **情境 A — 倍數壓縮至產業中位（機率 25%）**：超大規模業者 capex 減速新聞 或 Q2'26 訂單儲量成長令人失望。Fwd P/E 自 44 重估至 22-28，對應 $24.76 EPS → **$545-693**。自中位進場 $1,026，這是 -32% 至 -47%。停損觸發於 $807（-21%），但跳空下實際成交於 $750-780 = 部位 **-25% 至 -27%**。在 1.5% NAV 上 = **NAV -0.38% 至 -0.40%**。
- **情境 B — Wind 分部 + 關稅升級（機率 15%）**：離岸 ITC 落日衝擊加深（$400M 損失擴大至 $600M+），鋼鐵／電工鋼關稅衝擊 $400M+。股價滑落至 $850-900 區間（-17% 至 -22%）。$807 停損勉強守住或觸發。**NAV -0.30%**。
- **情境 C — Fed/總體衝擊 + 高 beta 解倉（機率 10%）**：GEV beta 1.31、12m +152%、80% 機構持股、268M 流通股——典型的被迫賣盤輪廓。SPX -10% = GEV 在資金流下 -18% 至 -25%。停損在跳空下觸發。**NAV -0.30% 至 -0.40%**。
- **情境 D — 盈餘品質空方算術驗證（機率 15%）**：街頭將 $2.05B 遞延所得稅資產釋出正常化剔除；正常化 P/E 約 100× 成為共識框架。安靜地降評至 $700-800。停損觸發。**NAV -0.30%**。

累積尾部機率約 50-65% 在 1-3m 窗口內發生*某種*停損觸發事件。Q2'26 財報（7 月底）的單一個股特有跳空風險是主要集中度。

## Recommended adjustments
- **倉位：Medium 1.5% → Small 0.75-1.0%**（理由：62% 年化波動 + 零估值緩衝 + MACD 看跌交叉 + 內部人處分 = 每單位 NAV 的波動調整風險為普通工業股的 2×；倉位減半以使其相當）。
- **停損：$807 → $945-960**（理由：收緊至*略低於* MA50 $961.72——這正是交易員自己定義的重新評等為 NEUTRAL 的觸發點。如果交易員承認 MA50 跌破 = 論點削弱，為何要等到 $807？$945 停損對中位進場 $1,026 = 每單交易損失 -7.9%；在 0.75% NAV 上 = **NAV -0.06%**——比 -0.40% 容易存活得多）。
- **進場：分批／等待確認**——*完全跳過 $1,090 錨點批次*。等待以下任一：(a) 在量能下收盤回到 $1,150 上方（動能重啟）、或 (b) 拉回至 $962-1,000 配合 MACD 柱狀反轉。勿在 MACD 看跌交叉 + 52w 高點附近投入資金。
- **考慮避險**：搭配 XLI puts（Industrial ETF、3 個月、5-10% OTM），規模約部位名目金額 30%。成本約 NAV 0.15%，涵蓋情境 A/C 的系統性壓縮。或者，做多 SIEGY 作為相對價值配對（相同訂單儲量論點、倍數減半）——做空 GEV / 做多 SIEGY 捕捉倍數收斂。

## Position-level $ risk
依交易員計畫（1.5% NAV、中位進場 $1,026、停損 $807）：
- 停損損失 = ($1,026 − $807) × 股數 = $219/股 × N。在 $10M NAV 下，1.5% = $150,000 部位 = 約 146 股。停損損失 = $219 × 146 = **$31,974 = NAV 0.32%**（乾淨停損）或在實際跳空下 **約 $36-40k = NAV 0.36-0.40%**。
- **可接受？** 算術上是（低於每筆交易 NAV 0.5% 上限）。**策略上否**——停損如此之寬，功能上是*部位檢視*而非停損。26% 不利移動意味論點已實質性受損（很可能重估至 $545-693），即使在 $807 出場仍是接落下的刀。寬停損將原本應為停損的設計，轉變為沉沒成本決策。

依我的建議調整（0.75% NAV、進場 $962-1,000、停損 $945）：
- $ 損失 = ($980 − $945) × 股數 = $35/股 × 約 76 股 = **$2,660 = NAV 0.027%**。每筆交易風險減少 12×。釋出再進場的容量以等待論點重新確立。

## What I'd push for
**倉位減半（1.5% → 0.75%）、停損收緊至 $945（略低於 MA50）、拒絕 $1,090 錨點批次。** 等待以下任一：在量能下動能重啟 >$1,150 或乾淨拉回至 $962-1,000 配合 MACD 柱狀反轉，才部署首筆資金。以 3 個月期 XLI puts 5-10% OTM 對沖約 30% 名目金額，或作為 SIEGY/GEV 相對價值配對運作。論點是合理的，但進場時機與停損紀律暴露了比必要多 12× 的資金風險。先撐過 Q2'26 財報再考慮加碼。
