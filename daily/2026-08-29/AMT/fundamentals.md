# 基礎分析——AMT（2026年8月29日）

## 執行摘要

美國電塔（AMT）是全球領先的通訊基礎設施REIT，持有148,000多座通訊塔及數據中心設施。公司2025年營收成長5.1%至106.4億美元，淨利潤增長12.2%至25.3億美元，淨利率達23.8%。自由現金流健康，FCF/淨利率為1.50倍。然而，公司負債高達449.6億美元，淨債務35.7億美元，槓桿比例明顯，當前P/E為24.3倍，評估相對合理但不便宜，適合尋求穩定股息與基礎設施曝險的投資人。

### 股東回報率

- **ROE**（2025）：(2,529.5M / 3,652.5M) = **69.2%** — 異常高，反映高槓桿結構

### 估值合理性

AMT以24.3倍P/E交易略高於基礎設施REIT中位數，但考慮到：
1. 穩定5%左右營收成長
2. 23.8%淨利率與63%淨利增長軌跡
3. 高分紅收益率與穩定現金流
4. 全球多元地理位置降低風險

當前價位**相對合理但非便宜**，適合長期持有導向投資人，而非價值獵人。

## 紅旗警示

1. **高槓桿與低流動性**：淨債務35.7B，流動比率0.352，依賴持續現金生成與資本市場融資。
2. **配息率極高（96%）**：雖有FCF支撐，但成長空間受限，任何現金流下滑將威脅股息。
3. **EBITDA衰退**：2025年EBITDA 6.45B，YoY下降9.9%（雖正常化EBITDA上升，但報告EBITDA疲軟信號）。
4. **內部人淨賣出**：高層在188-215美元高點密集售股，暗示對股價認知保守。
5. **估值不便宜**：P/E 24.3倍與EV/EBITDA 18.6倍高於平均，缺乏明顯邊際安全性。
6. **利率敏感性**：作為高槓桿REIT，利率上升將增加融資成本，壓低估值倍數。

## 結論

**財務健康評分：良好（7.0/10）**

AMT展現穩健的營運表現，營收持續成長、淨利率擴張、現金流充沛，配息持續且具吸引力。作為基礎設施REIT領導者，受惠5G與邊際計算長期趨勢。然而，高槓桿結構與低流動資產配置為典型REIT風險，需持續監控利息覆蓋率與融資市場環境。

**估值吸引度：中等（6.0/10）**

當前P/E 24.3倍與EV/EBITDA 18.6倍相對合理，股息率3.97%具吸引力，但不具明顯折扣。適合：
- 尋求穩定股息與基礎設施曝險的長期投資人
- 能容納高槓桿結構的投資組合
- 對5G/邊際計算長期成長的看多者

不適合：
- 尋求低估值切入的價值投資人
- 厭惡高槓桿的保守投資人
- 短期交易者
