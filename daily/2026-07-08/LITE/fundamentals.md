# 基本面分析 — LITE（Lumentum Holdings）截至2026年7月8日

## 執行摘要

LITE 正在從電信衰退中復甦，由 AI/數據中心光模塊需求驅動。FY2025 營收 1,645 百萬美元，同比成長 21.1%；毛利率從 18.5% 躍升至 28.0%，反映製造效率改善與出貨組合優化。然而，公司仍在盈利復甦初期（淨利率 1.57%），大幅資本支出導致自由現金流轉負（-$104.7M），加上 19.21 倍淨槓桿比率（同業中位<3 倍）形成償債風險。更關鍵的是，管理層在近期高位（950-1000 美元/股）大幅賣出超過 $70M 股票，強烈暗示內部對當前高估值缺乏信心。估值（P/E 149 倍、P/S 26.6 倍）與基本面嚴重脫節，整體表現為「復甦初期但高估值、高槓桿、弱現金流」的組合。

**PEG 比率分析**：0.63x 看似便宜，但基於以下假設：

- **風險**：任何執行不力將導致 PEG 瞬間>1.5

### 絕對估值與合理性檢驗

**基於 FY2025 實際 EPS $0.37**
- P/E = $850/$0.37 = 2,297x **完全無法接受**
- 原因：FY2025 盈利僅 $25.9M（剛脫離虧損），基數太小導致倍數失效
- **啟示**：不能用過去盈利評估股價，必須看未來增長預期

**基於 Forward FY2026E EPS $18.13**
- P/E = $850/$18.13 = 46.9x（相對合理范圍邊界）
- **隱含前提**：FY2026 EPS 需達 $18.13（同比增 4,800%，完全不可信）
- **市場預期**：若共識 $18.13，表示市場預期 FY2026 營收 $2.8-3.0B、毛利率 28%、EBITDA$350M+

**基於 EBITDA 倍數**
- TTM EBITDA $508.8M（基於 FY2025 年度數據+FY2026 Q1-Q3 估算）
- EV/EBITDA = $62.9B / $0.509B = **123.6x**（極高）
- 健康公司通常 8-15x；高增速公司可承受 20-25x；LITE 123.6x 無法用任何框架解釋

**合理估值推導**（基於保守假設）
- **假設情景**：FY2026 營收 $2.8B、毛利率 27%、EBITDA $300M、EBITDA 倍數 20x
- **合理 EV**：$300M × 20 = $6.0B
- **合理股價**：($6.0B - $1.73B 債務 + $0.88B 現金) / 67.78M 股 = **$64/股**
- **當前股價/合理股價**：$850 / $64 = **13.3 倍溢價**

### 估值驅動因素與風險

**高估值驅動因素**
1. **AI/數據中心熱點**：投資者對 Cloud & Networking 業務寄予厚望，給予「未來 50 年成長故事」溢價
2. **供應鏈稀缺性溢價**：光模塊供應緊張，市場給予溢價（但溢價正在縮小）
3. **技術周期位置**：市場處於 AI 基礎設施建設上升期，類似 2016 年 GPU 周期
4. **低基數效應**：從虧損到轉正，EPS 增速表面上極高

**高估值風險**
