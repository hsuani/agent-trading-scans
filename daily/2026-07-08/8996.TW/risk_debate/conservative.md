# Conservative risk view — 8996.TW

## Where trader is too aggressive

- **部位上限仍偏鬆**：原提案設定 ≤ 0.25% NAV，在以下五個風險因子同時存在的情況下仍屬偏積極：(1) ATR 數據完全缺失（僅估計 NT$50–80）；(2) 處置股前科使集合競價流動性風險尚未完全消除；(3) 5月 MoM 月增 −33.42% 缺乏管理層說明；(4) 外資 −121 張 + 自營商 −135 張同日淨賣，「聰明錢」方向明顯；(5) Q1 後市場共識尚未正式上修，定價錨點仍為落後 P/E 103x。五個風險因子疊加，0.25% NAV 的試探倉若遭遇流動性黑洞，實際損失很可能遠超預設。

- **止損距離過寬，恐難兌現**：Stop 設於 NT$1,200，距 Entry 中點 NT$1,415 達 NT$215（15.2% 跌幅）。若 ATR ≈ NT$60，此止損寬度約 3.6× ATR，正常情況下噪音觸發機率低，然而問題不在噪音，而在**流動性黑洞**：一旦 8996.TW 再度列入處置股，集合競價機制下止損單根本無法以設定價位成交，帳面止損形同虛設，實際虧損可能遠大於 NT$215 / 股。

- **董監質押率 20.89% 為被低估的尾部風險**：在高波動環境下，主要股東融資強制平倉可觸發瀑布式跌勢，且往往在盤中瞬間發生，此時已無法在 NT$1,200 止損。

## Tail scenarios

- **Scenario A（機率 25–30%）：2026-07-10 6月營收年增 < 30%，MoM 連三負**
  → 市場解讀成長動能見頂，外資加速調降目標價至最悲觀共識 NT$900
  → 假設跌至 NT$1,100（止損無效 / 跳空），Entry NT$1,415 → 損失 NT$315 / 股
  → 0.25% NAV 倉位之實際美元損失 ≈ 0.056% NAV（比預設嚴重 47%）

- **Scenario B（機率 15–20%）：Q2 EPS < NT$5 + 新任總經理宣布擴廠延遲**
  → 執行風險與估值雙重打擊，P/E 103x 錨點重新有效，股價測試 NT$900–1,000
  → Entry NT$1,415 → 損失約 NT$415–515 / 股，NAV 傷害 > 0.07%

- **Scenario C（機率 10–15%）：Fed 超預期升息或美國對台灣科技供應鏈加徵關稅**
  → 台幣升值壓縮出口利潤 + 外資系統性撤台，AI 供應鏈類股齊殺
  → 8996.TW 本益比壓縮至 30–40x（即便 EPS 軌跡不變），股價跌至 NT$900–1,200

- **Scenario D（機率 5–8%）：8996.TW 再度列入處置股**
  → 集合競價流動性凍結，部位無法正常出清，持有成本即為最大風險

## Recommended adjustments

- **Size：≤ 0.25% NAV → ≤ 0.15% NAV，或在 7/10 確認前 PASS**
  理由：五風險疊加 + 流動性黑洞使止損難以兌現；0.15% NAV 更能反映「觀察倉」而非「建倉」的信心水位。

- **Stop：NT$1,200 維持不動，但需搭配流動性觸發退場機制**
  若 8996.TW 重列處置股（任何一天），無條件立即縮減至半倉或以集合競價市價出清，勿等待 NT$1,200 止損線觸及。

- **Entry：7/10 前 PASS，收到 6月營收數據後再決定**
  若 6月 YoY ≥ 40% 且 MoM 轉正 → 以 NT$1,380–1,420 分兩批進場，第一批不超過 0.10% NAV，確認三日站穩後再補第二批。

- **考慮對沖**：若進場，可配置 TAIEX Futures 空單（台指期）或購入 AI 供應鏈 ETF 反向部位，對沖台灣系統性賣壓。
