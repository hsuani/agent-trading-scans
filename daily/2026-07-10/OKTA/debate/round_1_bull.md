# Bull case round 1 — OKTA

## Thesis（一句話論點）

OKTA 正從企業身份管理平台升格為 AI 代理授權基礎設施的**唯一官方標準**，Cross App Access 成為 Model Context Protocol 官方授權擴展奠定結構性護城河，疊加 FCF 利潤率 29.6% 的財務轉機，令公司在非人類身份 TAM 幾何倍增的超級週期下具備顯著重估空間。

---

## Growth drivers

- **AI 代理 TAM 幾何爆炸**：IAM 市場至 2030 年達 $45.22B（CAGR 15.7%）；去中心化身份市場 2026-2030 CAGR 53.5%，規模 $41.7B。2026 年起非人類身份（API、機器人、IoT、第三方整合）超過人類使用者 **3:1**，OKTA 的 XAA 是對接這波爆量的唯一 MCP 官方授權擴展。（來源：news.md）

- **XAA 商業化倒數計時**：2026-06-23 宣布 XAA 升格為 Model Context Protocol 官方授權擴展，合作夥伴涵蓋 Anthropic、Canva、Docker、Figma、Linear。Auth0 B2B SaaS 客戶 **7 月底**早期存取，Workforce 客戶 **8 月**透過 Okta Integration Network 全面上線。首批商業化 ARR 即將進帳，提供具體的 EPS 上調依據。（來源：news.md）

- **財務轉機驗證**：FY2026 FCF $863M（利潤率 29.6%），3 年複合營收增長 15.6%（CAGR），Q2 FY2027 EPS $0.91 超預期 $0.85（+7%），連續 beat 節奏強化市場對後續指引可信度。（來源：fundamentals.md、news.md）

- **有機擴張引擎**：NRR 107% 意味現有客戶隊伍每年自動貢獻超過 7% 額外 ARR，無需純靠新客戶開拓即能支撐加速成長。（來源：sentiment.md）

- **AI 代理產品已佔新品營收 30%**：AI 安全產品已不是未來概念，而是當下實際貢獻，為後期估值重估提供基本面錨點。（來源：fundamentals.md）

## Moat（競爭護城河）

**第一層：協議標準壟斷**  
XAA 成為 MCP 官方授權擴展，意味每一個採用 MCP 生態的 AI 代理若需跨應用存取，必須通過 OKTA 進行授權。協議層面的標準地位形成**技術鎖定**，競爭者即便功能相似也無法繞過此協議優勢。

**第二層：Workforce + Auth0 雙引擎覆蓋**  
企業員工身份（Workforce IAM）與開發者/B2B CIAM（Auth0）雙平台覆蓋，客戶遷移成本極高。Gartner Peer Insights 評分 4.6 星（1,141 條評論），領先 Ping Identity（4.4 星，621 條），體現客戶黏性有具體數據支撐。

**第三層：淨現金護城河**  
資產負債表持有淨現金 $2.13B（現金 $2.55B 減債務 $0.42B），資本充足可持續加大 AI R&D 投入，拉大與中型 IAM 競爭者的技術差距，並在環境惡化時提供防禦緩衝。
