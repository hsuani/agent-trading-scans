# UUP — Invesco DB US Dollar Index Bullish Fund｜基本面分析
**分析基準日：2026-05-16**

---

## 1. ETF 概覽

| 項目 | 內容 |
|------|------|
| 發行商 | Invesco |
| 類型 | 美元指數多頭 ETF（Long USD） |
| 追蹤標的 | Deutsche Bank Long US Dollar Futures Index（做多美元 vs 一籃子主要貨幣：EUR、JPY、GBP、CAD、SEK、CHF）|
| Expense Ratio | 0.77%／年（高費率，因使用期貨合約） |
| AUM | ~$352M（相對小，主要用於戰術性配置） |
| 機制 | 持有美元期貨合約（需定期滾轉，存在 roll cost）|
| 交易所 | NYSE Arca |

UUP 是 hedge 組合中**唯一的貨幣工具**，提供對美元走強的直接曝光。在全球不確定性升高時，美元通常受惠於「避險流入」；在通膨驅動 Fed 升息時，美元也因利率差異而走強。

**重要提醒**：UUP 追蹤美元對主要已開發貨幣（非美元）的強弱，主要由歐元/美元（EUR/USD）主導（佔約 57.6%）。

## 3. 美元驅動因素

### 基本面支持美元走強
1. **Fed 升息預期（Warsh 接任）**：美國利率差異（Fed Rate vs ECB/BOJ）支撐美元
2. **戰爭避險需求**：美伊衝突 → 全球避險資金流向美元
3. **通膨驅動緊縮**：油價 $100+ → PCE 上升 → Fed 被迫升息 → 美元走強
4. **就業強勁**：美國經濟相對強勁，美元享有「增長溢價」

### 主要貨幣分配（UUP 追蹤）
- EUR（歐元）：57.6%
- JPY（日圓）：13.6%
- GBP（英鎊）：11.9%
- CAD（加元）：9.1%
- SEK（瑞典克朗）：4.2%
- CHF（瑞士法郎）：3.6%

歐元區面臨能源危機（荷莫茲受阻影響歐洲能源進口）和 ECB 政策滯後，**EUR/USD 下行預期支撐 UUP**。

## 5. 關鍵風險

1. **美元逆轉風險**：若 Fed 政策意外轉鴿（衰退 > 通膨），美元可能急速走弱，UUP 大幅下跌
2. **高費率侵蝕**：0.77% + 滾轉成本，長期持有成本較高（適合戰術性短中期配置）
3. **集中於 EUR/USD**：UUP 報酬主要由歐元/美元決定，非均衡的多貨幣工具
4. **美國財政赤字長期利空**：若美元因財政赤字失去信任，長期走弱
5. **與黃金的負相關**：美元走強 = 黃金走弱，UUP + GLD 同時持有存在**正負對沖，可能降低整體對沖效果**
