## 1. ETF 概覽

| 項目 | 內容 |
|------|------|
| 發行商 | State Street Global Advisors（SPDR） |
| 類型 | 實物黃金支撐 ETF（Physical Gold-Backed） |
| 追蹤標的 | 黃金現貨（每股約代表 0.0932 盎司黃金） |
| Expense Ratio | 0.40%／年 |
| AUM | ~$153.5B（全球最大黃金 ETF） |
| 成立年份 | 2004 年 |
| 交易所 | NYSE Arca |

GLD 是全球規模最大的黃金 ETF，持有實物金條存放於 HSBC 倫敦金庫。投資人買入即間接持有黃金，無須承擔儲存與保管成本。

## 5. 關鍵風險

1. **美元走強**：USD 與黃金呈負相關，近期 UUP 連續上漲，短期壓制 GLD
2. **Fed 升息預期**：實際利率上升提高持黃金機會成本（黃金不配息）
3. **Fed 政策不確定性**：Powell 臨時主席 → Warsh 接任，政策路徑不明
4. **印度需求抑制**：Modi 呼籲停購，印度為全球最大黃金消費國之一
5. **技術面回調**：距 52 週高點 -18%，MA20/MA50 均位於當前價格之上
6. **ETF 折溢價風險**：極端市場條件下可能出現短暫大幅折價（過往危機期曾見）
7. **託管集中風險**：黃金存放 HSBC，存在單一機構風險
