# Aggressive risk view — EQIX

## Where trader is too cautious

1. **50/50 分批導致首日真實曝險僅 NAV 0.75–1%**：對具名 hyperscaler 合約、歷史最大指引提升的標的而言，信念與部位嚴重失配。以「技術面資料缺失」為由壓縮到半倉，是用操作缺陷替代基本面判斷。

2. **等待 Q3 盈利（2026-10-28）是主動放棄 80 天 Alpha**：Project Matterhorn 後續公告預期 2026-08-15，距今僅 7 天。若 xScale 預承諾比率屆時升至 75–80%+，市場將提前重評估值，分批策略反而製造追高成本。

3. **Q3「減速」被 FX 誇大**：報告匯率 9–11% 隱含固定匯率基礎仍達 10–12%，以一次性 FX 拖累製造「不確定性」而壓縮部位，屬過度謹慎。

4. **停損觸發點滯後於市場**：Q3 固定匯率成長 < 9% = 管理層指引下緣。等到該觸發，市場早已定價，等同在最壞情境完全反映後才離場。

## Asymmetry argument

- **最壞情境**（Q3 固定匯率 < 9% 且 hyperscaler 需求軟化）：P/AFFO 從 28x 壓縮至約 21x，隱含約 -25% 跌幅。以 4% NAV 計，最大絕對損失約 **NAV 1.0%**。
- **現實上行情境**（Q3 固定匯率 ≥ 12% + Fed 降息 + Project Matterhorn xScale 里程碑）：P/AFFO 重估至 30x+，隱含約 +30–40% 漲幅。以 4% NAV 計，潛在獲利約 **NAV 1.2–1.6%**。
- **Worst case vs. realistic upside R:R ≈ 1.2–1.6:1**（定性停損框架下已屬保守估計）。加入 Jan 2027 call spread，若 Q3 盈利超預期，非對稱性改善至 3–5:1，而損失封頂於 premium。
