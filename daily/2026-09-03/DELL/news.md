# 新聞——DELL （戴爾科技）截至 2026-09-03

## 公司特定頭條（過去14天）

- **2026-09-01** — DELL公布第二季度財年2027年財務成績，創紀錄營收達$47.0B，年增58%，調整後稀釋EPS為$7.04，年增203%。(BusinessWire / Investing.com)。**影響：極為看漲**。收益遠超華爾街預期（EPS超預期$2.17，營收超預期$2.16B），標誌著AI基礎設施需求的持續強勁動能。

- **2026-09-01** — DELL第二季度AI伺服器訂單達創紀錄$60.9B，退出時積壓達創紀錄$95.0B。(Investing.com)。**影響：極為看漲**。積壓中$95B創紀錄規模表明AI基礎設施採購熱潮持續強勁，能見度高達12-18個月。

- **2026-09-01** — 基礎設施解決方案集團（ISG）第二季度營收達$31.78B，年增89%；傳統伺服器及網路設備營收激增122%至$10.53B。(S&P Global / Investing.com)。**影響：極為看漲**。ISG創紀錄營收且傳統伺服器營收增速加速，表明超大規模資料中心和企業AI支出同時爆發。

- **2026-09-01** — DELL提高全年財年2027年指導，營收預期調升$25B至$192.0B中值（年增約70%），調整後EPS預期為$25.50。(CNBC / MarketBeat)。**影響：看漲**。大幅提升全年指導顯示管理層對AI伺服器需求和交付能力充滿信心，且邊際利潤仍在擴展。

- **2026-09-01** — DELL AI最優化伺服器營收達$16.40B，超過StreetAccount共識預期的$16.07B。(Investing.com)。**影響：看漲**。AI伺服器營收超預期代表高端AI晶片採購力度強於預期。

- **2026-09-09 (預定)** — 執行長Michael Dell和財務長David Kennedy將在高盛科技暨電信年會(Goldman Sachs Communacopia + Technology Conference)演講。(Dell Investor Relations)。**影響：中立**。已知的投資者溝通活動。

- **2026-09-10 (預定)** — 財務長David Kennedy將在花旗2026全球TMT年會(Citi 2026 Global TMT Conference)發言。(Dell Investor Relations)。**影響：中立**。已知的投資者溝通活動。

## 部門宏觀環境

- **2026-08-27** — 美國特朗普政府考慮擴大半導體關稅，可能延伸至伺服器等晶片產品，第二階段關稅可能消除對AI基礎設施的豁免。(CNBC / TechTimes / DCD)。**對IT伺服器產業影響：明顯負面**。若消除2026年1月以來對資料中心晶片的豁免，可能令DELL及其同業的成本結構惡化15-25%，進而壓制邊際利潤並延遲AI支出決策。當前積壓中$95B訂單可能受保護，但未來2026-2027年新訂單定價可能面臨成本透傳壓力。

- **2026-08/09** — HBM（高頻寬記憶體）產能在2026年已全數售罄，SK海力士、三星及美光均拒接新訂單。(Barchart / Semiconductor Industry)。**對資料中心伺服器產業影響：中度負面**。HBM短缺可能制約DELL AI伺服器在高階應用場景的出貨能力，迫使客戶延遲部署或轉向替代架構。

- **2026-全年** — 運算與資料儲存類半導體預計年增41.4%至超過$500B，但成本因供應鏈地域化重組而上升15%。(Utmel / Barchart)。**對伺服器OEM的影響：混合**。市場成長強勁但基礎成本結構上升，利潤承壓。

## 競爭對手動向

- **HPE** — 在與X (Twitter)的$1B AI伺服器交易中擊敗DELL和Supermicro；與DELL共同在NVIDIA GTC 2026推出Vera Rubin AI伺服器平台。(NetworkWorld / Futurum)。**對DELL的影響：中度負面**。HPE正在大型超大規模客戶中贏得交易份額，且推出新一代平台可能分流部分需求。

- **Super Micro Computer (SMC)** — 美國司法部於2026年3月19日起訴三名Supermicro高管涉及非法出口$510M NVIDIA裝備AI伺服器至中國，公司股價單週下跌33%。儘管面臨法律風險，Supermicro仍發佈爆炸性財年2027年指導。(Futurum / Yahoo Finance)。**對DELL的影響：看漲**。Supermicro法律危機可能加速客戶向DELL和HPE轉向，為DELL奪取市場份額創造機會。

## 淨讀評

DELL於2026-09-01公布的Q2財年2027年業績創造多項紀錄——營收$47B年增58%、AI訂單$60.9B、積壓$95.0B——並激進上調全年營收指導至$192B（年增70%）。ISG部門領先增長，伺服器及網路設備營收暴增122%。這些成績反映AI基礎設施超級週期的中期強勁動能。但近期頭條焦點轉向負面風險：(1)美國特朗普政府第二階段關稅計劃可能消除對AI晶片的豁免，威脅2027年以後新訂單的利潤率；(2)HBM產能全數售罄可能制約高階應用出貨；(3)競爭對手HPE在大型交易中贏得份額，Supermicro法律危機雖可能有利DELL奪佔，但該公司仍保持財年指導強勁。近期催化劑聚焦於9月投資者會議（可能闡述關稅對策與邊際利潤前景）與11月Q3財報。**淨頭條傾斜：強烈看漲（短期），帶有2027年成本結構和關稅風險邊際**。強勁的AI訂單動能和積壓為估值提供支撐，但對下半年邊際利潤率的關稅威脅和供應鏈不確定性需密切監控。
