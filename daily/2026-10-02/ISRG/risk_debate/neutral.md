# Neutral risk view — ISRG

> 注：aggressive.md 與 conservative.md 尚未生成，本文依據 investment_plan.md 與 trade_proposal.md 的多空論點推演各方立場，進行中立仲裁。

---

## Points of agreement (both sides)

- Q3 2026 財報（2026-10-20）是當前最關鍵的資訊節點，距今僅 18 天，財報前多空雙方均無決定性新數據可支撐全倉介入。
- ISRG 現價 $402.27 低於 MA200 $448.06（-10.2%），長期下行趨勢未翻轉；在趨勢確認前，任何倉位均應控制規模。
- 47x forward P/E 相對行業中樞 30–35x 屬真實偏高，不論看多看空均無法忽略此安全邊際不足的事實。
- 研究主管裁定 NEUTRAL / 信念 LOW，雙方均認同當前不宜全倉押注未知催化劑。

## Aggressive overreach

- **所在**：激進方認為現行技術面（MACD +2.35、RSI 58、站穩 MA50）與 6:1 的 R:R 結構足以支持 0.5–1% NAV 的正式多頭部位，主張財報前提前佈局吃盡向上跳空。
- **為何過激**：此論點混淆「技術結構良好」與「值得在低信念財報前加倉」這兩件事。Q3 財報結果雙向均不可排除（管理層已下修全年指引一次，再下修機率不低）；財報跳空 gap down 的下行風險可在單日吞噬數倍的事前 R:R。ATR14 $10.78 代表正常日波動即約 2.7%，財報日波動倍增屬常態。以低信念建立正式部位，在催化劑明朗前的「等待成本」換算並不划算。

## Conservative overreach

- **所在**：保守方主張完全現金、財報前零接觸，甚至在技術面若觸及 $395 以下即確認全面放棄試探，且財報後若數字一般（非大幅超預期）仍持續回避。
- **為何過保守**：ISRG 業務基本面並非崩潰情境——Q2 收入 +19% YoY、EPS 連續兩季超預期兩位數、da Vinci 5 放置 246 台創新高。競爭威脅（Hugo/Ottava）為真實存在但早期（市占侵蝕尚未量化）。過度迴避使投資人在財報後即時訊號出現時喪失反應能力，錯失 $400–$410 再入場區間的流動性窗口。「零接觸」的機會成本在牛方情境（+35% 至 $543）下不可忽視。

---

## Balanced adjustment proposal

- **Size**：財報前維持 **0 至最多 0.25% NAV** 的試探性部位（約等值 $250–$500/每 $100K NAV），且僅在以下「雙重確認」條件同時成立時方可介入：(1) 日線收盤突破 $416.51 並帶有過去 10 日均量 1.5 倍以上成交量；(2) 財報前至少保留 5 個交易日緩衝（即不晚於 2026-10-13 建倉）。若條件不觸發，維持零倉位至財報後。
- **Stop**：0.25% NAV 試探倉止損設於 **$395.00**（而非激進方的 MA50 $378.86）。提高止損價格縮短虧損幅度，止損幅度約 -1.8%（相對 $402.27 開倉價），最大損失限制於 0.25% NAV × 1.8% ≈ NAV 的 **0.0045%**，符合低信念紀律。
- **Entry**：$400–$410 為合理再入場區間；僅於突破 $416.51 帶量確認時入場，不在當前猶豫區間追買。
- **Hedge**：若持有 0.25% NAV 試探倉，財報前 5 個交易日買入 **1 張 ISRG Oct 18 $390 Put**（估計權利金 $300–$500），以少量期權對沖財報跳空風險；期權費相當於試探倉的保費，確保下行有界。
- **Time horizon**：財報前試探（若建）以 **2026-10-13** 為建倉截止；2026-10-20 財報後依「上行觸發條件」（EPS 超預期 ≥10%、美國程序增速 ≥14%、da Vinci 5 放置 >260 台）擴倉至正常規模（1–1.5% NAV）；若財報不及預期，立即平倉且啟動 SHORT/AVOID 評估。

## Net $ risk if stop hits

假設 NAV = $100,000：

| 情境 | 計算 |
|------|------|
| 試探倉 0.25% NAV = $250 | |
| 進場假設 $416.51（突破觸發），止損 $395.00 | |
| 損失幅度 = ($416.51 − $395.00) / $416.51 = **-5.2%** | |
| 倉位股數 ≈ $250 / $416.51 ≈ 0.6 股（實際取整 1 股） | |
| **最大股票損失** ≈ **$21.51**（= 約 0.022% NAV） | |
| Put 期權最大損失（若不觸發）≈ $300–$500 | |
| **合計最大風險** ≈ **$320–$520**（= 約 **0.32–0.52% NAV**） | |

若維持零倉位（不觸發條件），淨風險 = **$0**。
