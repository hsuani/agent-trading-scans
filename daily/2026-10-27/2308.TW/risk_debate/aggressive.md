# Aggressive risk view — 2308.TW

## Where trader是too cautious

- 0% sizing 加上「不提供進場價位」等同完全棄權，但基本面是可驗證的強：Q2 營收 YoY +47.8%、營業利益率 17.2%、ROIC 25.8%、淨現金 NT$1,132.4 億。空方論點的核心是「同業倍數武斷套用」與「現金轉換惡化」，並非需求證偽。在這種「基本面強、技術面轉弱、估值貴、二元事件在即」的組合下，完全不動用任何倉位，等於把這個binary event 的全部asymmetry 讓給場外——event-driven 的catalyst 正是最適合用小額、定義風險（defined-risk）工具參與的場景，而不是迴避。
- 轉LONG 的trigger 要求「收盤站回 NT$1,560 並放量收復 NT$1,655」，這代表若財報/法說大利多、股價直接跳空至 1,700+，而中途沒有回測確認，trader 會完全錯過起漲段。等待volume confirmation 在binary event 後的情境下，是殺死 alpha 的設計——財報公告後次日開盤即應依缺口方向行動，而非等待數日確認。

## Recommended adjustments

- Size：0% → 建議以「小額options曝險」取代完全空手，而非直接做多現股（現股0%合理，但曝險工具應保留）。
- Stop：若轉LONG，停損不應只卡在「結構破位 NT$1,560 下方」，應依計畫本身建議的 1.5–2倍ATR（約NT$115–154）設置，避免財報後正常波動就被洗出。
- Entry：財報/法說後次日開盤即依方向confirmed（毛利率數字+Q4 guidance）進場，不必等待多日volume breakout。
- Consider：財報前（10/27 收盤後）以極小倉位買進 NT$1,650/1,750 call spread（11月到期，涵蓋財報+法說），max loss =權利金，捕捉binary event 的上行asymmetry，同時不承擔現股下跌風險。

## Asymmetry argument

若買進call spread，每股最大損失＝權利金（估算NT$20–35/股等級，依現時IV），上檔若財報/法說確認多方情境、股價修復至MA20/50區（NT$1,790–1,800）甚至前高NT$2,005，spread 內在值可達NT$100/股（1,650/1,750價差）。Worst case max loss（權利金）vs realistic upside（接近spread 滿值），ratio 可達 3–5倍，遠優於現股「等確認」策略的1:1～2.5:1 R:R。

## What I'd push for

與其0%完全空手、等待多日確認的保守路徑，我主張財報前以極小倉位（可承受全損、不影響整體部位風險預算）建立NT$1,650/1,750 call spread 捕捉binary event 的上行asymmetry；財報/法說後若毛利率與Q4 guidance 確認偏多，次日開盤即以MEDIUM-HIGH（而非僅MEDIUM）信心直接進場現股多單，停損放寬至1.5–2倍ATR下方而非卡在結構價位，避免財報後正常波動提前洗出，讓部位有機會參與修復至NT$1,790–2,005的空間。
