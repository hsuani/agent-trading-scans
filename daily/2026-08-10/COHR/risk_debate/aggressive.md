# Aggressive risk view — COHR

## 交易員過於保守之處

- **完全忽略財報前選擇權不對稱機會**：零倉位等待固然規避了跳空風險，但同時放棄了以有限 premium 捕捉強勁業績爆發的最有效工具。買入 call spread 可將最大損失鎖死於所付 premium，不暴露於正股的全額跌幅風險，這一不對稱結構恰好為此類二元事件量身定製。

- **「半倉試探」財報後進場過度謹慎**：若 EPS ≥ $1.75 + FY2027 毛利率指引 ≥ 40% 雙重觸發確認，代表整個成長敘事已獲硬數據背書、投機溢價轉化為基本面錨點。此刻半倉是在已確認的 alpha 上踩煞車，應直接升至 75% 全倉部位。

- **未利用 LITE（8/11）作為前哨訊號**：Lumentum 財報提前一日（8/11）公布，若 LITE 再次大幅超預期（上季已年增 58%），即為 COHR 財報前最即時的賽道溫度計，可動態調整 call spread 規模，但交易計劃對此窗口完全沉默。

## 建議調整

- **Size（財報前）**：0% → 組合資金 2–3% 建立 call spread（最大損失封頂於 premium，絕對損失可控）
- **Size（財報後觸發確認）**：半倉 → **75% 倉位**，EPS ≥ $1.75 且毛利率指引 ≥ 40% 雙觸發同時成立方執行
- **Stop（財報後）**：維持財報後反應低點設定，此寬鬆止損合理，無需收緊
- **Entry（財報前）**：等待 → 財報前 24 小時（或 LITE 確認後）建立 call spread
- **考慮槓桿工具**：Call spread $385/$435，到期 2026-08-22（週選）；PRICE_DATA_UNAVAILABLE 下 premium 為估算，建議 8/11 盤中補取實時報價後校正執行

## Asymmetry argument

| 情境 | 結果 |
|------|------|
| Call spread 最大損失（premium 估算） | ~$15/股 → $1,500/百股 |
| 上行情境：股價至 $435（EPS 大幅超預期 + 指引上調） | 獲利 ~$35/股 → $3,500/百股 |
| **Ratio B/A** | **$3,500 / $1,500 ≈ 2.3:1** |
| 下行情境：股價跌至 $310（miss + 獲利了結） | Call spread 損失封頂 premium，不隨正股跌幅 -18% 同步虧損 |

注意：財報前 implied volatility 必然偏高，call spread 比單買 call 更有效壓縮 vega 成本，因賣出上方高 strike 同步出售高溢 premium。

## What I'd push for

財報前以不超過組合 2–3% 建立 $385/$435 call spread，鎖定最大損失於 premium 之內，換取若 EPS ≥ $1.75 + 毛利率指引突破 40% 時的結構性爆發收益；這是唯一能在二元事件中兼顧有限損失與有意義上行參與的工具。財報後若雙重觸發確認，應以 75% 倉位正股跟進，止損設於財報當日反應低點，不應再以「半倉試探」自我設限。8/11 LITE 財報為動態調整窗口：若 LITE 業績強勁，可在 call spread 基礎上適度提升規模。交易員 HOLD 策略的邏輯完整，但在選擇權工具的運用上留下了明顯的 alpha 缺口。
