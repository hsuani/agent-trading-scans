# Bull case round 1 — ARM

## Thesis（1句）
ARM 正同步兌現三重里程碑——Armv9 版稅費率翻倍、資料中心版稅首度超越手機、超大規模雲服務商 CPU 市占達 50%——結構性轉型已具財務驗證，目前 34-39% 回調提供具吸引力的重估進場窗口。

---

## Growth drivers

- **Q1 FY2027 營收年成長 22%，淨利 2.7 億美元超市場預期**（news.md：2026-07-29 財報），展現 AI 資料中心需求對基本面的直接拉動。
- **Armv9 版稅費率 ~5%，約為 Armv8（2.5-3%）之兩倍**（news.md）；Q3 Armv9 版稅創紀錄達 7.37 億美元，年增 27%。Armv9 目前僅佔總版稅約 25%，組合升級空間巨大，每提升 1 個百分點即帶動毛利邊際進一步改善。
- **資料中心版稅收入年翻倍，首度超越智慧型手機成最大業務版塊**（news.md），業務結構從消費電子週期性業務轉向 AI 基礎設施長期穩定收入，系統性降低營收波動。
- **AGI CPU（136 核心，TSMC 3nm N3P，與 Meta 聯合開發）訂單簿已逾 20 億美元**（news.md），商業能見度覆蓋 FY2027 及 FY2028，標誌 ARM 從純授權商正式進入自主晶片收入。
- **Neoverse CSS V3 / N3 獲 16 家以上企業設計贏單**，包含 Amazon、Google、Marvell、NVIDIA（news.md），頭部雲服務商和晶片設計廠同步採用，授權版稅基數持續擴大。
- **超大規模雲服務商 CPU 計算份額達 50%**，Computex 2026 正式宣告（news.md），x86 對資料中心的壟斷地位終結，市場份額扭轉具戰略意義且難以逆轉。

---

## Moat

ARM 護城河由三層相互強化的壁壘構成：

1. **生態系鎖定**：全球 99% 行動端、50% 超大規模 CPU 皆跑在 ARM 指令集；作業系統、EDA 工具鏈、編譯器生態經過數十年積累，客戶遷移至 RISC-V 的隱性成本遠超版稅節省。
2. **版稅定價權**：Armv9 費率相比 Armv8 提升約 2 倍，且客戶在 AI 推理工作負載高度依賴先進架構後議價能力減弱；16+ CSS 設計贏單進一步以客製化服務形成新一層黏著。
3. **知識產權複利效應**：授權模式毛利率 70-74%（fundamentals.md），邊際利潤隨版稅組合升級自動放大，FCF 邊際利潤 20-25%，無製造資本支出拖累，競爭者複製需花費十數年生態建設。

---

## Upside scenario

依 Q1 FY2027 淨利 2.7 億美元推算 FY2027 全年淨利約 11 億美元，攤薄股本約 10.5 億股，估算 FY2027 EPS ~$1.05：

- **Base**：P/E 45× × FY2027 EPS $1.05 = 目標價 $47.25，相較高點 34-39% 回調後，隱含潛在回報 **+40-55%**
- **Bull**：P/E 55× × FY2027 EPS $1.15（AGI CPU 訂單加速確認 + Armv9 組合提升至 35%）= 目標價 $63.25，隱含潛在回報 **+80-100%**
- **EV/EBITDA 交叉驗證**：授權 + 自主晶片混合模式 EBITDA margin 預期升至 60%+；EV/EBITDA 50× 對應 ARM 業務質量（零槓桿、淨現金 2.4B+）屬合理區間（fundamentals.md）

## Rebuttal to bear round 0

本輪為辯論首輪，無前序熊方報告，以下預先反駁核心空方論點：

- 空方主張：「Qualcomm 訴訟敗訴削弱 ARM 版稅定價能力」
  反駁：法院判決範圍僅限縮 ARM 針對被收購公司重新談判授權的能力，並未觸及現行版稅費率結構。Armv9 ~5% 費率持續生效；AGI CPU 自主晶片收入更在版稅之外開闢直接收入流，分散法律風險敞口。

- 空方主張：「P/E 50x+ 估值無法在成長放緩時持撐」
  反駁：$2B+ AGI CPU 訂單簿提供 FY2027-2028 收入能見度；Armv9 版稅組合僅達 25%，若升至 50% 則 EPS 可提升 15-20%，有效 P/E 快速收縮。毛利率 70-74%、FCF/淨利潤比 1.05-1.10×、淨現金 2.4B+（fundamentals.md）均支持授權平台高溢價。

- 空方主張：「RISC-V 開源架構長期侵蝕護城河」
  反駁：16+ CSS 設計贏單、超大規模廠商深度整合 Neoverse 生態、50% 雲端 CPU 市占率均已形成難以解開的路徑依賴。RISC-V 生態工具鏈成熟度與 ARM 差距仍以年計，ARM 早已在競爭壓力存在的環境下完成市占里程碑。

## Confidence

**8 / 10**

三重里程碑（Armv9 費率升級、資料中心超越手機、50% 超大規模市占）均已獲 2026 年財報和行業公告具體驗證，非前瞻預測；Q1 FY2027 淨利超預期確認成長軌跡；AGI CPU $2B+ 訂單提供多年收入能見度。主要不確定性來自：缺乏即時股價數據無法精確計算入場回報（market.md 全數不可用）；Qualcomm 反訴後續與中國市場地緣政治風險尚待解決。整體而言結構性轉型故事完整且有財務驗證支撐，信心充分，但 2 分扣除反映上述未解風險。
