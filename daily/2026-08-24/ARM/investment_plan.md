## 辯論摘要

### 多方最強論點
多方以三項已獲財報驗證的結構性里程碑作為核心：一、Armv9 版稅費率（~5%）較 Armv8（2.5-3%）翻倍，Q3 版稅創紀錄 7.37 億美元（+27% YoY）；二、資料中心版稅年翻倍，首度超越手機成最大業務版塊，業務結構由消費電子週期性收入轉向 AI 基礎設施長期收入；三、超大規模雲服務商 CPU 計算份額達 50%（Computex 2026 正式宣告），標誌 x86 壟斷終結。AGI CPU 逾 20 億美元訂單簿為 FY2027-2028 提供多年收入能見度。毛利率 70-74%、淨現金 2.4B+、FCF/淨利潤比 1.05-1.10×，財務體質支撐高溢價。

### 空方最強論點
空方以三項有據可查的結構性壓力反擊：一、成長降速從 38%（FY2024）降至 22%（Q1 FY2027），PEG 1.4-1.8× 的溢價在繼續降速時失去依據；二、特拉華州法院 Qualcomm 判決確立，ARM 無法在被收購公司基礎上重談授權條款，長期定價增長上限受壓；三、SoftBank 持股 87.1% 構成確定性供給懸頂，機構浮動股僅 5-8%，吸收空間極為有限。內部人淨賣出 8-15M 美元（買賣比 40:60）亦缺乏強烈加碼信號。

---

## 三大核心爭論點（Cruxes）

1. **Armv9 滲透速度**：Armv9 目前僅佔版稅收入約 25%。若三年內升至 50%，EPS 可提升 15-20%，有效 P/E 快速收縮，支撐當前估值；若滲透停滯於 30% 以下，P/E 50-65× 將面臨均值回歸壓力。此項為多空共識最關鍵的分歧點，Q2/Q3 FY2027 財報版稅組合數據可直接驗證。

2. **Qualcomm 判決的實質損害範圍**：判決限制 ARM 於被收購客戶場景重談授權，但現行費率結構（Armv9 ~5%）未受衝擊。爭議在於：隨著半導體業整合加速，此裁定是否會在未來 3-5 年系統性壓低新合約授權費率增長天花板，抑或僅影響邊際案例。Qualcomm 第二輪違約訴訟（預計 2026 年 3 月開庭）結果為關鍵觀察事件。

3. **AGI CPU 商業模式矛盾**：ARM 進入自主晶片業務直接與 AWS Graviton、Microsoft Cobalt 等核心授權客戶形成競爭關係。若大型雲服務商因此縮減 CSS 採購或加速自研，版稅基數受損將超過 AGI CPU 帶來的直接收入。若雲服務商維持「授權 + CSS + 部分自研」多層策略，ARMコ模式成功多元化。FY2027 CSS 設計贏單兌現率是可追蹤指標。

## 裁決：誰的論據更紮實？

**多方在證據質量上略勝一籌**，但空方的結構性憂慮不可忽視。

多方引用的三重里程碑（Armv9 版稅創紀錄、資料中心超越手機、50% 超大規模市占）均為 2026 年財報與行業公告的具體、可偽證、有時間戳的事實，而非前瞻預測。Q1 FY2027 淨利 2.7 億美元超預期、BofA 分析師積極報告後單日 +4%，進一步確認市場仍認可成長動能。空方的 RISC-V 替代威脅在 2-3 年內量化困難，AGI CPU 客戶衝突目前仍屬推斷而非財報數據。

然而空方兩項論點具備確定性：Qualcomm 判決為司法事實，SoftBank 87.1% 持股為公開資料。這兩項風險並非靠成長超預期就能抵銷，它們是結構性壓力。成長降速從 38% 至 22% 亦是已確認的軌跡，而非假設。

綜合評估：多方有財務與市占里程碑佐證的長期複利故事，空方有真實存在的估值壓力與供給懸頂。在 34-39% 回調後，風險報酬比已由不利轉向中性偏多，但尚未充分吸引高信念加碼。

## 淨裁決（Net Verdict）

ARM 正在執行一個真實的結構性轉型——從消費電子版稅商轉型為 AI 基礎設施核心授權平台，且里程碑均有財報數據支撐。然而，P/E 50-65× 的估值在成長降速環境下存在均值回歸壓力，Qualcomm 判決與 SoftBank 懸頂為兩個難以靠業績超預期完全解決的結構性阻力。34-39% 的回調已部分消化悲觀情緒，Armv9 版稅升級週期（目前僅 25%，遠未飽和）是最具說服力的長期 EPS 增益引擎。在無法取得即時價格數據評估技術面的情況下，整體裁決傾向 LONG，但信念強度維持 MEDIUM：基本面支持方向，但估值與供給結構的不確定性阻止升至 HIGH。Armv9 滲透速度與 Q2 FY2027 財報是最接近的驗證點。
