# Investment plan — AMZN as of 2026-08-24

## 直向立場
LONG — conviction MEDIUM

## 辯論核心分歧點（Crux）
1. **CapEx 是需求牽引還是資本效率危機**：2025 年 CapEx 暴增至 $131.8B（+58.8% YoY），2026 指引再上修至 $220B，FCF/NI 崩跌至 0.099。多方稱管理層明言 2027-2028 產能「已被預訂滿」是需求驗證；空方指出「訂閱滿」只證明需求存在，不等於邊際 ROIC 足夠覆蓋資金成本，此假設需 2-3 年才能證偽或證實——目前雙方都拿不出已實現的邊際報酬數據，是真正未解的事實缺口。
2. **AWS 成長是否可持續於 30%+**：Q2 2026 AWS 年增 37%（18 季最快），2027 展望 $222B；但空方引用市場預期整體 AWS 增速放緩至 15-20%（Azure、GCP 追趕）。10/29 Q3 財報的 AWS 增速與 CapEx 指引是否見頂，將是可驗證的關鍵數據點。
3. **367x P/FCF 是否已把「CapEx 軟著陸」完全定價**：若 Q3 未釋出 CapEx 回落訊號，估值安全邊際幾乎不存在（bear 下檔情境 -20.7% 至 -38.2%）；若確認回落，bull 上檔情境（+13% 至 +41%）才成立。

## 多方站得住腳之處
- AWS 加速非放緩為已實現硬數據（37% YoY，非預測），且連續四季 EPS 正驚喜（Q1 +68.2%、Q2 +217.7%）。
- 尾隨 P/E 20.8x 低於歷史區間（25-35x）與同業中位數，估值並非全面泡沫化，僅 P/FCF 一項指標極端。
- 資產負債表穩健（債務/股本 37.2%、利息覆蓋 43.8x），有財務彈性支撐加碼投資而不觸及償付風險。
- 三引擎（AWS + Ads + 零售）交叉護城河與物流自動化（Tetromino、機器人倉儲）具體且有日期可驗證的落地進度。

## 空方站得住腳之處
- FCF/NI 0.099、FCF 利率 1.07% 是可驗證、已發生的硬數據，非推測；且股東回報（股利、回購）已停擺三年以上。
- CapEx 指引方向持續上修（$200B → $220B），未見「見頂」訊號，與多方「軟著陸」敘事矛盾。
- 內部人一致性淨賣出（貝佐斯、Jassy、Garman 全數賣出、零買入，6 個月 $365M）在估值高點值得留意，即便個別解釋為稅務規劃。
- 技術面短期轉弱：MACD 直方圖負值擴大、10 日 8 天收黑、量縮整理，缺乏承接動能；分析師與零售情緒過度一致樂觀（60 位 0 賣出、StockTwits 83/100）本身可能是逆向警訊。
- 關稅（13%）與消費者購買力萎縮對零售毛利的壓力屬中期真實風險，雖可被 AWS/Ads 稀釋但非零。

## 淨判決
基本面顯示 Amazon 處於典型的高成長企業「投資轉獲利延遲」階段：營收、毛利率、ROIC 均創高，AWS 動能明確加速且經 Q2 財報實證，但現金轉換效率的惡化程度（FCF/NI 僅 0.099）與估值極端（P/FCF 367x）代表市場已預先定價一個尚未證實的樂觀情境。技術面短期呈量縮箱體整理、動能轉弱，與情緒面過度一致樂觀形成對比，顯示這是「故事夠好但時機未到」的局面。鑑於多方論點有更多結構性、已實現的成長證據支撐，且尾隨估值倍數（P/E）本身並不誇張，傾向偏多，但 CapEx 效率的核心疑慮要到 10/29 Q3 財報才能驗證，故不給高信心。

## 什麼會改變判決
- **上檔觸發**：Q3 財報（2026-10-29）釋出 CapEx 指引見頂或回落訊號（如降至 $180-200B 區間），或 FCF 利率回升至 3%+。
- **下檔觸發**：CapEx 指引再度上修且 AWS 增速降至 25% 以下，或股價失守 $258 箱體下緣、進而測試 $226 支撐。
- **關鍵監控數據**：FCF/淨收入比率、AWS 同比增速、10/29 財報 CapEx 指引方向、內部人是否出現首次買入訊號。

## 部位規模建議（僅為定性參考，非投資建議）
中等信心度做多 → 建議中等偏保守部位，保留加碼彈性；宜等待 10/29 財報 CapEx 指引確認後再考慮加碼至更高部位，而非現階段一次全額建倉。
