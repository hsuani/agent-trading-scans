# Bull case round 1 — AMZN

## Thesis（1句話）
AWS 雲端成長重新加速至18季度新高、AI基礎設施護城河被 Anthropic $100B 十年承諾量化錨定、廣告與電商作為第二與第三支柱協同提速，AMZN 具備向分析師一致目標 $326（+39%）乃至牛市目標 $400（+71%）推進的多重催化劑。

---

## Growth drivers（成長驅動力）

- **AWS 重新加速，非線性突破**：Q2 2026 AWS 營收 $42.2B，YoY +36.7%，為18季度以來最快成長，大幅超越市場預期 31%。年化達 $169B，並非成熟業務的線性外插，而是AI工作負載需求爆發的結構性重啟。AWS 合約負債達 $496B 且三位數成長，代表未來數年確定性收入可見度極高。

- **AI/晶片業務年化 $25B+ 且快速爬坡**：Amazon Bedrock 平台支出 QoQ 年增 170%，AI 及晶片業務合計已突破 $25B 年化速率，成為 AWS 增量成長的加速器，且尚未包含 Anthropic 合作帶來的外溢效益。

- **Anthropic 合作形成 $100B 長期護城河**：Amazon 追加 $5B 投資並持有 $20B 選擇權；更關鍵的是 Anthropic 承諾10年採購 Trainium 晶片（5GW）並將 $100B 算力消費指定在 AWS 平台。Anthropic 自身年化收入已超 $30B，此一排他性夥伴關係直接強化 AWS 的客戶壁壘與模型選擇差異化（Bedrock 多模型策略 vs. Azure 單押 OpenAI）。

- **廣告業務：被低估的高利潤引擎**：TTM 廣告營收超 $70B，YoY +26%；Q2 單季即達 $19.8B（較 Q1 $17.2B 環比再加速）。AI Creative Agent 工具全球推廣，配合 Alexa for Shopping 350M+ 用戶基礎（Q2 互動量 YoY +5倍），廣告貨幣化週期仍在早期。

- **整體營收規模與利潤率雙升**：Q2 合併營收 $200.6B（+20% YoY），營業收入 $27.5B（+43% YoY），AWS 營業利潤率擴張至 39%（YoY +650 bps），展示規模效應正在顯現。

---

## Moat（護城河）

AMZN 擁有三層相互強化的護城河：

1. **雲端規模壁壘**：AWS 以 28% 市佔（Azure 21%、Google 14%）維持領先，每一美元 CapEx（2026年指引 $220B）皆在擴大數據中心容量與區域覆蓋，後進者複製成本高達數年時間與數千億美元。

2. **AI 生態系統黏性**：Bedrock 支援多元基礎模型（含 Anthropic Claude），企業客戶一旦建立訓練流程與推論基礎設施，遷移成本極高。Amazon 自研 Trainium 晶片降低對 NVIDIA 的依賴，Anthropic 的 5GW 承諾進一步鎖定晶片-雲端垂直整合優勢。

3. **電商飛輪與廣告定價權**：超 3 億買家的購物意圖資料讓亞馬遜廣告的 ROI 對品牌主具有無可替代的精準性，Prime 會員黏性創造持續的零售貨架貨幣化機會。

## Rebuttal to bear round 0

（本輪為 Round 1，無前輪熊方論點需反駁；下方預先構建對常見空方論點的反擊）

- 熊方常見論點：「CapEx $220B 侵蝕 FCF」
  **反駁**：AWS 合約負債 $496B（三位數成長）代表此一支出有確定性收入對應；AWS 利潤率已達 39%（+650 bps YoY），資本密集轉化為利潤率而非消耗。歷史上 AWS 每一輪 CapEx 加碼均在 2-3 年後驅動利潤率躍升，2026 年的 $220B 正是 2028-2029 FCF 的播種。

- 熊方常見論點：「內部人士全員賣出 $459M，無人買入」
  **反駁**：此行為在科技大型股管理層多為預設計劃性套現（10b5-1計劃），Bezos 本人歷年按計劃持續減持，並未影響公司基本面。機構被動式買入量遠大於內部人賣出規模，供需結構仍偏多。

- 熊方常見論點：「FTC 反壟斷風險 2027 年開庭」
  **反駁**：FTC 廣告調查截至目前最大和解案僅 $2.25M，2027 年庭審仍早，且 AWS 與廣告業務具有高度競爭性替代品（即使分拆，各部門均可獨立估值且加總高於現市值），監管風險已被市場部分定價。

- 熊方常見論點：「Google Cloud 成長更快，AWS 失去份額」
  **反駁**：AWS Q2 成長 36.7% > Google Cloud 27.96%，市佔 28% vs. Google 14%，絕對規模優勢使 AWS 每增加一個百分點的成長率創造的新增收入約為 Google Cloud 的兩倍。Bedrock 多模型策略優於 Azure 單押 OpenAI，企業客戶偏好模型多樣性。
