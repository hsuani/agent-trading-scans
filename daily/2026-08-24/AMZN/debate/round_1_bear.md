# Bear case round 1 — AMZN

## Thesis（一句話）
AMZN 以 $2.79T 市值定價在近乎完美執行的基礎上，但 $220B CapEx 造成 FCF 急劇收縮、Q2 EPS 大幅虛增於 Anthropic 一次性收益、共識擁擠至歷史極端，任何 AWS 成長放緩或 AI 投資回報落空皆可觸發 30-45% 的估值壓縮。

---

## Demand / market risks（需求與市場風險）

**零售端蠶食加速**
TikTok Shop、Temu、Shein 以病毒式社群商務正面衝擊 Amazon Marketplace。美國社群商務規模 2026 年已突破 $100B（電商佔比 7.2%），且增速遠高於亞馬遜核心搜尋型購物。亞馬遜的廣告飛輪仰賴搜尋意圖流量，一旦發現型購物（discovery commerce）崛起，廣告單價與點擊率雙雙承壓。

**退貨率侵蝕邊際利潤**
2026 年電商退貨率 20.4-24.5%，退貨詐騙率 15.1%。隨著 Amazon 擴展藥局、Prime Air、無人機等複雜品類，單次配送成本上升，退貨成本比率的改善速度將滯後於 CapEx 投入。

**Q3 營收序列下滑**
Q3 指引 $197-202B，低於 Q2 $200.6B。公司解釋為 Prime Day 時間移位，但序列衰退在公司聲稱「全速前進」的敘事中顯得突兀，若市場重新定價成長溢價，即成催化劑。

---

## Margin / cashflow risks（利潤與現金流風險）

**CapEx $220B 令 FCF 深度負值**
亞馬遜 TTM 營業現金流估計 $100-120B。CapEx 上調至 $220B 後，FCF = **負 $100B 至 $120B**。公司以「成長型資本支出」框架敘述此數字，但若 AI 基礎建設的貨幣化時程延後 1-2 年，巨額 D&A（折舊攤銷）將壓低未來會計利潤，並需新增融資——稀釋風險隨之上升。

**Q2 EPS 嚴重失真**
Q2 EPS $5.75（遠超預估 $1.81），但其中包含 Anthropic 持股的 **$53.4B 稅前非營業收益**。按 10.8B 流通股估算，非營業部分每股貢獻約 **$4.94**，實際營運 EPS 僅 $0.81。市場若以「$5.75」作為正常化基礎推算 PE，將系統性低估真實倍數。

**Trainium 業務年化 $20B，但尚未驗證外部客戶黏性**
晶片業務訂單承諾 $225B+，幾乎全來自 Anthropic（亞馬遜本身已投入 $5B+ 累計）。此為關聯方交易，外部市場第三方接受度未充分驗證，承諾可撤銷且依賴 Anthropic 高速成長。

## Competitive / regulatory（競爭與監管）

**Azure + OpenAI 在企業 AI 工作負載的整合優勢**
Microsoft 將 OpenAI 深度嵌入 Azure Copilot 生態，企業採購已形成 Microsoft 365 + Azure 捆綁慣性。AWS 靠 Anthropic 補強，但 Anthropic 模型同時在 GCP 與 Azure 上提供，AWS 排他性並不存在。若 AWS 成長從 36.7% 滑落至 20-25%，市場對 AWS 的估值倍數將大幅重評。

**DOJ / FTC 反壟斷訴訟**
FTC 針對 Amazon Marketplace 的反壟斷調查持續，DOJ 亦關注 AWS 在聯邦政府市場的獨佔地位。若法院裁定需拆分 AWS 或限制 Marketplace 條款，整個商業模式的協同效應即瓦解。此為尾部風險，市場共識幾乎未定價。

**TikTok Shop / 社群商務**
廣告業務 $70B TTM 以購物意圖搜尋為核心。發現型社群商務平台繞過亞馬遜搜尋直接完成交易，廣告主預算轉移將侵蝕廣告 ROAS，進而壓低廣告單價。2026 年分析師尚未充分量化此轉移的量級。

## Tactical（技術面）

- 股價在 Q2 財報後（2026-07-30）由 $220 區間急拉至 **$259-278**，單月升幅逾 18%，幅度擴張明顯
- Amazon Stores CEO Herrington 於 $278.39（2026-08-03）賣出，顯示高管認為當前價位為合理套現點
- 技術指標（無完整數據，依價格行為推斷）：上升後 RSI 可能超過 70，進入超買區；若市場廣度惡化，首個關鍵支撐回落至 **$240**，破則下測 **$210-215**（上升缺口回補）
- 分配型量價結構：機構 13F 追蹤樣本 21 檔基金減持 vs. 20 檔增持，分化訊號出現於高位

## Rebuttal to bull round 0

本輪為 Round 1，無前置 Bull 輪可反駁。以下針對市場主流多頭論點進行反駁：

- 多頭主張：「AWS Q2 成長 36.7%，創 18 季新高，確立 AI 超級週期」
  反駁：AWS 成長加速的部分原因是 Anthropic 本身消耗大量 AWS 算力（關聯方需求），扣除後的第三方有機成長率被高估。此外 Azure 在歐洲與亞太金融業的滲透率正快速上升，AWS 市佔率保衛戰的行銷成本尚未完整反映在財報中。

- 多頭主張：「Q2 EPS $5.75 大幅超越預期，驗證盈利能力」
  反駁：剔除 Anthropic $53.4B 一次性稅前收益，Q2 營運 EPS 僅約 $0.81。若以此為基礎正常化，市場實際支付超過 80× 營運盈利，而 $220B CapEx 意味著 D&A 在 3-5 年內大幅上升，壓縮未來正常化 EPS。

- 多頭主張：「57 BUY 評級、0 SELL，反映基本面強健」
  反駁：此為反向訊號。95% 買入共識意味著潛在買家幾乎已全部進場，邊際買盤耗盡；同時任何基本面意外——無論是 AWS 成長放緩、CapEx 超支或監管裁決——都將面對零空頭保護的自由落體式下跌。歷史上，0% 賣出評級往往出現在頂部附近（如 2021 年 Meta、2022 年 Netflix 崩跌前）。

- 多頭主張：「Trainium 訂單承諾 $225B+，年化 $20B，確立晶片業務護城河」
  反駁：$225B 承諾幾乎完全來自 Anthropic，而 Anthropic 本身由亞馬遜主導投資。這是亞馬遜對自己生態系統的循環承諾，而非市場第三方對 Trainium 優越性的獨立驗證。一旦 Anthropic 的 LLM 市佔率受 OpenAI / Google 壓縮，承諾量將縮水。

## Confidence（信心度）

**信心度：7 / 10**

**理由**：
亞馬遜的基本面確實強健，AWS 成長加速、廣告業務持續高增長，且機器人自動化長期降低零售成本。然而，**估值已將大量正面情境提前定價**；$220B CapEx 造成 FCF 深度負值這一事實是有據可查的現金流壓力；Q2 EPS 的高度失真為可驗證的會計問題；95% 買入共識的歷史上是市場過熱的可靠訊號。主要不確定性在於：若 AI 算力需求持續爆炸式增長，$220B CapEx 本身即成護城河，令空頭論點短期失效。故評分 7 而非 9。
