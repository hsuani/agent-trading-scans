## Consensus top pick

**6669.TW（緯穎）**

規模最大、動能最強的族群龍頭。8 月單月營收 NT$1,443.12 億（YoY +50.36%），為本族群絕對量體最高；Amazon 德州機架合作由 WSJ 2026-09-09 帶日期確認，是本周最具時效性的正面催化劑。液冷切換成本（6-18 個月客戶重新認證週期）形成技術護城河，分析師 17-19 Buy / 0 Sell 展現基本面共識。唯一限制因素：EPS 出現首次負向意外 -5.35%，且技術面與估值因代理封鎖無法驗證，故 Conviction 自 HIGH 下修至 65% / M。倉位 1.25% NAV，取得即時報價後方可執行。

## Contrarian pick

**2376.TW（技嘉）**

族群內估值最低（forward P/E 11.7×），對應 EPS YoY +93%，幾乎沒有任何成長溢價。市場因其主機板供應商定位與 10.63% 的低毛利率而給予折價，Morgan Stanley 更已降評。然而 NVIDIA 官方新聞稿（2026-06-01）正式列名技嘉為 Vera Rubin CPU 系統製造商，並對接 CoreWeave、Azure、Google Cloud、Oracle，角色已從零組件廠升級為系統整合商，市場尚未完全重新定價。9 月 15 日美台協議生效（對美關稅 20%→15%）是明確時間點的近期催化劑，提供入場節奏錨點。R:R to T1 = 1.8，為族群內唯一可計算且超過 1.5 的標的，具備不對稱報酬潛力。

## 族群共同觀察

**共同催化劑**
- Hyperscaler CapEx：Meta、Microsoft、Amazon Q3 財報（10 月中旬）將是全族群最重要的同步事件窗口
- 月營收公告：每月 10 日前後，四檔標的同步揭露，為最高頻率的論點檢驗點
- 9 月 15 日美台貿易協議生效：直接降低對美出貨成本，利好在美有製造佈局的 6669.TW、3231.TW 與 2376.TW

**共同風險**
- NVIDIA 平台集中度：四標的業務均高度依賴 NVIDIA GPU 供應鏈，任何出貨延遲或平台切換（客製 ASIC 崛起）將同步衝擊
- ODM 毛利率天花板：結構性毛利率上限（5–12%）加上年度降價條款（APC），任何成本通膨均難以轉嫁
- 分析師過度一致：6669.TW（17-19 Buy / 0 Sell）、3231.TW（17/17 Buy / 0 Sell）、2376.TW（7/7 Buy / 0 Sell），極端共識代表錯誤定價空間多在下方，負面驚喜的殺傷力被不對稱放大

**籌碼擁擠警示**：6669.TW 與 3231.TW 的分析師共識幾乎相同，機構持倉方向高度一致，若同步出現任何 CapEx 下修措辭，退場動能將形成連鎖共振，單日流動性可能不足以容納全族群同步賣壓。

**相關性叢集**：6669.TW 與 3231.TW 同為超大規模雲端 ODM 龍頭，客戶重疊（Hyperscaler 三大），月營收週期與毛利率結構高度相似，兩者報酬相關性預計最高（r > 0.80），不宜同時持有最大倉位。2376.TW 因客戶結構含 CoreWeave / Azure / Oracle（企業混合），相關性略低。2356.TW 因中國客戶依賴，與其他三檔的相關性在地緣政治事件時可能逆向分化。
