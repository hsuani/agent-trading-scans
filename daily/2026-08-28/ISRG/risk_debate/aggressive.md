# Aggressive risk view — ISRG

##交易員過度保守之處
- **等 MA50 站穩才進場 = 用更貴的價格買同一支股票**。交易員的做多觸發是 $384-396，但今天收盤價是 $371.18——等「確認」的代價是至少多付 3.5-6.7%，alpha 已經在等待中流失。技術面落後（lagging）指標本質上就是要犧牲進場價換取心安。
- **AVOID 的理由建立在舊資訊上，不是新資訊**：內部人零買進、成長指引降速，這些在 sentiment/news 中已存在數週，股價已從高點回落 38.5%，市場大概率已消化。等待「訊號收斂」等於等一個已經反映在價格裡的事實被重新確認，而非真正降低不確定性。
- **內部人賣出被賦予過高權重**：對 ISRG 這種市值等級的高管，例行性 10b5-1 分散持股計畫賣股是常態，不必然是опportunistic 空頭訊號，卻被研究經理列為「唯一具體訊號」而拉低整體信心至中性。
- **硬數據（FCF 裕度 24.7%、淨現金 34.1 億、毛利率逆勢上修至 68-69%）本應獲得比技術面雜訊更高權重**，但目前判斷把兩者對沖成平手，低估了資產負債表品質這種「跌不破」的下檔保護。

## 建議調整
- **Size**：觀望/等待 → 建立起始倉位（standard size 的 1/3），現價 $371.18 附近分批進場，Q3 財報（10/20）驗證後視結果加碼至標準或以上。
- **Stop**：不要設在 $371.18（等於零緩衝、開盤就會被洗掉）；改設在 52 週低點下方 $325（低於 $328.57 支撐），給股價足夠空間撐到財報。
- **Entry**：現在進場，不等 MA50 $384 站穩再追。
- **Consider**：買進 2026-11 到期（財報後）call spread，履約價 $400/$440，鎖定財報成長指引優於預期的催化劑，同時把下檔風險限制在權利金成本，不需承擔股票倉位的全額波動。

## 不對稱論證（以 100 股起始倉位為例，現價 $371.18）
- **Worst case（跌破 52 週低點 $328.57）**：損失 $371.18 - $325 = $46.18／股 → 100 股約 $4,618 最大虧損。
- **Realistic upside（財報後收復第一階阻力 $443.84）**：獲利 $443.84 - $371.18 = $72.66／股 → 約 $7,266。
- **樂觀情境（分析師目標區間 $508-582 中值 $545）**：獲利約 $173.82／股 → 約 $17,382。
- **Ratio**：B/A 於保守目標 ≈ 7,266 / 4,618 ≈ 1.57:1；於分析師目標 ≈ 17,382 / 4,618 ≈ 3.76:1。考慮到淨現金護體、毛利率上修屬落地事實，下檔被基本面部分托住，此不對稱值得承擔。
