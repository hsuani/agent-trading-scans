# Bear case round 1 — OKTA

## Thesis (1 sentence)
OKTA 財報超預期後單日暴漲 27.6% 已透支未來多年的樂觀假設，在 P/E 125×、ROE 僅 3.7%、營收增速連續三年遞減、且 CEO/CFO/法務長於股價上升周期全程系統性拋售的背景下，現價 $172.91 是一個技術面極度超買、基本面估值與獲利品質脫節的做空／避開機會。

## 需求 / 市場風險
營收 YoY 增速三年連降：FY24 21.8% → FY25 15.3% → FY26 11.8%，成長曲線已明顯平化，逼近成熟軟體公司區間。身份管理已成主流採購類目，Microsoft Entra、Amazon IAM 等巨頭以平台捆綁方式競爭，OKTA 無獨家技術壁壘；fundamentals.md 明確列出「客戶集中度無公開披露」為紅旗，大客戶流失風險無法評估。AI Agent 產品線（Okta for AI Agents、Permiso 收購）雖是新敘事，但至今僅是「新增長向量」而非已驗證的營收貢獻，市場已提前為其定價。

## 利潤率 / 現金流風險
FY26 有效稅率僅 7.9%，遠低於 21% 法定稅率，主要靠歷史虧損抵減與稅務規畫支撐淨利，稅率正常化將直接壓抑淨收入成長，這部分獲利品質是不可持續的會計順風而非營運改善。ROE 僅 3.7%，遠低於優質科技股 10-15% 水準，反映稀釋股本（FY23 158M → FY26 179.3M，+13.5%）拖累每股價值創造。營業利潤率雖轉正至 5.2%，但仍遠低於行業中位數 8-15%，獲利轉折的「故事」尚未完全兌現到絕對水準。

## 估值風險
- Bear：P/E 35×（SaaS 產業中位數）× FY27E EPS $1.50（假設 +15% YoY，較 FY26 $1.31 溫和成長）= **$52.5**，較現價 -69.6%
- Worst：技術面若跌破 $129.02 一級支撐，向 GuruFocus 財報前內在價值估算 $104.56（隱含現價高估 39.5%）修正，並進一步測試 $107 二級支撐，implied **-38% 至 -45%**

即便不做極端假設，sentiment.md 揭露的分析師平均目標價 $146.34 也是財報前設定、尚未消化 27.6% 單日暴漲，對照現價 $172.91 已隱含 **-15.4%** 落差；highest target $180 距現價僅 4.1% 空間，risk/reward 明顯不對稱。EV/EBITDA ~59x、P/S 10.4x、trailing P/E 125x 三項指標同步處於歷史與同業高位，任何一季 miss 或 guidance 保守化都足以觸發多重估值收斂。

## 競爭 / 監管
身份管理賽道擁擠，Microsoft、Amazon 等巨頭以平台捆綁定價侵蝕獨立廠商議價權。PANW 收購傳言（2024-2025 談判，估價分歧 $13.5B vs 市值 ~$23B）為舊聞重炒，屬投機性催化劑而非確定事件，若市場過度定價此想像空間，一旦傳言未兌現將引發失望性拋售。CISA 新規雖利好身份/威脅偵測需求，但同時利好 CrowdStrike、Zscaler、SentinelOne 等競爭對手，非 OKTA 獨享。

## 技術面（Tactical）
關鍵破位價位 $129.02（7/28 低點）；跌破後下一站 $107.00（6/18 低點）。RSI14 達 70.39 進入超買，BB %B 1.25 已突破上軌顯示價格延伸過度；20 日年化波動率高達 111.6%，ATR14 $9.30 意味著日內振幅極寬，適合空頭以窄停損試探。6 個月動能 +130%、3 個月 +82.5% 屬拋物線式上漲，歷史上此類單日財報跳空（+27.6%）後常見「賣消息」（sell-the-news）獲利了結賣壓，尤其在機構持股高達 97.97% 的情況下，一旦風向轉變流動性可能迅速收緊。

## Rebuttal（回應市場共識多頭敘事）
本輪尚無 bull round 0 檔案可直接反駁，但 sentiment.md 揭示的市場共識論點值得預先拆解：
- 多頭論點：「35 位分析師買入、8 家投行財報後同步升評至 $180，AI Agent 身份管理龍頭地位確立。」
  反駁：升評普遍發生於 27.6% 暴漲之後，帶有追高性質；平均目標價 $146.34 實際上仍低於現價，顯示分析師模型尚未完全消化此漲幅的合理性，升評本身可能是滯後反應而非前瞻判斷。
- 多頭論點：「內部人淨買入 322,674 股（85.1% 買入占比），機構如 Fidelity 大幅增持 43.5%，資金流向正面。」
  反駁：淨買入數字主要由基層員工股票授予構成，CEO、CFO、法務長三位最高層在整個股價上升周期（$87→$172）從未實質買入，僅執行 10b5-1 計畫持續拋售逾 $12M，高層與基層信號方向相反，應以高層行為權重更高。

## Confidence
6/10。基本面轉盈與現金流品質（FCF 率 29.6%、淨現金 $442M）確實紮實，做空純基本面理由不足；但估值倍數（P/E 125x）、單日暴漲後的技術超買（RSI 70+、BB %B 1.25）、以及高管系統性拋售三者疊加，構成足夠有力的「避開新倉／逢高減碼」論據，短期回檔機率高於繼續線性延伸機率。

BEAR ROUND 1 COMPLETE
