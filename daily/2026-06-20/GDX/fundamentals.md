# GDX (VanEck Gold Miners ETF) 基金分析 — 2026-06-20

## 執行摘要

GDX 是追蹤全球黃金及白銀礦企指數的被動型 ETF，持有頭部礦企如紐蒙特(Newmont)、阿格尼科(Agnico Eagle)、巴瑞克(Barrick)等。基金規模 271 億美元，年度費用率 0.51%，在大宗商品週期驅動下，過去12個月報酬率達 58.94%，但近期受到金價回檔影響，3個月負報酬 -22.83%。基金與實體金 ETF(GLD) 的相對強度(GDX/GLD 比率 0.213)反映市場對採礦成本與營運槓桿的定價。在金價、美元走勢、採礦成本等巨觀因素共同作用下，基金已從高點(52週最高 $117.18)回落，目前估值吸引力適中。

## 巨觀驅動因素 (Macro Drivers)

GDX 的表現取決於以下核心巨觀變數：

### 1. 黃金現貨價格 (Gold Spot Price) — PRIMARY
| 因素 | 影響 | 當前狀況 |
|---|---|---|
| **金價上漲** | GDX 上升，幅度通常大於實體金(槓桿) | 2025年全年上漲，2026年初回檔 |
| **金價下跌** | GDX 下跌，幅度通常大於實體金 | 近3個月金價疲軟，導致 GDX -22.83% |
| **長期名義利率** | 利率上升 → 金價下跌 → GDX 承壓 | Fed 政策為主要監測點 |
| **地緣政治溢價** | 風險資產規避時，金價上升 | 2026上半年全球局勢相對穩定 |
| **美元強弱** | 美元升值 → 金價下跌(以美元計價) | USD 指數 vs 金價負相關 |

### 2. 採礦營運成本 (Mining OpEx) — SECONDARY
| 成本項目 | 影響 | 當前狀況 |
|---|---|---|
| **能源成本** | 油價上升 → 礦企邊際利潤受壓 | 需監測全球能源市場 |
| **勞動成本通膨** | 工資上升 → 營運利潤下降 | 全球薪資漲勢持續 |
| **採礦權稅率** | 稅率上升 → 礦企淨利潤下降 | 部分國家(澳洲、加拿大)可能提高資源稅 |
| **環境法規** | 更嚴格的 ESG → 成本上升 | 先進國家趨勢 |

**邊際利潤槓桿**: 
- 當金價 > 採礦成本時，邊際利潤寬闊，GDX 上升幅度最大
- 目前金價約 $2,200/oz，全球平均採礦成本 $1,100-1,300/oz，利潤空間仍充足，但邊際正在縮小

### 3. 採礦資本支出週期 (Mining Capex Cycle)
| 階段 | 特性 | 對 GDX 影響 |
|---|---|---|
| **擴張期** | 礦企投入大規模勘探、建設 | 短期利潤受壓，長期產能提升 |
| **成熟期** | 產能穩定，現金流充足 | GDX 受惠，高股息/回購 |
| **衰退期** | 礦藏枯竭，關閉礦場 | 利潤下行風險 |

**當前週期**: 主要礦企(Newmont、Agnico)正處於中等擴張期，新礦場陸續投產(預期2026-2028年產能釋放)

### 4. 匯率(特別是美元指數)
| 效應 | 說明 |
|---|---|
| 美元升值 → 金價下跌(美元計價) → GDX 下跌 | 負相關 |
| 美元貶值 → 金價上升 → GDX 上升 | 正相關 |

**當前**: 美元相對穩定，不是近期金價回檔的主因
