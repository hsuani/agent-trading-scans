# Aggressive risk view — VRT

## Where trader is too cautious

- **倉位過小**：Medium 信心對應 1.5% NAV、且只先建半倉 0.75%，面對 $15B 積壓訂單（相當於 FY2025 全年營收 1.47 倍）、FCF 利潤率 18.48%、連續四季平均超越共識 14.65%，起手倉位嚴重不足。這類執行紀錄扎實、能見度高的成長股，保守初倉是在用低信心框架對待高確信基本面。

- **進場時機太晚**：財報日（2026-07-29）當天等待「兩項條件同時達標」才進場，等同於承認把最有利的進場點讓給已持倉者。VRT 過去四季超預期幅度均值 14.65%，今日 Q2 EPS 共識 $1.43 實際上是已被壓低的錨點。等確認打開後追進，代表用更高的價格買進，Alpha 被消耗在等待決策中。

- **止損框架太概念化**：以 35x Forward P/E 壓縮至 $200 作為下行錨點雖合理，但若止損設在這裡則跌幅達 -28%，倉位在不利情境下承受的波動過大；更應以 40x P/E（約 $229）作為執行止損線，讓倉位有空間但損失可控。

- **遺漏 Options 不對稱結構**：財報催化劑日是 options 最具效率的進場時機。交易員完全忽略了 call spread 這個在潛在 +34.6% 上行、-28% 下行格局下，能以有限本金捕捉大幅度 payoff 的工具。

## Asymmetry argument

以 2026-07-27 參考價 $279.50 計算：

- **現實上行**：分析師共識目標價 $376.15，漲幅 **+$96.65（+34.6%）**
- **最大下行**：40x P/E 止損線 ~$229，跌幅 **-$50.50（-18.1%）**
- **R:R 比**：96.65 / 50.50 = **1.91:1**（股票部位）
- **Options R:R**：Call spread 最大獲益 $70，最大虧損 ~$14 權利金，**R:R 約 5:1**

若以 $1M NAV 計算具體損失上限：2.0% NAV 初倉 × 18.1% 最大損失 = **$3,620 絕對損失上限**（可承受）；滿倉 3.0% NAV 於財報後建立，最大損失 = **$5,430**（仍在可接受風險範圍）。
