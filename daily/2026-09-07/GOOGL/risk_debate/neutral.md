# GOOGL 中立風控意見 — 2026-09-07

- Google Cloud Q2 82% YoY、backlog $514B、搜尋廣告 +17% 均為有時間戳的硬數據，多方論點基礎紮實。
- CapEx 從 $60-80B 跳升至 $195-205B，造成年化 FCF 赤字約 $100B，是真實的財務結構性壓力，不能以 backlog TCV 完全抵銷。

- Q3 財報（10 月下旬）是決定論點成立的核心催化劑，現階段任何完整佈局均需預留調整空間。

## 激進方過激之處
- **規模膨脹缺乏技術錨點支撐**：激進方以「硬數據充分」主張將倉位從 1.5% 擴大至 2.5% NAV，但在 PRICE_DATA_UNAVAILABLE 的前提下，缺乏動能確認，放大規模等同於在不明趨勢中加大賭注。R:R 4.2× 優異，但 R:R 高不等同信念高——此差異應反映在倉位上。
- **立即全倉進場破壞分批紀律**：激進方認為等待 $352-355 回測是「懲罰自己」，此論點流於情緒；原方案 60/40 分批的設計正是為了應對 FCF 壓縮可能帶來的短期下行壓力，棄之不合理。
- **Call spread 疊加過度複雜化**：在尚未確認 MEDIUM 信念值得 2.5% NAV 的前提下，額外疊加期權槓桿等同雙重加碼，若方向反轉，損失路徑更難控制。

## 保守方過激之處
- **止損 $338 內部矛盾**：保守方正確指出日 ATR 約 $6、90 天標準差達 $58，卻提出距進場僅 $22 的止損（$360-$338）——這比它批評的 $328 方案更容易在正常市場雜訊中被洗出，自我矛盾明顯。止損縮緊至 $338 在 vol-adjusted 意義上反而更弱，不是更強。
- **0.75% NAV 過度削減使 R:R 失去意義**：4.2× R:R 在 0.75% NAV 下，T1 絕對獲利不足 0.28% NAV，對組合貢獻可忽略不計；當一個優異的 R:R 機會因規模過小而無法產生實質報酬，風控就失去了服務報酬的本意。
- **XLC put hedge 相關性不精準**：XLC 為傳播媒體板塊 ETF，內含多檔非 GOOGL 個股，用以對沖 GOOGL 特定的 DOJ 尾部風險，基差風險（basis risk）顯著，成本 0.10-0.15% NAV 未必能有效保護真正的下行缺口。

## 最終建議給組合管理人

以 **1.5% NAV（$15,000 / $1M NAV）** 布局 GOOGL LONG，執行細節如下：

1. **即時執行 55%（$8,250）**：於 $352-$368 現價區間市價單建立首批頭寸。
2. **次批 45%（$6,750）**：設置限價單候買 $352-$355；若 Q3 財報（10 月下旬）確認 Cloud 毛利率收斂 AWS/Azure 且 CapEx 指引未再上調，則不論市價直接補足至 1.5% NAV。
3. **止損 $328 嚴格執行**：收盤跌破即平倉，不預設移動止損，理由是論點錨點明確（低於所有已知內部人價格），情緒性微調只會破壞紀律。
4. **不加對沖**：XLC puts 基差風險過大；DOJ 尾部風險以規模控制（1.5% NAV 上限）取代期權對沖，若 DOJ 情勢惡化，則直接觸發平倉機制。
5. **Q3 財報後再評估**：若 Cloud 毛利率顯著改善且 CapEx 指引持平，可考慮上調至 2.5-3% NAV；若 CapEx 再次上調或廣告增速意外惡化，則執行失效條件平倉。
