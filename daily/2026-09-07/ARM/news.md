# 新聞 — ARM 截至 2026-09-07

## 公司特定重點新聞（過去 14 天）

- **2026-08-07** — ARM Q1 FY2027 業績創紀錄：利潤 2.7 億美元，營收年增 22%，毛利率 98%，AI 資料中心需求強勁（The Motley Fool）。影響：看漲。AI 資料中心市場蓬勃發展，推動了 Arm 的創紀錄成長。

- **2026-08-07** — AGI CPU 訂單簿超越 20 億美元（FY 2027–2028），Arm 策略進入 AGI 市場，目標 2031 年達到 150 億美元營收（Futurum）。影響：看漲。Arm 從純授權商轉向自有晶片設計商，打開新商業驅動力。

- **2026-08 中旬** — Arm CSS（Compute Subsystems）授權達 21 份，涵蓋 12 家公司；5 家客戶已出貨 Arm CSS 晶片；CSS 授權費約為 v9 核心授權的 2 倍（Arm 新聞室）。影響：看漲。CSS 是高利潤率的新授權類別，推動皇家特許費加速。

- **2026-07-29** — Arm Q4 FY2026 業績創紀錄：營收 14.9 億美元，年增 20%；非GAAP每股盈餘 0.60 美元（Investing.com）。影響：看漲。連續第四季度營收超 10 億美元，指數級成長加速。

- **2026-08** — 皇家特許費年增 27% 至 7.37 億美元（Q3 FY2026），主要驅動力為 Armv9 與 Arm CSS 採用率上升，以及資料中心晶片使用量增加（Arm 新聞室）。影響：看漲。Armv9 與 CSS 命令更高的皇家特許費，動力充足。

- **2026-08** — 資料中心皇家特許費年增超過 100%，預期未來數年資料中心將成為最大業務部門，超越行動市場（多家分析師）。影響：看漲。資料中心是 Arm 最高成長率的部門。

- **2026-08** — Armv9 採用率預期 2-3 年內達到皇家特許費收入的 60%-70%，目前約 25%；行動電話皇家特許費年增約 30%，遠超市場 <2% 單位成長（Benzinga）。影響：看漲。Armv9 漲價效應遠大於量差。

- **2026-08-13** — Arm 股價上升，摩根士丹利上調目標價至 212 美元，而新街研究首次給予買入評級；RBC Capital 將目標價從 475 美元下調至 340 美元（Motley Fool）。影響：混合。分析師對估值看法差異大。

- **2026-09-** — Arm 宣布 2026 年年度股東大會，提交薪酬政策和董事會提名供股東投票（商業通訊）。影響：中立。公司治理常規事項。

## 部門宏觀事件

- **2026-08 週期** — 超大規模資料中心 CPU 市場佔有率迅速上升至約 50%（相較一年前的 18%），由 NVIDIA Grace Blackwell、AWS Graviton、Google Axion 和 Microsoft Cobalt 驅動（多家分析師）。影響於半導體業：Arm 授權架構在資料中心成為新主流，終結 x86 長期統治；驅動業界投資轉向 Arm 生態。

- **2026-08** — AWS Graviton（基於 Arm）已服務近 10 萬個雲端客戶，推動 AWS CPU 需求的一半以上（Arm 新聞室）。影響於雲端基礎設施：超大規模服務商積極採用 Arm 自有設計，減少對第三方處理器的依賴。

- **2026-06 Computex** — ByteDance 和 Oracle 宣布採用 Arm 新型 AGI 資料中心處理器；Arm AGI CPU 啟動合作夥伴名單共 8 家客戶（科技新聞週期）。影響於晶片產業：全球領先的軟體公司和超大規模服務商達成共識，Arm 成為 AI 基礎設施首選。

## 同業信號

- **NVIDIA** — 2026 年 2 月完全出售 Arm 持股；NVIDIA Grace CPU 與 Arm AGI CPU 直接競爭，改變了過往中立授權的生態關係。含義：Arm 從 NVIDIA 最大授權客戶轉變為直接競爭對手，標誌著 Arm 策略轉型。

- **Apple** — 繼續在 iPhone 和 Mac 中採用 Arm 架構（Apple Silicon），推動行動和個人電腦皇家特許費成長。含義：Apple 為 Arm 最高價值授權客戶，Armv9 與 CSS 採用推動遞增稅率。

- **Amazon** — Graviton 系列晶片在 AWS 上大規模部署，拉動資料中心皇家特許費年增 >100%。含義：Arm 從電信和消費者領域擴展到雲端基礎設施的主導地位。

- **Google、Microsoft** — Google Axion 和 Microsoft Cobalt 均採用 Arm 架構，推動超大規模業者 CPU 市場佔有率升至 50%。含義：Arm 成為雲端對標基礎設施架構。

## 淨觀點

Arm Holdings 展現了極其強勁的基本面勢能。Q1 FY2027 業績營收年增 22%、毛利率 98% 及 20 億美元 AGI CPU 訂單簿彰顯了公司從單純授權商轉型為自有晶片設計商的策略成功。CSS 授權規模擴張至 21 份合約、資料中心皇家特許費年增逾 100%、Armv9 漲價效應（皇家特許費年增 27%）等多項指標均指向強勁的商業動能。SoftBank 86.4% 控股權確保了長期策略穩定性。短期風險來自分析師對估值的分歧（RBC 降級 vs 新街首次買入）及行動裝置皇家特許費成長放緩預期（BofA 警告記憶體成本壓力）。但資料中心需求爆發、Armv9 /CSS 滲透率上升及第一方晶片設計商身份確立形成強大的結構性尾風。

- 催化劑：資料中心市場轉向 Arm、超大規模服務商大規模採納、Armv9/CSS 漲價混合
- 風險：短期估值高企、行動裝置增速放緩、NVIDIA 直接競爭威脅
