# Aggressive risk view — NVDA

## Where trader is too cautious
- Investment plan 自己承認：多方證據（營收 YoY +105.8%、營益率 60.8%→66.2%、淨現金 +24.1B、MA200 之上 +9.1%，長期多頭排列未破壞）是「較硬」的事實，空方疑慮（DSO、FCF/NI）仍待 11-17 驗證。這不是一個該給 LOW 信心+Small size 的設定，這是趨勢完整、只是短期整理的局面。
- Trigger 寫「現價 $221.97 位於支撐區與 MA20 之間，不建議追價，Wait for pullback」——但 10-21 已經 +2.54% 反彈離開 $213.32 低點，量能雖偏弱，若 10-28 FOMC 偏鴿或雲端大廠資本支出上調，股價可能直接站上 MA20 $226.87 而不回落到 $213-217，屆時整批倉位都錯過。等待完美進場價，是用「確定錯過」去換「不確定的小幅更好 R:R」。
- Sizing 僅 Small（0.5%）至 Medium（1.5%），上限仍低。R:R 到 T2 高達 3.25，這種不對稱本該用更大 size 去放大絕對報酬，而非僅因「信心 LOW」就把倉位壓到近乎象徵性。

## Recommended adjustments
- Size：Medium（1.5%）→ Large（3%）。理由：R:R 3.25 遠高於 1.5 門檻，且長期趨勢結構未破；即使 11-17 財報前，Large size 搭配嚴格 stop 仍可控風險。
- Stop：不建議收緊到 $213.32（太貼近、beta 2.22 + FOMC 事件風險下極易被插針洗出），維持 $208.93 甚至可再給到 $207.25（次一支撐），用時間換空間，避免財報前波動放大造成假跌破。
- Entry：現在就先用 Large size 的 1/3 於市價 $221.97 建倉，其餘 2/3 保留在 $213-217 分批承接——不要把全部籌碼賭在「價格一定會回測」這個假設上。
- Consider：若想放大曝險又不想放大絕對 $ 虧損，可用 12 月到期 call（履約價約 $220-230）取代部分現股曝險，鎖定下檔為權利金，上檔仍可參與財報後跳空。

## Asymmetry argument
以 $215（進場區中點）、停損 $208.93、Large size 3%（假設帳戶 $100,000 = $3,000 名目）計算：
停損距離 2.82% → 最大虧損 A ≈ $85。
到 T2 $234.76 距離 9.19% → 實際上行 B ≈ $275。
B/A ≈ 3.25，且絕對虧損僅 $85，遠低於可承受範圍，沒有理由只用 Small/Medium。

## What I'd push for
現在先用 Large size 的三分之一於市價建立第一批倉位，不要空手等待完美回測；剩餘籌碼留在 $213-217 分批加碼，站回 MA20 後補足到 Large 上限；停損維持（或略放寬至）$208.93-$207.25 區間以避開 FOMC 前的洗盤，絕對虧損金額（約 $85-$130）相對 B（約 $275 以上）完全可承受，沒有理由讓「信心 LOW」把本該放大的不對稱機會縮小成象徵性倉位。
