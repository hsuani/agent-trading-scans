# Aggressive risk view — 3189.TW

## Where trader is too cautious

**1. 分析師目標價是落後指標，不是天花板**
Goldman Sachs NT$370 的目標是以 2025 年 EPS 基準建立的模型輸出，在 AMD 確認訂單擴大（2026/06/16 Digitimes）及管理層 EPS 翻倍指引**之前**所設定。拿過時的分析師目標價來定義「超漲」，是拿後照鏡開車。市場已在消化新資訊；模型尚未更新。這個「溢價 +95.7%」的論述對當下進場決策的殺傷力，遠低於交易員以為的程度。

**2. MA20 止損 R:R = 1.54 被拋棄，理由不充分**
交易員自己計算出 MA20 止損下 T1 的 R:R = 1.54，大於 1.5 門檻，卻以「T1 靠近 BB 上軌受限」為由棄用。但 T1 = NT$778 只是第一目標，不是論文全部。若動能延續——Q1 EPS +92%、AMD 訂單入列、ABF 缺口 2028 年達 42%——T2 = NT$850 的概率並非零。即便給 T2 只有 30% 的到達概率，期望值仍優於 PASS。

**3. 等待 Q2 財報是「等別人先跑」**
Q2 財報（7 月中旬）一旦毛利率突破 24%，市場即刻重新定價。屆時進場的理想入場點 NT$778–800，比現在貴 7–10%。Alpha 來自在確認前承擔不確定性，不是在確認後追高。這就是為何「等待」會殺掉 alpha 的核心邏輯。

**4. 止損設定太寬（MA50 = -22.7%）讓倉位變小，邏輯倒置**
交易員因為 MA50 止損下 R:R = 0.33 而拒絕進場，但解法不是 PASS，而是**縮小倉位 + 收窄止損**。MA20 = NT$689 提供合理的近端失效點（論文短期動能未破）；用小倉配 MA20 止損，風險金額可控，論文框架成立。

## Recommended adjustments

- **Size：0% → Small（0.5–0.75% NAV）**
  理由：現價 NT$724，止損 MA20 = NT$689，每股風險 NT$35。以 NT$100 萬帳戶為例，0.75% NAV = NT$7,500，可買約 10 股，最大損失約 NT$350（0.035% NAV）。這是探索性倉位，不是全押。
- **Stop：MA50（NT$560）→ MA20（NT$689）**
  MA20 收盤失守代表短期動能翻轉，論文暫停。給空間但不給 -22.7% 的無謂虧損。
- **Entry：現在進場（TWD 724 附近）vs 等待突破 NT$778**
  等突破確認多花 7%，且突破當日成交量爆量時容易追高滑點。若論文正確，現在是較優買點。
- **Consider：輕度 options 槓桿**
  若台股選擇權流動性允許，可考慮 Call spread：買入 行使價 NT$750 / 賣出 NT$850，到期 2026-09（Q2 財報後 + ABF ASP 談判結果前）。以 debit spread 限定最大損失於權利金，放大 T2 upside 的 R:R 至 3x+。

## Asymmetry argument

| 情境 | 金額（以 0.75% NAV = NT$7,500 部位計）|
|---|---|
| 最差損失（MA20 止損，-4.8%）| -NT$360 |
| T1 獲利（NT$778，+7.5%）| +NT$562 |
| T2 獲利（NT$850，+17.4%）| +NT$1,305 |
| Ratio（T2 / Max Loss）| **3.6x** |

即使 T2 只有 40% 到達概率，期望值 = 0.4 × 1,305 + 0.6 × (−360) = **+306（正期望值）**。

Worst case max loss：**NT$360（0.036% NAV）**。
Realistic upside（T1 + T2 混合）：**+NT$700–1,300**。
Ratio B/A = **1.9x–3.6x**，超過 1.5 門檻。

## What I'd push for

現在以 **Small 倉（0.5–0.75% NAV）、止損 MA20（NT$689）** 建立探索性多頭，而不是空等 Q2 財報。理由很直接：Q1 EPS +92% 已兌現、AMD 訂單入列已公告、ABF 供需缺口有第三方數據、管理層 EPS 翻倍指引具體存在——這些不是預測，是已知事實。分析師目標價是舊模型輸出，不代表估值上限。MA20 止損將最大損失壓在 0.036% NAV，這個金額不值得讓你錯過一個 3.6x 非對稱機會的起始點。若 7 月財報正面驗證，加碼至 Medium 倉（1.5% NAV）。若 MA20 失守，停損離場，損失可承受。**進場探索，而不是在場外等著看別人賺。**
