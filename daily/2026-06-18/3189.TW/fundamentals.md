# 基本面分析 — 3189.TW (景碩科技) 截至 2026-06-18

## 執行摘要

景碩科技作為台灣IC基板龍頭廠商，2025年營收來到393.5億元，相比2024年的305.3億元成長28.8%，顯示AI晶片基板需求強勁。然而淨利表現反差：2025年稅後淨利159.6億元（包含子公司少數股東權益調整前為271.7億元），但扣除少數股東淨利後僅48.9億元，反映複雜的股權結構與子公司盈利貢獻分配。自由現金流從2024年的負29億元轉正至17.1億元，顯示現金生成能力恢復，但資本支出仍高達63.8億元。目前本益比極度高估（trailing P/E 212.9倍），但forward P/E 35.1倍與正常化盈利預期相較仍有下行風險。

## 營收與獲利性

### 營收成長
- 2022: 42.44 十億 TWD
- 2023: 26.83 十億 TWD (YoY: -36.8%)
- 2024: 30.53 十億 TWD (YoY: +13.8%)
- 2025: 39.35 十億 TWD (YoY: +28.8%)
- 三年CAGR (2022-2025): -2.7%

營收於2022年達高峰42.4十億元，隨後2023年驟降36.8%至26.8十億元，反映全球晶片庫存調整衝擊。2024-2025年營收恢復強勢成長，28.8% YoY成長主要受惠於AI伺服器晶片基板（特別是CPU/GPU用ABF基板）需求激增。

### 毛利率與営業利益率
- 2022年毛利率：37.0% (15.71十億 / 42.44十億)
- 2023年毛利率：25.2% (6.76十億 / 26.83十億)
- 2024年毛利率：28.4% (8.67十億 / 30.53十億)
- 2025年毛利率：21.1% (8.31十億 / 39.35十億)

毛利率從2022年的37.0%下降至2025年的21.1%，跌幅達1590bp，反映激烈的市場競爭與成本控制壓力。儘管營收倍增，毛利額反而只有8.31十億元（低於2022年的15.71十億）。

- 2022年營業利益率：22.6% (9.60十億 / 42.44十億)
- 2023年營業利益率：3.9% (1.06十億 / 26.83十億)
- 2024年營業利益率：3.4% (1.05十億 / 30.53十億)
- 2025年營業利益率：6.8% (2.66十億 / 39.35十億)

營業利益率自2022年的22.6%跌至3-4%水位，2025年略微回升至6.8%，仍低於歷史正常水位。

### 淨利與ROE
- 2022年淨利（含少數股東）：79.3十億 元
- 2023年淨利（含少數股東）：11.7十億 元
- 2024年淨利（含少數股東）：13.3十億 元
- 2025年淨利（含少數股東）：27.2十億 元
- 2025年淨利（母公司）：15.96十億 元

少數股東權益占淨利比例高達65.5%（8.64十億 / 13.2十億），反映Kinsus子公司股權結構複雜。

- ROE (基於母公司淨利 1.596十億 / 平均股東權益 ~32十億): 4.98% (極低)
- ROE (基於含少數股東淨利 2.717十億 / 總權益 41.4十億): 6.56%

ROE均處於低水位，反映盈利能力受損。

## 主要催化劑與風險

### 短期催化劑（3-6個月）
- **Q2 2026財報發布**：預期於7月中旬公佈，市場關注毛利率能否維持或改善
- **AI晶片需求持續**：Intel、AMD、NVIDIA對ABF基板的採購需求推升
- **資本支出指引**：管理層是否持續降低capex，進一步提升FCF

### 中期風險（6-12個月）
- **基板產業競爭加劇**：南韓Samsung、日本Shinko Electronics等競爭者擴產，景碩市佔率面臨壓力
- **毛利率持續承壓**：若2026年毛利率無法回升至25%以上，息前稅後利潤將難以支撐高本益比
- **資本支出反彈**：若新興技術（如chiplet、3D封裝）需要大規模投資，FCF回正可能短暫

### 長期結構性風險
- **台積電等晶圓廠垂直整合**：晶圓廠自建基板產能威脅獨立基板廠商
- **地緣政治**：台灣位置敏感，美中科技戰加劇時可能面臨需求或供應鏈干擾
- **摩爾定律趨緩**：若AI晶片成長放緩，基板需求增速從28.8%回落至個位數

## 紅旗與關鍵隱憂

### 盈利能力衰退
- 毛利率從37%（2022）急速萎縮至21.1%（2025），跌幅1590bp，反映定價能力喪失與成本控制不力
- 淨利率（母公司）僅4.1%（15.96 / 393.5），遠低於歷史的18.8%（2022）

### 股權結構複雜性
- 少數股東佔淨利65.5%，母公司實際淨利僅159.6億元，實際ROE僅4.98%
- 複雜的中國子公司結構與增值稅返還機制造成會計波動大

### 估值陷阱警訊
- Forward P/E 35.1倍仍高於台灣半導體產業平均15-20倍，暗示市場對景碩未來成長預期極高
- 若Forward預期的EPS 20.62元無法達成，估值將快速回檔

### 現金流可持續性疑慮
- FCF 17.1十億元基數仍小，佔OCF 21.1%，若資本支出反彈或營收增速放緩，FCF立即轉負
- 過去三年平均FCF為-16.3十億元，2025年轉正只是恢復，非常態

### 毛利率復甦空間有限
- 若毛利率無法回升至28%以上（2024年水位），營業利潤難以支撐35倍本益比
- 競爭對手擴產與價格戰將持續壓低行業利潤率

## 結論

景碩科技作為台灣AI基板龍頭，營收成長動能強勁（28.8% YoY），但盈利能力面臨深度衝擊：毛利率腰斬、淨利率僅4.1%、ROE接近5%。自由現金流轉正（17.1十億元）為正面訊號，但基數仍小，可持續性有疑。

**估值判斷**：Forward P/E 35.1倍隱含市場預期景碩未來EPS將恢復至20+元水位，並維持年增30%以上。若此預期落空，估值將面臨重大回調風險。EV/EBITDA 3.75倍相對低估，但需配合盈利能力改善才能兌現。

**投資特點**：高成長、低盈利、高估值—典型的景氣循環成長股。適合對台灣AI產業前景有高度信心、且能承受短期波動的機構投資者。風險承受度低者應等待毛利率與ROE明顯改善後再進場。
