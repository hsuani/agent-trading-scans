# 基本面分析 — NVDA 截至 2026-08-31

## 執行摘要

輝達(NVDA)在截至2026年1月31日的財政年度中，營收達$2,159.4億，較上年同期增長65.3%，3年複合年增長率達100%。公司在AI加速運算領域佔據絕對領導地位，淨利潤率達55.6%、營業利率60.4%，顯示世界級的盈利能力。然而，毛利率從74.9%回落至71.1%，營運資本膨脹導致自由現金流與淨收入比率降至80.5%，均需注意。股價$220.75對應市值$5.33兆，本益比45倍、本淨比40倍，估值已充分反映增長預期；相較之下，本益比對應Q1年化基礎僅23倍。公司資本配置績效卓越，在65%營收增速下仍回購$400.86億股份，已累積淨現金$515.2億。**財務健康度整體優良，但估值風險需密切監控。**

|-----|---|---|---|---|

**毛利率回落**：FY2026毛利率280個基點的下降(74.9% → 71.1%)，反映：
1. 高階晶片(H系列)競爭加劇，定價壓力
2. 庫存堆積期間折扣促銷(2023年庫存危機後的常規化)
3. 產品組合轉變：高毛利專用晶片增速低於低毛利通用加速器
4. 晶圓代工成本(台積電N5/N4工藝)上升

**營業與淨利率保持60%+**：儘管毛利率下滑，營業槓桿仍強勁，研發(R&D)支出僅$184.97億(占營收8.6%)、銷管費用$45.79億(2.1%)，均保持紀律。稅率15.1%相對溫和。

## 關鍵風險旗標

### 紅旗信號

1. **毛利率下滑280個基點**：雖然仍處71.1%高位,但趨勢需密切監控
   - 決定因子：下一季是否穩定或繼續下滑
   - 警戒點：若跌破70%或進一步至68-69%

2. **營運資本膨脹加劇**：
   - 應收帳款 YoY +$15.4B，天數可能從60天擴至75-90天
   - 庫存 YoY +$11.3B，較正常升幅為快
   - **跡象**：可能反映客戶需求弱化或輝達主動增庫存應對潛在短缺

3. **估值倍數高位脆弱**：
   - P/E 45倍基於歷史盈利,任何負面指引下修10-15%都將觸發調整至P/E 35-40倍
   - 潛在股價下跌20-30%

4. **股票回購在高位持續**：
   - $400億回購可能高估,應監控管理層對未來的謹慎態度
   - 若回購突然暫停,可能預示內部對前景悲觀

5. **地緣政治尾部風險**：台灣情勢升溫、美中晶片戰爭升級

### 綠旗信號

1. **現金與FCF充裕**：$515億淨現金賦予戰略靈活性,可應對需求衝擊
2. **創新領先**：H系列設計週期領先競爭對手12-18個月
3. **客戶多元化進展**：汽車/邊緣計算/企業AI新客群滲透
4. **資本紀律**：毛利率下滑但利率控制得宜,運營槓桿依然強勁
