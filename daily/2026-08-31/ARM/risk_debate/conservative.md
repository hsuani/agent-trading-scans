# Conservative risk view — ARM

## Where trader is too aggressive

- **BUY Gate $245–$280 安全邊際不足**：距 GF Value $187.72 仍有 31–49% 溢價。街道共識目標中位本身就是分析師的樂觀假設，以共識目標當買入錨點等於用「次樂觀」對抗「最悲觀」的尾部風險，結構上不對稱。
- **244x trailing P/E 的容錯空間為零**：Q1 FY2026 已發生 -38% EPS 錯失（$0.25 vs $0.40）；若 Q3 FY2026 再度失誤，55–62x Forward P/E 在市場重新定價時可壓縮至 35–40x，對應股價 $150–$180，遠低於任何現有 BUY Gate。
- **機構持股 0.47% 是結構性棄票**：這不是「尚未發現的隱藏寶石」，而是最了解估值框架的專業資金在 $369 拒絕接手的明確訊號。CFO 於 $392 出售 + 20 筆 insider sell 無一買入，信號密度已超過雜訊門檻。
- **營業利潤率從 11% 壓縮至 7%**：費率倍增的紅利被研發擴張全數吸收；在費率尚未有效轉化為盈利之前，增速本身的可持續性存疑。

## Tail scenarios

- **Scenario A（概率 20%）：Qualcomm NUVIA ALA 上訴敗訴** → 頂級客戶授權繞道合法化，高端代理稅收基礎受損 → 股價跌至 $185–$200，自 BUY Gate 上緣 $280 計損 $80–$95/股，$ loss ≈ $1,500（0.5% NAV 倉位），且護城河永久性受損，停損無法救回本金。
- **Scenario B（概率 25%）：2027 年 AI CapEx 週期反轉** → 主要雲廠商削減 CapEx 指引，代理稅收增速驟降至 <10% YoY → Forward P/E 支撐崩解，股價跌至 $200–$220，自 $280 計損 $60–$80/股，$ loss ≈ $1,100–$1,450（0.5% NAV）。
- **Scenario C（概率 30%）：Q3 FY2026 EPS 再次大幅錯失 + 利潤率未改善** → 市場信心崩潰，即時跌破 BUY Gate 下緣 $245 止損觸發 → 自 $280 計損 $35/股，$ loss ≈ $625（0.5% NAV）。此為「最輕」情境，但在 $245 觸止損後股價仍可能繼續下探至 GF Value $187。

## Recommended adjustments

- **BUY Gate**：$245–$280 → 壓低至 **$200–$215**（GF Value $187.72 上方 7–14% 安全墊），僅在此區間且伴隨基本面確認才考慮進場。
- **Stop**：$245 → **$183**（GF Value 下方 2–3% 緩衝，代表護城河假設完全失效），以結構支撐而非技術位設置止損。
- **Entry**：拒絕一次性建倉，改為三分法：$215 建 1/3、$200 建 1/3、$187 有正面基本面催化劑才補最後 1/3。
- **Hedge**：若已持有部位，可考慮買入 SOX ETF 的 3–6 個月 put（delta -0.25 左右）以對沖 AI CapEx 週期系統性回調。

## Position-level $ risk

以調整後方案（進場 $210，止損 $183）：
損失/股 = $210 − $183 = **$27**
0.5% NAV 倉位（假設 NAV $1,000,000）= $5,000 / $210 ≈ 23.8 股
**$ loss if stop hits = $27 × 23.8 ≈ $643 = 0.064% NAV**

數字層面可接受，但問題核心不在絕對金額：在 Qualcomm 上訴裁決與 AGI CPU 量產兩大二元事件明朗化之前，**本金永久性損失的概率遠高於短期停損數字所能反映的範圍**。0.5% NAV 的倉位規模本身不算激進，但在當前不確定性視窗下，任何多頭部位的時機都是問題。

## What I'd push for

完全 AVOID 直到股價跌至 $200 以下，且同步出現以下至少一項基本面錨點：Q3 FY2026 EPS 超預期並伴隨 non-GAAP 營業利潤率回升至 10%+，或 AGI CPU 量產首筆代理稅收正式認列。Qualcomm 上訴懸案未解之前，BUY Gate 不應設於任何高於 GF Value $187.72 三成以上的水位，因為一旦授權執行力受損確認，ARM 的護城河論點會與估值同步崩解，屆時不論從哪個「安全」價位買入，止損都難以保護本金。寧可錯過 $245 的反彈，也要避免在核心風險事件解決之前暴露於 -49% 的結構性下行。
