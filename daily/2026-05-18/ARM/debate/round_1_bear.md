# Bear case round 1 — ARM

## Thesis（1 句話）
ARM 的 IP 授權護城河正遭受 FTC 反壟斷調查與自我競爭困局雙重侵蝕，FCF 崩潰 83%、估值高達追蹤 P/E 240 倍，而管理層一致拋售 $24.6M 股票——股價應從 $206 回落至 $120–$130，下跌空間逾 37%。

---

## 需求 / 市場風險

**客戶集中與轉向自研**：ARM 授權營收高度依賴 Apple、Qualcomm、Samsung 等少數大廠。Apple M/A 系列晶片、Amazon Graviton、Google Axion 均屬「ARM 架構但自行設計」，減少對 ARM CSS 套件的採購依賴，直接壓縮未來 royalty 提升空間。一旦主要客戶決定縮減標準 CSS 授用，ARM 的授權費成長敘事將出現實質裂縫。

**AGI CPU 自我競爭邏輯矛盾**：ARM 宣布推出自有 AGI CPU，直接與 Qualcomm、Apple、Nvidia 等授權客戶競爭終端市場。這是「房東變房客競爭對手」的商業模式矛盾——客戶勢必加速「去 ARM CSS 化」、尋求 RISC-V 替代或縮減授權規模，長期損害授權信任基礎。

**中國市場政治風險**：SoftBank 控股 ARM，而中國客戶（華為、阿里雲等）受美中科技冷戰衝擊，未來授權續約與新合約風險不對稱偏高，智慧終端與物聯網授權段尤為脆弱。

---

## 利潤 / 現金流風險

**FCF 崩潰為核心警示**：FY2025 FCF 僅 $1.58 億，YoY 暴跌 83.2%；FCF/NI 僅 20%，遠低於健康基準 90%。主因為應收帳款激增 $7.43 億（+61%），顯示客戶付款週期異常延長，可能預示主要被授權方財務壓力或談判條件惡化。帳面利潤 $7.92 億與實際現金收入之間存在巨大落差，GAAP 利潤品質不可信。

**Capex 加速侵蝕邊際**：研發 capex 從 $1.43 億升至 $2.39 億（+67%），隨著 AGI CPU 投入深化，未來兩年 capex 仍將持續攀升，對 FCF 形成持續壓制，「輕資產 IP 授權商」的高利潤神話開始褪色。

**收入品質存疑**：應收帳款占營收比率異常高企，若有任一主要客戶（特別是 Qualcomm，目前與 ARM 處於法律糾紛中）延遲付款或提出爭議，ARM 將面臨大額壞帳風險，進一步衝擊帳面利潤。

|------|---------|------------|---------|-----------|
| 基本熊市 | 40× | $3.05 | $122 | **-41%** |
| 溫和熊市 | 50× | $3.05 | $153 | **-26%** |

追蹤 P/E 240 倍、EV/EBITDA 202 倍、P/FCF >140 倍，遠超半導體 IP 同業合理區間（P/E 25–35 倍）。即使給予 AI 溢價，前瞻 P/E 67.8 倍亦已是奢侈定價。FTC 調查一旦升級，估值溢價將首當其衝壓縮。

**熊市目標價：$120–$130**，隱含 -37% 至 -42% 下跌空間。

---

## 競爭 / 監管威脅

**FTC 反壟斷調查（2026-05-17 正式啟動）**：FTC 調查 ARM 在推出自有 AGI CPU 之際是否以授權存取權限制競爭對手（Apple、Qualcomm、Nvidia）。若 FTC 認定存在反競爭行為，最壞情況可能要求業務拆分或強制開放授權條款，直接摧毀 ARM 的定價權護城河。歷史上，反壟斷案件往往造成目標公司 15–30% 的長期估值折損。

**Qualcomm 訴訟懸案**：Delaware 法院已全面駁回 ARM 對 Qualcomm Nuvia 授權轉讓的指控，ARM 反訴仍待審。持續訴訟消耗法律成本，且進一步打擊授權方對 ARM 授權模式的信任；若 ARM 在反訴中再度敗訴，將進一步削弱其對被授權方的控制力。

**RISC-V 替代威脅加速**：Google、西部數據、三星等大廠均已布局 RISC-V 架構研發。ARM 的反壟斷問題反而加速推動業界評估 RISC-V 替代選項，長期授權議價空間受到侵蝕。
