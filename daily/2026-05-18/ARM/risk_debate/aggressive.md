# Aggressive risk view — ARM

## Where trader is too cautious

- **等待代價被嚴重低估**：交易者要求 FTC 輕判 + 財報驗證 + 價格回踩 $195–$205 三條件同時成立。這是「完美風暴才進場」的思維。現實是：FTC 若以行為修正令結案，ARM 單日跳升 15–25% 並非不可能，直接穿越 $240 阻力。等待者在 $195 接不到單，反倒要追 $230 的高點，機會成本已超過計算中的風險。

- **Stop $166.69 過緊，反而是問題所在**：ARM ATR14 高達 $14.61，年化波動率 111.99%。從當前 $206.49 到 stop $166.69，距離約 $39.80（19.3%），乍看空間充足。但問題在於：若在 $195–$205 進場，stop 距離僅 $28–$38，以此波動率計算，一次常規日內震盪即可洗掉止損，然後股價重新往上走。止損設在 $166.69 局部高點概念上正確，但這個止損與 Small 0.5% NAV 組合在一起，根本沒有為倉位尺寸成立的理由——若寬止損是設計，那倉位必須對應放大才能讓 R:R 在資本配置層面有意義。

- **Sizing 0.5% NAV 幾乎是象徵性倉位**：以 MEDIUM 信心度、96.9% 毛利率護城河、$2B AGI CPU 訂單已驗證的基本面而言，0.5% NAV 不是謹慎，是放棄機會。就算最壞情況股價跌至 $120（熊方目標下緣），從 $205 進場的 0.5% NAV 倉位絕對損失不過 0.2% NAV——這個量級的下行根本不需要三條件觸發的繁文縟節。

- **R:R 計算使用 T1 ($239.50) 作為分母太保守**：交易者自己計算至 T2 ($280) 的 R:R 達 2.68——這是合格數字。若以此為目標，現價 $206.49 進場、stop $166.69，R:R = ($280 − $206.49) / ($206.49 − $166.69) = 73.51 / 39.80 ≈ **1.85**，略低於 2.0 門檻，但考量 Armv9 升級路徑的非線性加速，$280 目標本身可能偏保守（研究報告上緣 $338）。

## Recommended adjustments

- **Size：Small 0.5% NAV → Medium 1.5% NAV**（理由：護城河確實存在、AGI CPU $2B 訂單已有客戶背書、即便用熊方目標 $120 試算，1.5% NAV 倉位最大絕對損失約 0.64% NAV，仍在可承受範圍）
- **Stop：$166.69 維持**（概念正確，勿收緊；但要明白此 stop 隱含的波動容忍必須對應更大倉位才有意義）
- **Entry：現價 $206.49 分批建倉 50%，不等三條件全部成立**（FTC 調查啟動已是已知，市場部分定價；剩餘 50% 留待 FTC 公告或 $195–$200 回踩擇一觸發）
- **考慮 options 非對稱結構**：買入 ARM 2026-10-16 到期 $220/$260 call spread（delta 較低、gamma 捕捉 FTC 利好跳升），最大損失鎖定在 call spread 權利金，若 FTC 輕判引發跳空至 $240+，賠率可達 4–6 倍。這正是 FTC 二元事件最適合的非對稱工具。

## Asymmetry argument

| 情境 | 股價目標 | 1.5% NAV 倉位損益（以 $206.49 進） |
|---|---|---|
| 最壞（FTC 拆分裁定，跌至 $120） | $120 | 約 −0.64% NAV |
| 基本（FTC 輕判，財報中性，$239） | $239 | 約 +0.24% NAV |
| 樂觀（FTC 輕判 + 財報驗證，$280） | $280 | 約 +0.53% NAV |
| 極樂觀（Armv9 加速 + AGI CPU，$338） | $338 | 約 +0.96% NAV |

**Worst case 最大損失：約 0.64% NAV。Realistic upside (T2)：約 0.53% NAV。極樂觀上緣：約 0.96% NAV。Ratio (upside/downside) ≈ 0.83–1.50。**

這個比率乍看不佳，但關鍵在於：FTC「結構性拆分」並非基本情境，市場共識及訴訟慣例均偏向行為修正。若將 FTC 輕判概率估為 65%，期望值即轉正。加上 call spread 結構可將最大損失鎖定在權利金，非對稱性大幅改善。

## What I'd push for

當前交易者的計畫在邏輯上無誤，但「等待完美進場」在高波動 binary event 股票上是最昂貴的錯誤之一。ARM 的核心護城河（150 億顆晶片生態、96.9% 毛利、Armv9 升級路徑）並未因 FTC 調查而改變；調查本身反而壓低股價、製造了不對稱進場窗口。建議立即以 1.5% NAV 分批建立初始部位（現價 50% + 回踩或 FTC 公告後 50%），同步搭配 ARM 2026-10-16 $220/$260 call spread 捕捉 FTC 利好跳升的非線性報酬。Stop 維持 $166.69，並在 FTC 結果公布後依裁定性質決定是否加至 2.0–2.5% NAV。機會成本不是「等到確定再進」，而是「確定發生時股價已不在」。
