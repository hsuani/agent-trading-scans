## Asymmetry argument

以 3% NAV、假設組合規模 $500,000 計算：

| 情境 | 細節 |
|---|---|
| 持倉金額 | $15,000（3% NAV） |
| 進場均價 | $424（60%）+ $405（40%）= $416.40 |
| 最大虧損（止損 $350） | ($416.40 − $350) × 倉位數量 ≈ **$2,385**（-0.48% NAV） |
| T1 獲利（$469） | ($469 − $416.40) × 倉位數量 ≈ **$1,893** |
| T2 獲利（$540） | ($540 − $416.40) × 倉位數量 ≈ **$4,416** |
| T2 R:R | $4,416 / $2,385 ≈ **1.85x** |

若加入 Options Spread（以 $3,000 淨權利金成本、最大獲利 $110 × 30 份 = $3,300 潛在毛利）：
- 最大虧損：$3,000 淨權利金
- 最大獲利：$3,300（不含倉位）
- **Worst case 總損失：$2,385（股票止損）+ $3,000（選擇權歸零）= $5,385（-1.08% NAV）**
- **Realistic upside（T2 $540）：$4,416 + $3,300 = $7,716（+1.54% NAV）**
- **組合 B/A Ratio：$7,716 / $5,385 = 1.43x**

不算豐厚，但這是悲觀情境。若 Q2 財報 EPS 大幅超預期推動股價至 $560+，選擇權 Spread 達最大獲利，總收益可達 **$10,000+（+2.0% NAV）**，同樣最大損失 $5,385，**B/A = 1.86x**。
