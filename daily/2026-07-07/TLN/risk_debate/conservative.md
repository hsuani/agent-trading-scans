# Conservative risk view — TLN

## Where trader is too aggressive

- **加碼門檻過低**：計畫在突破 MA20 $388 後即加碼至 Medium (1.5%)，但 MA50 ($374)、MA200 ($373) 與 MA20 ($388) 在股價上方形成三線密集阻力帶，短暫突破極易為假突破。加碼條件應更嚴苛：連續三根日線收盤站穩 $392+ 且成交量 ≥ 1.2x 五日均量，且須等 $983M 增資完成或撤銷後方可執行。
- **$983M 稀釋懸頂被低估**：240 萬股 SEC 登記後可隨時按市價折讓出售。若以 5% 折讓定價，發行價落在 $347，與止損 $348 幾乎重疊。一旦啟動銷售，極可能形成缺口跳空越過止損，無法按預定 $348 執行。
- **Jefferies 降評訊號未充分定價**：NTM P/E 23.4x 對比同業公用事業 12–16x，溢價由 AWS PPA 支撐，但現金流最早 2029 年落地。三年內 TLN 靠純 PJM 容量收益支撐溢價；容量市場若有負驚喜，估值壓縮空間 25–30%。
- **ATR $13 vs 止損距 $16**：緩衝僅 1.2× ATR，對年化波動率 40–45% 個股而言過薄，單日重大利空即可跳空穿越。

## Tail scenarios

- **情境 A（機率 20%）**：$983M 增資以 >5% 折讓定價 → 股價跳空至 $340–$348，止損跳空執行，實際損失超出預設 $16/股。
- **情境 B（機率 15%）**：FERC 對 AWS 互聯協議作不利裁定 → AWS 現金流敘事右移至 2031+，估值重估至 P/E 17–18x，理論價格 $295–$315，最大跌幅達 18%。
- **情境 C（機率 10%）**：Q2 財報 EBITDA 低於指引下緣 $1.75B → 市場重新質疑 FY2026 可達性，首輪跌至 $335–$340，機構解鎖賣出延伸下行。
- **情境 D（機率 10%）**：Fed 鷹派突發（通膨再加速）→ 高 P/E 成長型公用事業補跌，$365 → $320–$330，稀釋發行視窗同期打開，雙重壓力疊加。

## Recommended adjustments

- **Size**：Small (0.5%) 初倉維持不變；Medium (1.5%) 加碼需同時滿足：(1) $983M 增資完成或撤銷確認，(2) 連續三根日收盤站穩 $392+，(3) 量能放大。三者缺一不可。
- **Stop**：$348 → 改用「日線收盤跌破 $355」作觸發條件（距入場中位 $364 達 $9），避免日內 ATR 噪音與跳空雙重問題；比 $348 更能反映收盤確認邏輯。
- **Entry**：集中在 $358–$362 低端建倉，不在 $370 附近追入；等待 2026-07-20 Power Uprate 報告確認後再評估補倉。
- **Hedge**：配置小量 TLN 2026-09 $350 Put，預算 ≤ 0.1% NAV，專門對沖稀釋跳空與 FERC 尾部風險。
