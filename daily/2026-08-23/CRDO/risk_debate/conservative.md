# Conservative risk view — CRDO

## Where trader is too aggressive

1. **停損過寬（24.6%）**：$177 停損距入場中位 $234.82 達 $57.82，在年化波動率 40%+ 環境下幾同無效保護——正常市場噪音即可觸及，而三週內 $177→$283→$234 的劇烈波動已充分說明此點。停損寬鬆不等於安全，只是讓虧損更大。

2. **整個交易高度依賴 T2 催化劑鏈**：T1 R:R 僅 0.63×，嚴重低於 1.5× 門檻；T2 $364 需同時滿足 FCC 禁令年底落地 + 光學 DSP 首次具體揭露 + 第六超大規模客戶簽約，三重催化劑同時兌現且 non-GAAP forward P/E 需從 22-28× 擴張至 35×，機率並不高。

3. **管理層套現訊號未充分折現**：12 個月 334 筆出售、0 筆買入，CEO 在 $210–$212 設定 10b5-1 計畫，現行市價 $234 已高於管理層判斷的出售合理區，倉位未對此額外壓縮。

4. **技術確認完全缺失**：PRICE_DATA_UNAVAILABLE，RSI、MACD、支撐位均無法驗證，進場依據僅為基本面錨點與分析師共識，而非市場結構確認。

## Tail scenarios

- **Scenario A（機率 20%）**：Q2 FY27 財報（9 月）指引低於 $465M，光學 DSP 貢獻未明確揭露 → 市場切換至 GAAP P/E（60-70×）框架，分析師目標均值下修至 $180–$200，$177 停損觸及 → 損失 ≈ 0.12% NAV（原倉位）。

- **Scenario B（機率 15%）**：任一佔比 >10% 超大規模客戶（如 Microsoft、Meta）公告自研連接晶片或轉向 Marvell → 季度營收衝擊 -15 至 -20%，股價短期跌穿 $177 停損，信心重創難以補回。

- **Scenario C（機率 10%）**：Fed 鷹派意外（通膨回升）驅動科技股系統性殺估值，SMH 回撤 15%+；CRDO 高 beta（估計 β ≈ 1.8+）對應跌幅達 27%+，股價逼近 $170，穿越 $177 停損。

- **Scenario D（機率 8%）**：FCC 禁令導致超大規模 CSP 部署延遲，本為多頭催化劑的政策反轉為需求壓力，管理層被迫下調展望，股票重定價。

## Recommended adjustments

- **Size**: Small（0.5% NAV）→ **Extra Small（0.25% NAV）**。理由：技術確認缺失、管理層全面套現、T1 R:R 不合格、高波動率四重疊加，應以最低試探性倉位進場，待 Q2 FY27 財報確認後再加倉。

- **Stop**: $177.00 → **$210.00**（距入場 $229 約 8.3%，仍覆蓋 GF Value $225.81 緩衝，避免承擔 24.6% 的靜默虧損風險）。

- **Entry**: 嚴格等候 $226–$229 回測 GF Value 錨點後方進場首批；市價 $234.82 不追入，若無回測則觀望至財報。

- **Consider**: 以 SMH 2026-10 到期虛值 5% put 對沖系統性科技股回撤，保費約 0.05–0.08% NAV，可對沖 Scenario C 風險。

## What I'd push for

在技術確認完全缺失、管理層連續 12 個月淨拋售 $479.7M 且市價已超越 CEO 套現區的條件下，本交易不應以 $234 市價直接進場。正確做法是：倉位壓縮至 0.25% NAV，**嚴格等候 $226–$229 回測確認支撐**，停損上移至 $210（承擔 ~8% 回撤而非 24.6%），輔以 SMH put 提供系統性保護。若 9 月財報前無回測機會，寧可錯過，等財報後實際數字確認光學 DSP 貢獻再執行。T2 $364 多頭情境值得等待，但須以更嚴格的入場紀律換取真實安全邊際。
