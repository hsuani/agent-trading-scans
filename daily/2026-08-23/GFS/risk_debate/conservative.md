# Conservative risk view — GFS (GlobalFoundries)

## Where trader is too aggressive

**Stop 過寬、名義上合理但實質危險。** 止損設於 $44.00，距入場中值 $53.93 達 $9.93（-18.4%）。GF Value 內在價值僅 $45.07，與止損相差 $1.07——意即市場只需跌穿內在價值，止損幾乎自動觸發。這不是「在內在價值下方設防」，而是「把內在價值當做跳板」，邏輯脆弱。

**30 筆內部賣出被低估。** CLO 於 $52.62、CBO 於 $57.81 分批出清，高層在現價附近持續出場。即便假設部分為 10b5-1 預排，在 6 個月 30:0 買賣比的環境下入場，等同正面迎擊持有最多資訊的一群人。這一點在提案中輕描淡寫。

**Forward P/E 36× 對特色代工廠已是溢價危機。** Q3 年化 EPS $1.48，對應 $53.93 隱含 Forward P/E 36×，遠超代工業合理區間 18–22×。矽光子敘事尚無任何可量化訂單，估值壓縮風險至今無人定價。

**Data vacuum 使任何倉位皆屬蒙眼操作。** FCF、債務結構、客戶集中度、ROIC 全為 DATA_UNAVAILABLE，在核心財務健康指標缺失的情況下，0.25% NAV 的「探索性」部位並不安全。

## Tail scenarios

- **Scenario A（概率 35%）：Q3 財報矽光子訂單能見度完全缺席，EPS 指引繼續環比下滑至 $0.30 以下。** 估值重估至 18× P/E → 目標價 $26.64，自入場 -51%。若持有 0.25% NAV，$ loss = 約 NAV 0.13%；看似不大，但個股暴跌過程中滑點會讓止損失效，實際虧損可能遠超 $9.93。

- **Scenario B（概率 20%）：Mubadala 宣佈任何形式減持。** 公眾流通股低，流動性枯竭觸發非線性拋售。止損 $44 可能以 gap-down 形式穿越，實際出場價格可能落在 $38–$42，虧損擴大至 $11–$16/股。

- **Scenario C（概率 15%）：Fed 意外升息或地緣衝擊（台海、中東）。** 高 Forward P/E 個股在風險偏好驟降時最先被殺估值，GFS 此時無法獲得任何「防禦性」保護，與 TSMC/三星的競爭敘事同步惡化。

---

## Recommended adjustments

- **Size：0.25% NAV → 0.10% NAV**（理由：Stop 寬度 18.4%、內部人淨賣出、Data vacuum 三項疊加，現行規模仍超出低確信度標準；若必須表態，0.10% NAV 為可接受的實驗性底限）
- **Stop：$44.00 → $47.50**（理由：GF Value $45.07 之上設防；給予 $2.43 緩衝，但如跌破 $47.50 即代表市場明確拒絕 GF Value 支撐，多方框架先行失效）
- **Entry：不在財報前建倉，嚴格等待 Q3 財報後次日確認**。若管理層首次量化 SCALE 訂單且 Q4 EPS 指引環比正成長，再以市價切入。任何提前佈局均屬不必要的事件風險敞口。
- **Consider：以 IXN（iShares Global Tech ETF）或 SOXX put spread 對沖半導體大類風險**，避免因行業輪動放大個股損失。

## Position-level $ risk

以入場中值 $53.93、止損 $47.50 計算（調整後）：

止損寬度 = $53.93 − $47.50 = **$6.43**

假設 NAV = $1,000,000，0.10% NAV 部位 = $1,000，持股約 18.5 股

若止損觸發：$ loss = 18.5 × $6.43 = **約 $119（NAV 0.012%）**

此水準可接受，但須注意 Scenario B Mubadala 減持引發的 gap-down 可能令實際出場遠低於 $47.50，建議以最壞情境（出場 $38）計算最大損失：18.5 × $15.93 ≈ **$295（NAV 0.030%）**，仍在容忍範圍內。

原提案 0.25% NAV + 止損 $44 的實際損失上限：NAV $1,000,000 → 部位 $2,500 → 46 股 → 止損損失 $457，gap-down 至 $38 則損失達 **$738（NAV 0.074%）**，對低確信度個股而言不必要地偏高。

## What I'd push for

GFS 目前不具備入場條件。高層 30 筆賣出比 0 筆買入、Forward P/E 36×、FCF 與債務結構完全不透明，任何一項單獨成立都足以要求「等等看」。提案中 0.25% NAV 已是小倉，但在 Mubadala 流動性陷阱與 gap-down 風險下仍過度。建議明確降至 0.10% NAV，同步將止損收緊至 $47.50，並設定硬性規則：**Q3 財報前不建倉，財報後若矽光子訂單缺席或 EPS 指引持續環比下滑，直接升級為 SKIP**。目前最謹慎的立場是持幣等待，讓 Q3 財報做決策，而非現在押注不確定性。
