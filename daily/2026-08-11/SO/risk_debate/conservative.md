# Conservative risk view — SO

## Where trader is too aggressive

**估值溢價已充分消化樂觀預期**：當前隱含 P/E ~21x 相較公用事業歷史合理區間 15–18x 溢價 17–40%。投資計畫中雖承認此溢價，但 0.5% NAV 進場仍是在尚未確認溢價能否維持的狀況下付出完整風險敞口。AI 敘事已反映於股價，催化劑若未能兌現，下行空間等比例釋放。

**EPS 品質隱患被低估**：Q2 EPS 超預期 +23% YoY，但同期營收落後共識 4.7%（$6.98B vs $7.45B）。在 $8.1B 年度 capex 擴張週期中，成本壓縮驅動的 EPS 無可持續性——資本開支上升必然壓縮利潤率，此模式無法複製至 Q3/Q4。

**內部人訊號被邊緣化**：GPC CEO Kimberly Greene 以約 $96.67/股（情緒報告引用 $94.53 近似基準估算）變現 25,000 股，套現約 $241 萬。6 個月 0 買入／5 賣出，持有最完整資訊的管理層選擇出場，應視為首要警示，而非「流動性需求」的例行解釋。

**16/25 分析師維持 HOLD**，2 家 Strong Sell；機構共識傾保守，進場前需有更強論述基礎。

## Tail scenarios

- **情境 A（概率 20%）：Fed 震盪 — 10Y 美債殖利率突破 4.5%**
  公用事業估值乘數系統性收縮，P/E 由 21x 壓縮至歷史中位 16x，隱含股價下行 ~24%。情緒報告引用參考價 ~$94.53，估算跌幅目標約 $72，NAV 0.5% 倉位承受完整損失。

- **情境 B（概率 25%）：Q3 2026 盈利失速 — 營收缺口持續擴大**
  成本壓縮空間耗盡疊加 capex 攀升，EPS 未達預期，全年指引下調至 $4.50 下端以下。股價重估下行 15–20%，「AI 公用事業溢價」敘事出現裂縫。

- **情境 C（概率 15%）：OpenAI 合約揭示為不具拘束力 MOU**
  現金流確定性大幅降低，3.2 GW 核心論述崩解，P/E 快速回歸 16–17x，股價下行 20–25%。75 GW 潛在管道歷史轉化率僅 20–30%，有效落地量可能僅 15–22 GW，略高於已簽 17 GW，敘事溢價幾乎歸零。

- **情境 D（概率 30%）：板塊輪動 / 成長股重回主導**
  利率保持穩定但市場風格切換，公用事業相對大盤落後 10–15%，缺乏超額收益，持有機會成本偏高。

## Recommended adjustments

- **Size**：0.5% NAV → **0.25% NAV**（理由：OpenAI 合約法律性質未確認、P/E 溢價已高、管理層淨賣出三者同時存在，不宜半倉買入未驗證溢價）
- **Stop**：無即時報價，以論述失效代替技術性停損——OpenAI 合約確認為 MOU 或 Q3 EPS 品質不達標，立即清倉，不等待價格觸發
- **Entry**：勿於除息日 2026-08-17 前搶進；除息後觀察支撐穩定度，確認無額外技術性賣壓再建 0.25% 基礎倉
- **Hedge**：若組合已持有其他公用事業（NEE / DUK），SO 加入將形成利率敏感型集中曝險；建議以 XLU 賣出跨式或買入保護性賣權對沖板塊下行風險
