## 關鍵情緒敏感因素

對 IBM 情緒有重大影響的因素：

1. **量子商業化進展**
   - Osprey / Condor 性能達成 → 上升情緒
   - 商業應用遲滯 → 下降情緒
   - 合作夥伴擴展 → 正面信號

2. **混合雲市場份額**
   - Red Hat 客戶擴展 → 上升
   - 市場份額流失 → 下降
   - 定價權維持 → 正面

3. **AI 投資回報**
   - watsonx 客戶增長 → 上升
   - 邊際率改善 → 上升
   - R&D 投資增加而收益未見 → 下降

4. **傳統業務衰退幅度**
   - 基礎設施服務客流流失加速 → 下降
   - 主機業務穩定 → 穩定情緒

5. **宏觀經濟週期**
   - 企業 IT 支出預期向上 → 正面
   - 衰退信號 → 負面
