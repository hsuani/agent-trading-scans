# 基本面分析報告 — SO (南方公司) 截至 2026-06-16

## 執行摘要

南方公司是美國東南部主要的受監管電力公用事業，主要經營喬治亞州和阿拉巴馬州的電力分配。2025年財務表現顯示營收穩定成長（YoY +10.7%），淨利息達43.41億美元，但自由現金流轉為負（-29.35億美元）。核心挑戰包括：(1) 高槓桿比率（負債/股權 190.4%），淨債務增至705.2億美元；(2) 資本密集型業務受沃格特3、4號核電機組完成後持續高度資本支出驅動（2025年資本支出127.37億美元）；(3) 股息覆蓋率相對緊張（淨收入對股息比率下滑至76%）。估值方面，尾隨本益比23.7倍，高於公用事業部門中位數，但遠期本益比18.8倍反映市場對近期EPS成長的謹慎預期。關鍵催化劑為2026年7月30日季度業績與Vogtle投資報酬逐步實現。

## 營收與獲利能力

- **2025年全年營收**：295.53億美元

- 東南部地區需求增長，尤其是數據中心與AI相關負載（長期趨勢）

- 2025年季度營收分佈不均，Q1/Q2/Q3/Q4分別為77.75B/69.73B/78.23B/69.81B（季節性明顯）

## 催化劑與風險

### 正面催化劑 (6-12個月)
1. **Vogtle 3/4核電機組完全商業化**
   - 目標：2026年全額投入，貢獻2.4GW新增容量與穩定電力收入
   - 影響：長期現金流正常化，資本支出回落，FCF轉正可期
   
2. **2026年季度業績**
   - 下次公佈：2026-07-30
   - EPS預估：$1.01（Q2）
   - 上一次(Q1 2026-02-19)：報告$0.55 vs 預估$0.56，略低但基本符合

3. **監管費率審批**
   - 喬治亞州與阿拉巴馬州持續推進費率上調以彌補Vogtle投資成本
   - 預期長期利潤率正常化

4. **AI與數據中心電力需求**
   - 東南部數據中心與AI廠房建設加速
   - SO受惠於當地電力供應壟斷優勢

### 負面風險
1. **高槓桿與利率上行風險**
   - 淨債務709B與債務/EBITDA 5.3x處於危險邊際
   - 若利率再升，融資成本與利息費用進一步膨脹
   - 預期評級機構可能下調信評，提高融資成本

2. **Vogtle投資超支風險**
   - 歷史成本超支已達數十億美元（從最初~140億膨脹至逾200億）
   - 部分超支已由南方公司吸收，股東最終承擔成本損失

3. **FCF持續負值**
   - 若資本支出持續超過營運現金流，公司將依賴融資維持股利
   - 股利可持續性受威脅

4. **監管與能源轉型風險**
   - 煤炭與核能政策變化可能影響長期資產價值
   - 再生能源轉向成本與投資不確定性

5. **經濟衰退與需求下滑**
   - 若經濟衰退，電力需求下滑將影響營收與現金流

## 結論

南方公司作為東南部主要受監管公用事業，長期基本面受Vogtle核電機組完成與區域需求成長支撐。然而，當前財務結構呈現嚴峻挑戰：高槓桿（負債/股權 190%）、自由現金流負值（-29.35億）與利息負擔飆升（32.38億）已達危險邊際。股價（P/E 23.7x）預先反映了過於樂觀的Vogtle回報假設，下行風險高於上行。

**基本面評分：5.1/10** — 低於中位數，不符合基金與機構投資組合的"A"級標準。

建議跟蹤進展，除非 (1) FCF 於2026年下半年恢復正向，(2) 管理層清晰披露Vogtle完成時程與成本確定性，(3) 股價調整至P/E <20x 反映風險溢價，否則宜保持謹慎立場。
