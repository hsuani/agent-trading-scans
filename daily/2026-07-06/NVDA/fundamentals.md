# 基本面分析 — NVDA 截止 2026年7月6日

## 執行摘要

### 估值解讀

**Trailing P/E 31.3倍 vs Forward P/E 16.5倍的落差分析**

這個落差反映市場對NVDA未來增速放緩的預期：
- Trailing P/E基於過去12個月$6.70 EPS，反映當前估值相對已實現盈利
- Forward P/E基於預期未來12個月~$12.75 EPS，預示2027年淨利約$215B（同比+79%）

若2027年實現79%增長，Forward P/E 16.5x則代表合理估值水準。

**相對成長性評估**

PEG比0.63（低於1.0健康線）顯示NVDA的增速仍足以支撐當前估值：
- 若Year-1增速75%：PEG = 31.27 / 75 = 0.42 ✓ (非常便宜)
- 若Year-1增速50%：PEG = 31.27 / 50 = 0.63 ✓ (略顯便宜)
- 若Year-1增速30%：PEG = 31.27 / 30 = 1.04 ✗ (開始昂貴)

**關鍵風險：持續高速成長的必要性**

若AI資料中心支出在2027-2028年進入飽和期，增速從目前65%跌至20-30%，則：
- 合理Trailing P/E應為18-22x（業界水準）
- 當前估值面臨30-40%下行空間（股價目標$147-$181）

EV/EBITDA 30.8倍及Price/Sales 20.4倍均顯示市場對AI超級週期的高度溢價，但與PEG支撐一致。

## 紅旗與關注點

1. **估值高企與增速下行風險** - Trailing P/E 31.3倍、Forward P/E 16.5倍均處高位。若2027年增速未能達75%+，估值面臨20-40%回調空間。

2. **毛利率下行趨勢** - 2026年毛利率從75%(2025)降至74.14%，後續產品組合調整與競爭可能進一步壓低至68-72%，衝擊淨利率至50%以下。

3. **地緣政治升級風險** - 美中科技戰升溫，對華銷售管制已對營收產生約5-10%壓力，若進一步升級，可能對資料中心與邊緣AI出口造成15-20%影響。

4. **供應鏈依賴集中** - 100%依賴台積電先進製程代工(N3/N2)，台灣地緣風險與產能瓶頸為長期隱患。

5. **競爭形勢轉變加速** - AMD EPYC在雲計算市場追趕加快，Google TPU、Meta MTIA等自研晶片成熟度提升，市場份額可能從80%+逐步下降至70-75%。

6. **應收帳款與存貨增長** - 應收增加67%、存貨增加112%，雖為正常的銷售增長反映，但需監控應收天數進一步延長與庫存堆積風險。

7. **營運資本惡化** - FCF/NI從83.5%(2025)降至80.6%(2026)，營運資本需求上升，若客戶付款週期進一步延長，現金流可能受到明顯衝擊。

8. **成長率可持續性質疑** - 若資料中心設備支出在2027-2028年進入飽和期（預期概率40-50%），增長將轉向軟體與邊緣應用（低毛利），當前估值難以維持。

## 結論

NVDA呈現營收、利潤、現金流全面強勁的財報表現，淨利率55.64%為全球科技股罕見水準，自由現金流$96.7B足以支撐積極的股份回購($40.09B)。資產負債表堅若磐石，現金$62.6B無債務壓力，流動比3.44x反映極強流動性。基本面評分滿足PASS標準（營收成長+65.3% >> 15%、FCF/NI 80.6% >> -1）。

然而，當前估值(trailing P/E 31.3x、EV/EBITDA 30.8x)已充分反映AI超級週期預期，後續上升空間受限於：

1. **成長率可持續性** - 65%的營收增長能否維持至2027年是最關鍵變數，市場預期逐步放緩至30-50%
2. **毛利率前景** - 若競爭加劇推低至68-70%，淨利率將受明顯衝擊至50%以下
3. **市場飽和信號** - 若資料中心加速器支出在2027年開始進入平台期，增速將陡峭下降

**建議監控重點**：

- **短期 (6-12個月)** 密切監控Q1、Q2 FY2027財報中毛利率走勢、客戶備貨計畫與GB200/GB600供貨節奏
- **中期 (12-24個月)** 評估AI晶片市場需求是否如預期軟著陸，競爭對手份額侵蝕程度，特別是AMD與自研晶片進展
- **風險管理** 設定止損位於Forward P/E 12-13倍(對應股價$156-$170)，止盈位於Forward P/E 20倍(對應股價$260-$275)
