# Conservative risk view — EQIX

## Where trader is too aggressive

**估值論點被低估嚴重度**：提案本身已承認 P/FFO 25.6x 嚴重高估，但即使「容忍」現有 ≤1.0% NAV 倉位仍屬過寬。基本面分析的利率情境表已自我揭示關鍵矛盾——在四種情境中，包括「超級牛市」（10年美債 2.5%、WACC 5.5%）的隱含公允價值 $774，**相較現價 $1,089 仍下跌 -29%**。換言之，買進方自己的 DCF 框架在每一個利率情境下都指向負報酬，卻仍持倉 1.0% NAV。

**PRICE_DATA_UNAVAILABLE 使停損管控失效**：無即時報價，無法確認 ATR、動態支撐位或精確停損距離，倉位風險實為盲區。這本身就是減倉理由。

**內部人士$9.6M 售出被低估**：執行主席 Charles Meyers 於 $1,081–1,090 賣出 $5.6M，CPO Brandi Galvin Morandi 於 $1,076 賣出 $4.0M——成交價恰在現價 $1,089 附近。分析師報告以「規模相對市值微不足道」輕描淡寫，但兩位最接近公司資訊的高管同時在估值高峰套現，不應被忽略。

**新 CFO 3 個月上任 + $40 億 atNorth 整合**：Olivier Leonetti 於 2026-03 接任，至今不足 120 天即面臨 $40 億跨境收購整合，執行風險被提案評為「穩妥」過於樂觀。

**超大規模廠商自建威脅時間軸被壓縮**：2031 年 2/3 容量自建的威脅從「長期風險」可能提前反映於 2026–2027 年分析師預期修正與倍數壓縮，並非遙遠事件。

## Tail scenarios

- **Scenario A（概率 25%）**：FOMC 7/29 維持利率不動，Q2 AGB 環比持平 → P/FFO 倍數收縮至 18–20x → 隱含股價 $765–$850，跌幅 **-22% 至 -30%**，1.0% NAV 持倉損失約 **-0.25% NAV**
- **Scenario B（概率 10%）**：2026 下半年通膨反彈、聯準會升息至 5%+ → P/FFO 壓縮至 11–12x（REIT 歷史熊市倍數）→ 股價 $468–$514，跌幅 **-53% 至-57%**；若已加碼至 1.5% NAV，損失達 **-0.82% NAV**
- **Scenario C（概率 15%）**：Q2 AGB 環比萎縮 >10%（<$340M）+ 主要超大規模客戶宣布加速自建 → 市場對 25.6x 倍數喪失信心，股價急跌至 $700–750，跌幅 **-31% 至 -36%**，1.0% NAV 損失 **-0.33% NAV**

## Recommended adjustments

- **Size**：Small（≤1.0% NAV）→ **Minimal（≤0.5% NAV）**（理由：在 PRICE_DATA_UNAVAILABLE 條件下無法設定精確技術停損；基本面 DCF 在所有利率情境均指向負報酬；內部人士雙雙在現價附近套現）
- **Stop**：原條件式觸發（AGB <$340M / EBITDA <51% / FOMC 不降息）→ 維持此邏輯，但**增設任一條件觸發後不等下一季財報即減至 0.25% NAV**，不給「觀察期」
- **Entry**：禁止在 7/29 雙催化劑確認前加碼至任何規模；等待 P/FFO ≤22x（對應股價 ≤$935）方可考慮回補至 1.0% NAV
- **Consider**：以 XLK 或 VNQ Jan 2027 put spread 對沖系統性 REIT 利率風險，或持有少量 DLR 作相對價值 pair（P/FFO 14.5x 有 5–10% AI 敞口但估值溢價合理）

## Position-level $ risk

假設 NAV = $1,000,000（示例）：1.0% NAV = $10,000 持倉；股價 $1,089，約持有 9.18 股。

- **Scenario A 觸發**（-25% 跌至 $817）：損失 = $2,500 = **0.25% NAV**
- **Scenario B 觸發**（-54% 跌至 $501）：損失 = $5,400 = **0.54% NAV**（若加碼至 1.5% NAV 則 $8,100 = **0.81% NAV**）

以 0.5% NAV 倉位計算：Scenario B 最大損失壓縮至 **0.27% NAV**，可接受。現有 1.0% NAV 在 Scenario B 損失 0.54% NAV，尚在可控範圍，但加碼閾值（1.5% NAV）一旦觸發後再遭極端情境打擊，損失幅度偏高。

---

## What I'd push for

將 EQIX 倉位從 ≤1.0% NAV 削減至 ≤0.5% NAV，理由如下：基本面分析的 DCF 情境表在所有利率假設下均顯示現價高估（最樂觀情境仍 -29%），內部人士執行主席與 CPO 在 $1,076–1,090 套現 $9.6M 與現價幾乎重疊，PRICE_DATA_UNAVAILABLE 令精確技術停損失效，新 CFO 3 個月上任即主導 $40 億跨境整合屬執行風險加乘。維持觸發停損條件不變，但任一條件成立後立即減至 0.25% NAV 而非「等待觀察」。7/29 雙催化劑若同時正面兌現（FOMC 降息 ≥25bp + AGB 環比不萎縮），可視市況回補至 0.75% NAV，但完整回到 1.0% NAV 須等股價回落至 P/FFO ≤22x（≤$935）再議，不在催化劑後以高價追入。
