# ETF 基本面分析 — TLT (iShares 20+ Year Treasury Bond ETF) 截至 2026-07-11

## 執行摘要

TLT 作為美國長期國債 ETF（追蹤20年以上美債），在 2026年7月處於嚴峻的基本面環境。**淨資產流出明顯（年初至今 -$40.5B），高存續期資產面臨利率上升壓力，而鷹派聯準會主席沃什主持下近期降息無望。** 國債殖利率已上升至 20 年期 5.08%、10 年期 4.59%，對持有人本金造成實質損失風險。通膨持續高企（PCE 4.07%、CPI 4.17%），政府赤字惡化（$1.9 兆，5.8% GDP 佔比），債券供給過剩而需求不足。綜合評估：**短期（3個月內）看空**，存續期風險顯著；惟長期（6-12個月）若聯準會轉向寬鬆或衰退擴大，軋空機制（27.5% 空頭部位）和避險買盤可能觸發反轉。

## 持倉與投資策略

### 基金組成（投資範圍）

| 特性 | 規格 |
|------|------|
| **追蹤對象** | 美國長期國債指數（20年期以上） |
| **主要持倉** | 美國財政部 (US Treasury) 公債 |
| **典型券種** | 2026-2046 年到期美債 |
| **持倉數量** | 通常 40-80 只美債工具 |
| **分散度** | 高（按期限與發行者分散） |

### 存續期風險（Duration Risk）

| 指標 | 2026年7月實況 |
|------|--------------|
| **基金存續期** | **~17 年** |
| **存續期風險敞口** | 極高 |
| **1% 收益率上升的影響** | -17% 價格損失 |
| **當前環境評估** | 升息/高利率持續 → 負面 |

**風險計算範例**：
- 若 20 年期美債殖利率從 5.08% 上升至 5.58%（+50bp），TLT 淨資產價值將下跌約 8.5%
- 若升至 6.08%（+100bp），損失約 17%
- 若回落至 4.58%（-50bp），漲幅約 8.5%（軋空場景）
