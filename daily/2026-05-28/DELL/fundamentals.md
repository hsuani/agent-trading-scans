# Fundamentals — DELL (2026-05-28)

## Executive Summary

戴爾科技(DELL)在2026財政年呈現強勁的營收成長與獲利復甦，營收年增39.5%至1,135.4億美元，淨利潤年增29.5%至59.4億美元，反映出AI基礎設施需求高漲驅動的企業伺服器與儲存業務動能。然而，高負債(總債務31.5億美元、淨債務19.98億美元)、負面股東權益(-24.7億美元)與較高的利息費用(年息13.9億美元)持續對財務穩定性造成壓力。當前本益比35.2倍(遠期11.9倍)存在高估風險，儘管FCF品質改善(FCF 85.5億美元、FCF/NI比95%)指標向好。

---

## Revenue & Profitability

### 營收成長
- **FY2026(截至2026年1月31日)**：113.54億美元
- **FY2025**：95.57億美元，年增 **+18.8%**
- **FY2024**：88.43億美元，年增 **-13.6%** (受2023年低基數)
- **3年CAGR (FY2024–2026)**：約 **+12.8%**

營收在FY2026大幅反彈，反映Infrastructure Solutions Group (ISG)的AI伺服器與高性能儲存需求強勁，以及整體企業IT基礎設施升級週期啟動。

### 毛利潤分析
- **FY2026 毛利**：22.71億美元 (毛利率 **20.01%**)
- **FY2025 毛利**：21.25億美元 (毛利率 **22.24%**)
- **FY2024 毛利**：21.07億美元 (毛利率 **23.84%**)
- **FY2023 毛利**：22.69億美元 (毛利率 **22.17%**)

毛利率下降至20.01%，較過去三年平均(22.75%)低200個基點，顯示組件成本上升與產品組合改變(AI伺服器毛利率通常低於傳統產品)的壓力。

### 營業利潤分析
- **FY2026 Operating Income**：84.46億美元，營業利潤率 **7.43%** (報告數據為8.15億美元)
- **FY2025 Operating Income**：65.56億美元，營業利潤率 **6.86%**
- **FY2024 Operating Income**：59.33億美元，營業利潤率 **6.71%**
- **營業利潤率趨勢**：緩慢改善，但仍低於科技硬體業界標準(8-12%)

SG&A費用雖在FY2026降至111.19億美元(相比FY2025的115.33億美元)，但營業槓桿仍有限。

### 淨利潤分析
- **FY2026 淨利潤**：59.36億美元，淨利潤率 **5.23%**
- **FY2025 淨利潤**：45.92億美元，淨利潤率 **4.80%**
- **FY2024 淨利潤**：33.88億美元，淨利潤率 **3.83%**
- **稀釋EPS (Diluted EPS)**：FY2026為8.68美元(較FY2025的6.38美元增30.9%)

淨利潤成長動力由營業利潤與利息費用變化共同驅動。

### 股本回報率 (ROE)
- 股東權益為負數(-24.7億美元)，ROE無法有意義計算。負面權益反映累積虧損與回購政策對資本結構的侵蝕。

## Cashflow & Balance Sheet

### 現金流品質

#### Operating Cash Flow (營運現金流)
- **FY2026**：111.85億美元 (+147% YoY)
- **FY2025**：45.21億美元
- **FY2024**：86.76億美元
- **FY2023**：35.65億美元

FY2026營運現金流大幅改善，主要由應付帳款增加(+126.65億美元)、應收帳款減少的季節效應驅動。

#### Free Cash Flow (自由現金流)
- **FY2026**：85.52億美元 (+357% YoY)
- **FY2025**：18.69億美元
- **FY2024**：59.20億美元
- **FY2023**：5.62億美元

FCF大幅反彈，反映運營效率改善與資本支出相對穩定(CapEx FY2026: 26.33億美元)。

#### FCF / Net Income Ratio
- **FY2026**：85.52 / 59.36 = **1.44**（高於0.9臨界值，說明FCF品質優良）
- **FY2025**：18.69 / 45.92 = **0.41**（品質較差，反映營運現金轉換困難）
- **FY2024**：59.20 / 33.88 = **1.75**（優質）

FY2026 FCF/NI比1.44顯示現金轉換效率恢復，儘管應付帳款變化幅度大(可能包含季節與供應鏈調整)。

#### FCF Margin
- **FY2026**：85.52 / 113.54 = **75.3%**（相對FCF營運能力強）
- **FY2025**：18.69 / 95.57 = **19.6%**
- **FY2024**：59.20 / 88.43 = **66.9%**

### CapEx 與資本配置
- **FY2026 CapEx**：26.33億美元，佔營收 **2.32%**
- **FY2025 CapEx**：26.52億美元，佔營收 **2.77%**
- **FY2024 CapEx**：27.56億美元，佔營收 **3.12%**
- **FY2023 CapEx**：30.03億美元，佔營收 **2.93%**

CapEx支出穩定且低於營收2.5-3%，表明公司資本需求適度，允許高FCF。

### 股票回購
- **FY2026 回購**：64.04億美元 (上升35.7% YoY)
- **FY2025 回購**：31.65億美元
- **FY2024 回購**：24.52億美元

高額回購抵消獲利，每年回購額相當於FCF的70-80%，反映優先級偏向股東回報而非償債。

### 股息
- **FY2026 股息**：14.59億美元，覆蓋率 = FCF (85.52) / (股息14.59 + 回購64.04) = **0.97**（緊張）
- **股息率**：2.52 / 305.32 = **0.83%**（偏低，相對科技同業）
- **支付比率**：2.1 / 8.67 (歷史EPS) ≈ **24.2%**（保守）

### 資產負債表健康狀況

#### 債務與槓桿
- **總債務 (Total Debt)**：31.50億美元
  - 流動債務 (Current Debt)：7.99億美元
  - 長期債務 (Long-term Debt)：23.51億美元
- **現金**：11.53億美元
- **淨債務 (Net Debt)**：31.50 - 11.53 = **19.97億美元**
- **淨債務 / EBITDA**：19.97 / 11.85 = **1.69x**（中等水平，可接受但有升高傾向）
- **債務 / 權益比**：不適用(股東權益為負)
- **利息覆蓋比 (EBIT / Interest Expense)**：8.823 / 1.56 = **5.66x**（足夠）

#### 流動性指標
- **流動比率 (Current Ratio)**：57.60 / 63.27 = **0.91**（低於1.0，輕度風險）
- **速動比率 (Quick Ratio)**：0.594（低於0.5-1.0建議值，流動性偏緊）
- **營運資本 (Working Capital)**：-56.67億美元（負面，反映現金集中度與應付帳款延遲支付）

負面營運資本並不罕見於科技硬體公司(Dell在供應鏈中的談判力強)，但需警覺應收帳款增長。

#### 股東權益
- **淨資產 (Stockholders' Equity)**：-24.70億美元
- **每股淨資產 (Book Value)**：-3.788美元
- **淨有形資產 (Tangible Book Value)**：-265.50億美元

負面權益反映：
1. 累積虧損歷史(FY2023-FY2025期間)
2. 高額回購耗盡權益(庫存股14.53億美元)
3. 重大收購整合(商譽19.55億美元)

此結構雖反映激進資本管理，但限制籌資靈活性與抗衝擊能力。

## Valuation

### 絕對本益比 (P/E Multiple)
- **Trailing P/E**：305.32 / 8.67 = **35.2x**
- **Forward P/E**：305.32 / 17.25 = **17.7x**(基於FY2027預期EPS)
- **PEG Ratio**：1.22(假設EPS成長率高於12%)

**評估**：
- Trailing P/E 35.2x處於高估區間(歷史同業平均12-18x)
- Forward P/E 17.7x更合理，但仍高於(科技硬體平均14-16x)
- PEG < 1.5表示成長潛力部分抵銷估值

### EV/EBITDA Multiple
- **Enterprise Value**：217.89億美元
- **EBITDA (FY2026)**：11.85億美元
- **EV/EBITDA**：217.89 / 11.85 = **18.4x**

高於科技硬體業界中位數(12-15x)，反映AI周期高估。

### 價格營收比 (P/S)
- **Price-to-Sales (Trailing 12M)**：1.75x
- **營收(LTM)**：113.54億美元
- **市值**：198.33億美元

**評估**：
與科技硬體業平均(1.2-2.0x)相當，未顯著溢價。

### 價格自由現金流比 (P/FCF)
- **FCF (FY2026)**：85.52億美元
- **P/FCF**：198.33 / 85.52 = **2.32x**
- **FCF Yield**：85.52 / 198.33 = **43.1%** (理論反向)

P/FCF 2.32x屬合理範圍(3-5x為昂貴，1-2x為便宜)，但FCF yield計算要扣除股息與回購。**調整後：** (85.52 - 14.59 - 64.04) / 198.33 = 3.1% / 市值，相對股債收益率考量，收益率偏低。

## Key Catalysts

### 短期催化劑 (未來3個月)

1. **FY2027 Q1 預期(2026年5月28日後發布)**
   - 下一個earnings日期：2026-05-28(今日) EPS estimate 2.96美元
   - AI伺服器需求持續性評論
   - 毛利率穩定度(成本壓力緩解跡象)

2. **供應鏈與庫存調整**
   - 庫存在FY2026升至104.37億美元(較FY2025的67.16億美元升55%)，預示準備應對市場需求或供應鏈建立安全庫存
   - 應收帳款亦升至260.43億美元(+67% YoY)，營運現金流受季節波動影響

3. **AI基礎設施週期確認**
   - ISG segment(伺服器、儲存)的增速與毛利率動向至關重要

### 中期催化劑 (6-12個月)

1. **利率環境與融資成本**
   - 當前淨債務占市值10.1%，但年利息費用13.9億美元(對EBIT 8.82億元形成下行壓力)
   - 若美聯儲降息，融資成本下降將改善利潤

2. **競爭態勢**
   - AI伺服器市場新進者(如自建伺服器廠商)與傳統競爭(HPE、Lenovo)的威脅
   - DELL在ISG中的市場佔有率與定價能力變化

3. **CSG segment復甦(消費/SMB)**
   - 筆電與工作站業務(Client Solutions Group)在企業更新週期中的復甦

### 風險因素

1. **估值高估風險**
   - Trailing P/E 35.2x若不能被EPS高增長所支撐，調整幅度可達20-30%

2. **毛利率壓力**
   - AI伺服器增量可能進一步稀釋毛利

3. **負面資本結構**
   - 股東權益為負，限制籌資彈性
   - 若發生景氣衰退，籌資成本大幅上升風險高

4. **高額回購政策(年均50-64億美元)**
   - 優先級高於債務削減(淨債務未見明顯下降)
   - 若現金流反轉，政策難以維持

5. **內線大規模賣出(Silver Lake 6.75+8.13億美元)**
   - 機構投資者變現升值，暗示高位減持
   - 與股價創52周高同步，具頂部信號意義

6. **應收帳款與庫存激增(+67% & +55% YoY)**
   - 應收帳款260.43億美元可能反映銷售條件寬鬆或客戶支付延遲
   - 庫存104.37億美元積累可能在需求放緩時形成減值風險

7. **流動性偏緊(Current Ratio 0.91)**
   - 雖有營運現金流支撐，但短期償付能力受限
   - 若營運現金流反轉，風險升高

8. **利率敏感性(年利息13.9億美元)**
   - 隸屬於高感息族群，美聯儲升息環境中邊際利潤受壓

9. **ISG業務集中度高**
   - AI伺服器與儲存需求為主要成長動力
   - 若此週期快速結束或客戶自建，營收風險高

10. **競爭壓力**
    - 新興廠商(如Supermicro、自建伺服器)與傳統競爭對手(HPE)蠶食市佔
    - 毛利率保護空間有限
