# EQIX 基本面分析 — 2026-05-30

## 執行摘要

Equinix (EQIX) 是全球領先的資料中心房地產投資信託，近期財務表現強勁。2025 年營收達 $9.22 十億美元（同比成長 5.4%），EBITDA $4.10 十億（邊際率 44.5%），淨收入 $1.35 十億（成長 65.6%）。公司通過穩健的營運現金流、積極的資本部署和 1.84% 的股息收益率維持營運，但高杠桿率（淨債務 $17.19 十億，債權益比 162.96%）和 2025 年 FCF 轉負（-$4 億）引發增長與償債平衡的關注。目前估值具有挑戰性：本益比 74.07x（遠高於歷史中位數），前瞻本益比 55.56x，預示增長預期已大幅融入股價。

## REIT 特定指標（FFO/AFFO 估算、股息分析）

### FFO（可分配基金）估算

根據年度資料：
```
REIT FFO = Net Income + D&A - Gains on Sales

2025: $1,350M + $2,066M - $1M = $3,415M ≈ $34.76/share
2024: $815M + $2,011M - $18M = $2,808M ≈ $29.29/share
2023: $969M + $1,844M - $5M = $2,808M ≈ $29.88/share
```

FFO 2025 年估值 $34.76/share，較 2024 年成長 18.6%。

### AFFO（可調整 FFO）估算
```
假設性 AFFO (減去 capex 中維護部分，約營收 4-5%):
2025: FFO $3,415M - Maintenance Capex (~$400M) = $3,015M ≈ $30.63/share
推定 AFFO 邊際率：33%（健康）
```
