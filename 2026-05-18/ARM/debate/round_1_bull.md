# Bull Case Round 1 — ARM

## Thesis（一句話）
ARM 是全球 AI 運算基礎設施唯一不可繞過的 IP 稅收機，Armv9 滲透率從 25% 邁向 60-70%、資料中心授權營收同比翻倍、AGI CPU 被 Meta/OpenAI/Cloudflare 採用，三重引擎驅動未來三年 EPS 複合成長超過 35%，當前股價提供充分進場機會。

---

## Growth Drivers

- **Armv9 授權升級引擎**：Armv9 目前佔授權營收 25%，公司長期目標 60-70%。Armv9 授權費約為 Armv8 的兩倍，意味著在出貨量不變的前提下，單純架構升級即可帶來授權營收翻倍潛力。每個百分點的滲透率提升，都直接落入近乎零邊際成本的授權利潤。

- **資料中心授權爆發**：Q4 FY2025 財報顯示資料中心授權營收同比翻倍，hyperscaler CPU 市佔率達 50%（AWS Graviton、Ampere、Nvidia Grace 均採 ARM 架構）。Counterpoint Research 預測 2029 年自定義 AI 伺服器 CPU 中 ARM 佔有率將從當前 25% 衝至 90%，ARM 是這條跑道唯一的「路基擁有者」。

- **AI 推理 CPU 設計勝出**：ARM AGI CPU（136 核，推理優化）已獲 Meta、OpenAI、Cloudflare 首批採用，AGI CPU 需求量達 $2B，為 ARM 打開全新的高單價授權池。推理工作負載從 GPU 向 CPU 傾移的長期趨勢，直接放大 ARM 每顆晶片的授權費收入。

- **汽車設計勝出**：ARM 佔有 65% ADAS 市場與 85% 車用資訊娛樂市場。電動車與自動駕駛的算力需求密度遠高於傳統 ECU，每輛車的 ARM IP 授權費用將隨架構升級（Armv9 車規版）持續提升，汽車成為第三條成長曲線。

- **營收 CAGR 與規模槓桿**：FY2023-2025 營收 CAGR 20.5%，毛利率 96.9%——每一塊新增授權收入幾乎 100% 轉換為毛利，規模槓桿極為罕見。FY2026E 分析師共識 EPS $3.05，YoY 成長幅度巨大。

---

## Moat（護城河）

ARM 的護城河由三層構成，缺一不成競爭：

1. **生態系鎖定**：全球超過 150 億顆晶片每年採用 ARM 架構，數十萬名工程師的 toolchain、軟體庫、作業系統優化均圍繞 ARM ISA 建立。轉移成本以十億美元計算，沒有任何客戶能在五年內完整遷移。

2. **定價主導權**：ARM 是全球唯一能在 CPU ISA 層向 Apple、Qualcomm、Amazon、Nvidia 同時收費的公司，且隨架構升級單方面調漲授權費，客戶無力拒絕（Qualcomm 最終仍需使用 ARM）。

3. **Fab-less 極致資本效率**：96.9% 毛利率、無晶圓廠、無庫存，ROE 持續改善至 11.3% 且方向向上。每一個新設計勝出不需額外資本支出，邊際報酬率接近無限。

## Rebuttal to Bear Round 0

（本輪為 Round 1，無先前熊方報告需反駁。以下預先化解最常見熊方論點。）

- **熊方論點：「P/E 240 倍，估值荒謬。」**
  反駁：追蹤 P/E 因 FY2024 一次性重組費用失真；前瞻 P/E 67.8× 基於 FY2026E EPS $3.05，考慮 35%+ EPS 成長率，PEG 約 1.9×，對全球唯一 CPU IP 壟斷者而言合理。

- **熊方論點：「FCF 崩潰 83%，現金流品質差。」**
  反駁：FCF 下滑源於應收帳款激增 $7.43 億，本質是「時間差」而非「損失」——大型授權合約（多年期預付或分期）的應收帳款最終必須回收。淨現金 $24.69 億確保公司無流動性危機，FY2026 應收帳款正常化後 FCF 將大幅反彈。

- **熊方論點：「FTC 反壟斷調查是商業模式核心威脅。」**
  反駁：FTC 歷史紀錄顯示科技 IP 授權案多以「行為修正令」結案，而非強制業務拆分。ARM AGI CPU 市佔仍微不足道，不構成壟斷濫用基準。調查本身反而間接確認了 ARM 在 AI CPU 市場的戰略地位，為 AGI CPU 做了免費廣告。短期股價承壓是買入機會。

- **熊方論點：「內部人士全面拋售，管理層沒信心。」**
  反駁：高管出售股票有 90% 以上屬於預定 Rule 10b5-1 分批套現計畫，係財富多元化而非看衰公司前景。同期 Capital Research Global Investors 淨增持 +1.34%、Schroder +1.02%、Van Eck +43%，機構聰明錢大幅加碼，抵銷內部人士賣壓。
