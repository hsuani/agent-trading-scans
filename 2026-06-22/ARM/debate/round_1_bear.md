# Bear Case Round 1 — ARM

## Thesis（一句話）
ARM 以 Forward P/E 142x、EV/EBITDA 438x 的泡沫估值定價，市場隱含 FY2027 淨利潤需暴增 263% 至 $3.29B，但客戶集中、RISC-V 侵蝕、自製 CPU 渠道衝突與全體高管系統性拋售，共同構成一個安全邊際歸零、下行風險超 50% 的做空良機。

---

## 需求 / 市場風險

**客戶集中是致命弱點**
Apple、Qualcomm、Amazon 合計估計佔版稅收入 60-70%。三者均在積極發展自有 CPU 架構（Apple Silicon 自研、Qualcomm Oryon 系列、AWS Graviton 自設計）。ARM 的版稅護城河與客戶自製化趨勢直接對立——授權客戶愈強大，繞過 ARM 標準 IP 的動機愈強，版稅率愈可能受壓。

**RISC-V 蠶食周邊市場**
RISC-V 開源 ISA 在 32 位 IoT、嵌入式控制器市場已取得實質份額。SiFive、Alibaba T-Head、StarFive 持續推進量產，ARM 在低端市場的版稅入口正被無成本替代品侵蝕。若 RISC-V 向中高端移動/伺服器延伸（RISC-V 64 位生態系加速中），ARM 的授權模式將遭受結構性衝擊。

**中國出口管制未解除**
中國市場佔 ARM 版稅收入比例可觀（華為海思、中芯國際設計鏈）。現行美國出口限制若擴大至 ARM ISA 授權層面，或中國廠商加速自研 RISC-V 方案，版稅缺口可能達 10-15%，直接衝擊已被市場定價為「確定成長」的 FY2027 EPS。

---

## 毛利 / 現金流風險

**CapEx 激增侵蝕 FCF**
FY2026 CapEx 從 $239M 暴增至 $575M（年增 141%，佔營收比 11.7%），淨 PPE 從 $420M 躍升至 $1.22B。ARM 從純 IP 授權商跨界至 AGI CPU 自製，資本支出結構性升高已不可逆。若 AGI CPU 客戶需求（$2B 預訂）未能如期兌現，FCF 將在 FY2027-2028 受到持續壓縮，高達 P/FCF 494x 的估值將更難辯護。

**AGI CPU 渠道衝突壓縮版稅空間**
ARM 自製 AGI CPU 並直接銷售給 Oracle、Meta、OpenAI，等同與 Nvidia（Vera CPU）、Qualcomm、AWS（Graviton）等核心授權客戶正面競爭。New Street Research 降評時明確指出：客戶可能視 ARM 為競爭者而降低授權意願，威脅現有版稅收入基礎。這是 ARM 商業模式歷史上從未出現過的結構性矛盾。

**R&D 強度達 56% 營收**
FY2026 R&D 支出佔營收 56%，SG&A 佔 23.4%，合計運營費用接近 80% 營收，即使毛利率 97.5%，真實 FCF 邊際仍受壓。若收入成長放緩至 15% 以下，利潤槓桿效應將急速消失。

---

## 資產負債表風險

**SoftBank 90% 控股懸劍**
SoftBank 持有 ARM 約 90% 股份。2024-2025 年 SoftBank 曾因財務壓力嘗試部分減持。若 SoftBank 面臨再融資壓力或投資組合需求，大規模配售股票將壓制股價，且因流通股僅佔 10%，任何大量出售都將造成不成比例的跌幅。這是公開市場投資者承受但未獲補償的隱性風險。

**無分紅、無回購、無資本回報**
FY2023-2026 零回購、零分紅。估值 $469B 市值的公司沒有任何資本回報機制，投資者僅依賴股價上漲，安全網完全缺席。

## 估值風險

| 情境 | P/E 倍數 | FY+1 EPS 假設 | 目標股價 | 較現價跌幅 |
|------|---------|--------------|---------|-----------|
| 基準熊市 | 50x | $2.00（指引不達預期） | $100 | **-76%** |
| 嚴重熊市 | 35x | $1.50（客戶流失 + RISC-V） | $52.5 | **-87%** |
| 溫和熊市 | 70x | $2.50（成長放緩但保持） | $175 | **-58%** |

**現價 $417.88，Forward P/E 142x 意味著市場定價 FY2027 EPS $3.084。** 這需要淨收入從 FY2026 實績 $904M 在一年內成長至 $3.29B（+263%）。ARM 歷史最佳單年 EPS 成長率為 +111.7%（FY2025），且係從低基期反彈。連續兩年 +263% 在 IP 授權商歷史中無前例可循。即使給予科技 IP 龍頭 50x P/E 的高溢價，EPS 達 $2.00 的情境下目標價僅 $100，較現價下行 76%。

## 競爭 / 監管威脅

**Morgan Stanley 降評 + Goldman Sachs 降至 Sell**
Morgan Stanley 於 2026-04-07 將目標價設為 $150（當前價格的 36%），預計 FY2027 成長趨緩、需求軟化。Goldman Sachs 降至 Sell，目標價 $120。這兩家機構均為 ARM 主要機構持股人，其降評意涵尤為深遠——即使最了解公司的大股東也開始認定股價已嚴重超前基本面。

**x86 反撲與 AMD Venice 威脅**
AMD EPYC "Venice"（Zen 6）以 TSMC 2nm 量產，最多 256 核、記憶體帶寬 1.6TB/s，在通用計算仍具顯著優勢。企業工作負載向 ARM 遷移的摩擦成本高，x86 軟體生態系統（Windows Server、VMware、SAP）的惰性不可低估，ARM 伺服器份額成長曲線可能遠比 Bernstein「2029 年 90%」的預測平緩。

## 技術面風險（Tactical）

- **關鍵崩跌位**：$368.28（MA20）為首道支撐；若失守，次級支撐 MA50 $269.89 距今跌幅已達 35%
- **距 MA200 偏離達 +146.9%**：歷史上當股價偏離 200 日均線超過 100% 時，均值回歸壓力極大，修正通常超過 40%
- **20 日年化波動率 118.6%**：高波動率為雙面刃，任何利空消息（指引不達、分析師降評）均可觸發單日 10-20% 跌幅
- **BB %B = 0.78**，Bollinger 上軌 $456.99 僅距現價 $39，繼續上行空間有限，而下軌 $279.56 距今跌幅 33%
- 1 個月回報 +62.8%、3 個月回報 +215.7%：過度快速的上漲本身即是拋售信號，動能消退後的回撤往往超出預期

## 反駁多方「版稅護城河」論點

**多方論點**：ARM 掌控全球 99% 智慧型手機 CPU ISA 授權，每顆晶片皆收版稅，具備不可取代的網路效應與轉換成本。

**熊市反駁**：

1. **護城河正在被客戶自建繞過**：Apple 自研 CPU 核心已不採用 ARM 的「公版」Cortex 設計，僅授權 ISA，版稅率因此較 Cortex 授權低。若更多客戶效仿（Qualcomm Oryon 已是前例），ARM 版稅率結構性走低。

2. **AGI CPU 自製破壞授權信任**：ARM 從 IP 授權商跨界至 AGI CPU 直銷，已成為核心授權客戶的競爭者。這不只是商業模式衝突，而是對整個授權生態的信任破壞——Nvidia、Qualcomm 等公司現在必須評估是否繼續擴大對一個競爭對手的 IP 依賴。

3. **版稅護城河無法支撐 142x Forward P/E**：即使接受 ARM 的護城河論述，半導體 IP 商的合理估值區間（類比 Synopsys、Cadence）為 P/E 30-60x。ARM 當前估值是 Synopsys 的 3-5 倍，不存在任何可量化的基本面理由。

4. **RISC-V 已證明 ISA 本身非不可替代**：RISC-V 在 IoT、嵌入式系統取得實質市占後，正向行動及伺服器推進。「ISA 不可替代」的前提已被市場行動否定。

## 信心評分

**信心：4/5**

依據：
- 估值偏離基本面的幅度有明確數據支撐（EV/EBITDA 438x vs 行業 12-20x）
- 高管全員拋售方向一致，無任何反向信號
- 兩家主要機構（Morgan Stanley、Goldman Sachs）均已降至 Sell/Neutral，目標價 $120-150
- AGI CPU 自製所造成的渠道衝突風險為新的、尚未被市場充分定價的結構性風險
- 扣分：技術面動能仍強（RSI 64，MACD 正值，MA 全線多排），短期可能繼續上漲；做空時機判斷困難，ATR $34.81 意味著逆向持倉的短期痛苦可能顯著
