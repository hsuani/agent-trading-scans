# Bull case round 1 — ARM

## Thesis（1 句話）
ARM 正從純 IP 授權商蛻變為資料中心 CPU 製造商，AGI CPU 客戶需求已逾 $2B、代理 AI 催生 CPU 文藝復興，在護城河深厚的版稅模式之上疊加高毛利自有晶片營收，支撐 2030 年前 $15B 營收願景，當前股價雖貴但對應一個非線性躍升式成長故事。

---

## Growth drivers（成長驅動因素）

- **AGI CPU 批量生產，需求超 $2B**：ARM 35 年來首次推出自有資料中心 CPU，截至 2026 年 5 月客戶訂購需求已超過 $2B，較 3 月發表會翻倍。Oracle Cloud Infrastructure、Meta、Cerebras、OpenAI、Cloudflare 均已簽約或部署（news.md）。這是從「授權費 + 版稅」雙腿進化為「授權費 + 版稅 + 產品利潤」三腿的歷史性轉折。

- **代理 AI 帶動 CPU 密度需求爆發**：代理工作流中 CPU 負責工具調用、API 路由、記憶體管理，佔整體延遲 50–90%。超大規模資料中心需大幅提高 CPU:GPU 比例（news.md）。ARM AGI CPU 136 核 3.2GHz 耗電 300W，相比 x86 128–192 核 390–500W，能效優勢直接映射為每伺服器機架 TCO 節省。Counterpoint Research 預測 ARM 在 2029 年前驅動 ≥90% 定制 AI 伺服器 CPU，較 2025 年 ~25% 大幅成長（news.md）。

- **Armv9 版稅率提升 + 超大規模採用擴大**：FY2026 營收 $4.92B，3 年 CAGR 22.6%，連續超過 15% 閾值（fundamentals.md）。Armv9 版稅率較 Armv8 提升，且 AWS Graviton4、Google Axion、Microsoft Cobalt、NVIDIA Vera 全線採用 ARM 核心，覆蓋率拉寬使版稅基數隨超大規模 CapEx 週期遞增。

- **Arm v9 + 自有 CPU 雙軌 TAM 擴張**：純 IP 授權 TAM 受限於版稅率與出貨量，但自有 CPU 業務的 TAM 等同於整個資料中心 CPU 市場（IDC 估 2025 年 $20B+），進場即打開第二曲線。管理層指引 2030 年前衝刺 $15B 營收，對應 FY2026 $4.92B 基礎年均複合成長約 20%（news.md）。

- **移動 AI / 汽車 / IoT 版稅持續複利**：FY2026 毛利率 97.5%（fundamentals.md），近乎純 IP 業務邊際。Neural Dawn 移動遊戲 AI 展示（2026 年 H2 上線）、Arm Neural Technology Playbook 拓展遊戲開發者生態，進一步鎖定高版稅的 Armv9 生態圈（news.md）。

---

## Moat（護城河）

ARM 的護城河有三層，彼此強化：

1. **ISA 生態鎖定（switching cost 極高）**：全球已出貨逾 3,000 億顆 ARM 核心晶片，開發者工具鏈、OS 優化、SDK 均圍繞 ARM ISA 構建。客戶轉換至 RISC-V 需重新設計軟體堆疊與工具鏈，成本高且時間漫長。RISC-V 在 32 位 IoT 邊緣有競爭，但資料中心與行動主處理器短期無可取代的生態支撐。

2. **版稅複利模式（royalty flywheel）**：晶片設計授權在設計階段收取一次性費用，量產後每顆晶片收取版稅，版稅收入隨出貨量自動增長，無須追加 marginal cost。97.5% 毛利率印證此模式。Armv9 版稅率更高，出貨比例逐季上升，帶動 ASP（平均版稅每顆）向上。

3. **超大規模客戶深度綁定**：Apple（iPhone A 系列）、Qualcomm（Snapdragon）、Amazon（Graviton）、Google（Axion）、Microsoft（Cobalt）、NVIDIA（Grace/Vera）全是 ARM 客戶，且部分已成為競爭者（ARM AGI CPU 競爭 x86 份額）而非放棄授權，因轉換成本太高。這些客戶在 AI 競賽中持續加大 CapEx，ARM 版稅基數受益。

## Rebuttal to bear（對空方的回擊）

此為 Round 1，尚無正式 bear report。下方針對最常見空方質疑逐一回擊：

- **空方主張：「P/E 529×、EV/EBITDA 437×，估值嚴重泡沫」**
  反擊：傳統倍數適用於成熟、低成長公司。ARM 同時擁有（a）版稅業務 97.5% 毛利率複利引擎，和（b）剛啟動、需求 >$2B 的 AGI CPU 自有產品業務。類比 2021 年 SaaS 平台給予 30–50× EV/Revenue，ARM 目前 EV/Revenue 94.8× 確高，但若 FY2028 收入達 $9B（CAGR 延續），倍數壓縮至 ~55× — 仍高但非泡沫式不可解釋。更關鍵：Bernstein、Wells Fargo、Mizuho 三家機構分析師在充分了解財務數據後同步上調目標至 $500，不是盲目炒作。

- **空方主張：「高管全員淨賣出，信心不足」**
  反擊：fundamentals.md 明確指出賣出總值 $58.6M，僅佔市值 $469.4B 的 **0.0125%**，規模極微。且部分賣出價格為 $160–$280（3–5 月），賣出後股價仍繼續大漲，顯示並非基於對基本面的悲觀，而是正常的 RSU 多元化操作。CEO Haas 最後一筆售出在 $160 附近，此後股票漲幅超 160%。

- **空方主張：「RISC-V 威脅授權護城河」**
  反擊：RISC-V 的威脅集中在 **32 位 IoT 低端市場**，而 ARM 收入主要來自高版稅的 Armv9 行動處理器（Apple、Qualcomm）與資料中心 CPU（Neoverse/AGI）。超大規模資料中心不會因 RISC-V 生態尚不成熟而放棄現有 ARM 工具鏈與軟體最佳化投資。ARM 自有 AGI CPU 進場反而是對 RISC-V 威脅最有力的主動防守。

- **空方主張：「客戶集中，Apple/Qualcomm 佔 60–70% 版稅」**
  反擊：客戶集中是歷史遺留特徵，正在快速稀釋。AGI CPU 業務新增 Oracle、Meta、Cerebras、OpenAI、Cloudflare、Rebellions 等資料中心客戶；NVIDIA Vera、RTX Spark 均採用 ARM 核心；汽車與 IoT 版稅比例逐季上升。集中度下降是可量化的多元化過程。

- **空方主張：「中國出口管制威脅版稅 10–15%」**
  反擊：此風險已知且部分定價。ARM 的授權模式讓中國客戶在限制升級前已完成架構授權；同時 AGI CPU 新業務主要服務美國超大規模客戶，實際上降低了對中國客戶版稅的依存度。地緣政治風險是雙面刃，若禁令迫使中國客戶尋找替代（RISC-V），ARM 反而能聚焦高利率西方市場。

## Confidence（信心評分）

**4 / 5**

**理由**：多頭論據建立在三個可驗證的具體事實上：（1）AGI CPU 已批量生產且需求 >$2B，（2）FY2026 收入 $4.92B、3 年 CAGR 22.6%，（3）97.5% 毛利率護城河。三家主流投行同步上調目標至 $500，技術面動量結構完整（動量評分 7.8/10）。唯一扣分點是現有估值倍數確實極端，執行風險高（FY2027 EPS 需 263% 增長），若財報指引不及預期，股價回調 30–40% 並非不可能。持多頭立場的前提是 AGI CPU 訂單轉化進度與超大規模 CapEx 週期維持不變。
