# Investment plan — ARM as of 2026-06-22

## Directional stance
NEUTRAL — conviction LOW

> 多頭與空方均提出有據可查、具日期來源的主張，勝負差距落在「執行風險能否兌現」這一不可確認的未來事實上。技術動能雖強，但估值極端，安全邊際歸零。裁定為 NEUTRAL，等待財報驗證。

---

## Crux of debate

1. **FY2027 EPS 能否達到 $3.08（+263%）？**
   多頭相信 AGI CPU 量產（需求 >$2B）、Armv9 版稅率提升與超大規模 CapEx 週期可同步拉高淨利率至 55%。空方認為此隱含假設在 IP 授權商歷史中毫無前例，且 CapEx 激增（$575M，+141% YoY）將壓縮 FCF。此裂縫若解不開，估值倍數就無法錨定。

2. **AGI CPU 自製是否破壞核心授權信任？**
   ARM 首次直接銷售資料中心 CPU，與 NVIDIA（Vera）、Qualcomm、AWS（Graviton）等核心授權客戶形成競爭。多頭認為這是第三條收入腿，新增 Oracle、Meta、OpenAI 等買家。空方（New Street Research，2026-06-18）明確指出渠道衝突將壓低授權意願，損害版稅基礎。此矛盾能否在不拆毀護城河的前提下共存，是最難量化的結構性問題。

3. **RISC-V 威脅範圍是否侷限於 IoT 邊緣？**
   多頭認為 RISC-V 尚無能力挑戰高版稅的 Armv9 行動與資料中心 CPU 生態。空方指出 RISC-V 64 位生態正在加速，且「ISA 不可替代」的前提已被部分市場行動否定。若 RISC-V 向中高端延伸，ARM 的版稅成長路徑將出現結構性缺口。

---

## Where the bull is right

- **業務基本面健康**：FY2026 營收 $4.92B，3 年 CAGR 22.6%，毛利率 97.5%，FCF $949M，FCF/NI 105%，淨現金 $2.29B；核心指標均達標。
- **AGI CPU 需求有具體落地**：截至 2026-05，客戶訂購需求已超 $2B，Oracle、Meta、Cerebras、OpenAI、Cloudflare 等均已簽約或部署，並非純粹預期敘事。
- **版稅複利護城河真實存在**：全球 3,000 億顆 ARM 核心晶片已出貨，工具鏈生態鎖定深，Apple、Qualcomm 轉換成本極高，短期內不存在大規模出走可能。
- **代理 AI 結構性利多**：CPU 在代理工作流中佔延遲 50-90%，超大規模 CapEx 週期（Meta、Google、AWS）推高 ARM 架構伺服器需求，Counterpoint Research 預測 2029 年前 ARM 驅動 ≥90% 定製 AI 伺服器 CPU。
- **技術面動能完整**：三線黃金排列，RSI14 = 63.96（非超買），MACD 直方圖正值，動量評分 7.8/10，短期趨勢結構健全。
- **多家主流投行支持**：Bernstein、Wells Fargo、Mizuho 同步上調目標至 $500，分析師 Buy 比例 67.5%，機構持股 95.4%。

## Where the bear is right

- **估值倍數達到歷史極端**：Forward P/E 142.5×、EV/EBITDA 437.9×、P/FCF 494.3×、EV/Revenue 94.8×，遠超科技 IP 同業（Synopsys、Cadence P/E 30-60×）。市場要求 FY2027 淨利潤在一年內從 $904M 跳升至 $3.29B（+263%），在 IP 授權商歷史中無前例。
- **高管全員淨售出，方向一致**：過去 2.5 個月 CEO、CFO、CLO、CCO、首席架構師等全數淨售出（總值 $58.6M），跨越 $160-$415 不同價位，具方向一致性，部分高管（CFO、CCO）在 $380-$415 高位仍持續賣出。
- **CapEx 激增改變財務結構**：FY2026 CapEx 從 $239M 暴增至 $575M（+141%，佔營收 11.7%），淨 PPE 從 $420M 跳升至 $1.22B，從純 IP 授權商跨界 CPU 製造，資本支出不可逆轉升高，若 AGI CPU 訂單未如期轉換為遞延收入，FCF 將在 FY2027-2028 持續承壓。
- **客戶集中風險未解**：Apple、Qualcomm、Amazon 合計估計佔版稅 60-70%，三者均在積極發展自有 CPU 架構，授權客戶自製化趨勢直接壓縮版稅率空間。
- **分歧機構發出明確警告**：Goldman Sachs 降至 Sell（目標 $120）、Morgan Stanley 目標 $150（2026-04-07）、New Street Research 降至 Neutral（2026-06-18），均在充分了解財務數據後得出截然不同的結論，空方機構論據有具體估值模型支撐。
- **技術面均值回歸壓力大**：股價距 MA200 偏離 +146.9%，20 日年化波動率 118.6%，ATR $34.81，任何利空（財報指引不達、分析師降評）均可觸發單日 10-20% 跌幅；下行至 MA50 $269.89 的跌幅已達 35%。

## Net verdict

ARM 的業務基本面是真實且健康的——強勁的收入成長、極高毛利率護城河、AGI CPU 產品線有具體訂單落地。然而，現股價已將未來三至五年最樂觀的情境提前完全定價：Forward P/E 142.5× 隱含 FY2027 淨利潤需一年暴增 263%，此假設在 IP 授權商歷史中無先例可循，安全邊際歸零。多頭最有力的武器是「平台重定價」論述，但此論述需要 AGI CPU 在 FY2027 財報中以遞延收入方式確認，且淨利率展現向 55% 的明顯躍升路徑，目前尚無財務數據支撐。空方最有力的武器是估值模型本身的數學不等式——即使接受所有多頭敘事，以任何合理的 P/E 折算目標價均在 $200 以下。裁定：現價位置既不具備進攻性多頭的 R:R，也不具備逆勢做空的時機確定性（技術面動能仍強）；NEUTRAL 為最符合風險紀律的立場，等待 FY2027 Q1 財報（預計 2026 年 7-8 月）提供事實錨點。

## What would change the verdict

- **上行觸發**：FY2027 Q1 財報管理層上調全年指引至 $6.5B+，且明確揭示 AGI CPU 訂單轉換為遞延收入的時間表與規模；淨利率展現向 40%+ 擴張的季度改善跡象；超大規模客戶（Meta、Google、AWS）公告 ARM AGI CPU 正式量產規模超過 10 萬顆以上。上述任一確認，可考慮轉為 LONG（conviction MEDIUM）。

- **下行觸發**：FY2027 Q1 財報指引低於 $5.5B 或 EPS 路徑無法支撐 $2.5+；AGI CPU 渠道衝突導致 NVIDIA 或 Qualcomm 公開表態縮減授權合作；中國出口管制擴大至 ARM ISA 授權層面，衝擊版稅 10-15%；股價跌破 MA20 $368 且 MACD 直方圖轉負。上述任一確認，轉為 SHORT_OR_AVOID（conviction MEDIUM）。

- **關鍵數據點監測**：FY2027 Q1 季報（2026 年 7-8 月）的淨利率、遞延收入科目、CapEx 指引；超大規模客戶（Meta、AWS、Google）季報中 ARM AGI CPU 伺服器採購金額；Armv9 版稅佔比是否持續每季上升。
