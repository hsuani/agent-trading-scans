# Bull case round 1 — SO

## 論點(1 句話)
Southern Company 是擁有東南部 AI/資料中心電力超級週期最低風險、受監管機構認可的方式:$26.5B DOE 貸款剛剛為其史上最大資本支出週期去風險化,Q1 資料中心負載 YoY 成長 +42%,2028 年基本費率凍結加上 beta 0.36 限制下檔風險,同時 EPS 在結構性緊縮的電力市場中以監管機構核准的約 5–7% 速度複合成長。

## 成長驅動因素
- **資料中心負載飆升**:2026 年 Q1 資料中心用電 YoY +42% 帶動 EPS 超預期(調整後 $1.32 vs 前年 $1.21);GA Power 已簽約 28 個大型負載專案約 11GW(news.md)。
- **區域負載成長**:2026 年區域內約 10GW 已簽約負載成長;至 2029 年 8% 年銷售成長,**Georgia Power 達 12%**——多年期費率基礎複利機器(news.md)。
- **DOE $26.5B 貸款(5/13/2026)**:支援 GA/AL 超過 16GW 容量建置;削減 $74B 債務堆疊的資金成本並移除股權發行壓力(news.md)。
- **Vogtle 3&4 投入運轉**:核能基底現在開始貢獻盈餘,相較建造期已去風險;CEG/TLN 核能溢價可比較。
- **營收重新加速**:FY25 營收 $29.55B,+10.6% YoY;forward EPS $4.92 = +25.5% 預估成長(fundamentals.md)。

## 護城河
受監管壟斷特許權(Georgia Power、Alabama Power、天然氣分銷),由州 PSC 對費率基礎設定 ROE。24/7 韌性基載 + 新核能 = 超大規模業者所需且無法自建的精確電力組合。位於 GA 的資料中心轉換成本實際上是無限。25 年股利增長連續紀錄象徵機構資本紀律。

## 上行情境
- **基本**:20x × FY+1 EPS $4.92 = **$98.40**,從 $93.68 +5% + 3.25% 殖利率 ≈ **+8% 總報酬**(12 個月)。
- **看多**:Raymond James PT **$104**(Outperform,5/9 上調);Mizuho 亦在 Q1 後上調。重新評等至 21x 於 $4.92 = **$103**,+10% + 殖利率 ≈ **+13%**。若 2027 EPS 在 12% GA 負載成長下印至約 $5.25,20x = **$105**。
- **不對稱性**:2028 年基本費率凍結限制監管下檔;beta 0.36 表示市場拋售中的回檔結構性受抑。

## 對空方論點的反駁(預期)
- **「FCF -$2.94B」** → 反駁:FCF 為負*正是因為* SO 正在資助史上最大成長性資本支出週期($12.74B,+42% YoY)進入監管機構核准且賺取保證 ROE 的費率基礎。這是特性,不是缺陷:每 $1 資本支出都會變成未來基於費率的盈餘。DOE $26.5B 貸款現在以便宜方式資助。
- **「Net Debt/EBITDA 5.0x」** → 反駁:位於公用事業舒適區間頂端但對資本支出週期高峰是**正常**;DOE 貸款以補貼利率取代市場債務,降低有效槓桿成本。受監管現金流 + 2028 費率凍結 = 可預測的去槓桿路徑。
- **「25 筆內部人賣出、0 買進」** → 反駁:總規模約 $4–5M 相對 $105.6B 市值 = 雜訊(<0.005%)。賣出集中於 $96–97 = 在高點附近合理多元化,幾乎可確定是 10b5-1 預排。沒有官員出脫有意義的持股比例。
- **「估值較同業溢價 10–15%」** → 反駁:由(a)Vogtle 完工去風險、(b)GA 12% 負載成長 vs 同業中位數約 3–4%、(c)同業中獨有 DOE 後盾來合理化。Forward P/E 19x 於 +25% 預估 EPS 成長 = PEG 低於產業。
- **「Q1 EPS YoY 持平」** → 反駁:調整後 EPS $1.32 *超預期*,且頭條掩蓋驅動未來盈餘的 +42% 資料中心負載——費率基礎回收週期才剛開始。
