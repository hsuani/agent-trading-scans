## 積極派論點：交易員哪裡太保守

**1. 倉位 1.5% NAV — 嚴重低估不對稱性**

交易員以「高波動率、Forward P/E 偏高」為由壓縮至 1.5%，這是用錯框架。高波動率是雙向的：在動能加速的強趨勢中，波動率是燃料，不是理由縮手。MRVL 目前具備三個罕見共鳴：基本面加速（Q1 FY27 +28%，Q2 指引 +35%）、結構性被動買盤（S&P 500 納入 6/22 強制觸發）、技術趨勢完整（MA20/MA50/MA200 牛市排列，MACD 擴張）。三者同步共振時，1.5% 的倉位等同在最佳進場窗口浪費火力。信念本應定為 HIGH，而非 MEDIUM。

**2. 止損 $233 — 止損太緊，必然被 whipsawed**

ATR = $26.33，即一日正常波動即達 10%。將止損設在 $250 進場的 -6.8% 處（$250 → $233），約莫只有 0.65× ATR 的空間。這個止損在任何一個普通的盤中震盪日就會被掃掉，反而是把虧損鎖死的設計。MA20 支撐在 $208.52，市場技術結構明確在 $210 才是真正的趨勢反轉確認點。止損應對齊 $205–$208，而非提早放棄在 $233。

**3. 進場 $245–$255 — 等待是在殺 alpha**

目前市價 $263，交易員等待「回撤至 $245–$255」方才重倉。問題在於：S&P 500 納入日 6/22 距今僅 14 天，被動資金進場窗口正在倒數。被動資金不會因為股價略高而等待，它們按市值比例強制買入。等回撤可能等到 $270+，錯失整個 S&P 納入行情。現價 $263 已在 -1×ATR 支撐 $237 之上 26 點，MACD 仍在擴張，沒有理由等待。**立即以市價建倉 60%，剩餘 40% 作為 S&P 納入後動態調整保留。**

**4. 忽略 Options 不對稱槓桿**

MRVL 年化波動率 68.97%，Options 溢價定價高，但 Call Spread 可以精準控制成本。現有方案完全沒有提及 Options，這是遺漏。建議考慮：**Call Spread $265/$310，expiry 2026-07-18**（涵蓋 S&P 納入後窗口）。以目前 IV 估算，此 Spread 成本約 $8–$10/share，最大虧損即為 premium，T1 獲利 $290 附近可回收 3× 以上。用組合 NAV 0.5% 的 premium 可以複製 NAV 2.5% 的股票倉位敞口，而硬停損即為 premium 總額。

## 風險說明（絕對金額框架）

假設組合 NAV = $500,000（舉例基準）：

| 情境 | 積極派方案（2.5% NAV = $12,500 股票 + 0.5% = $2,500 options） |
|------|------|
| **最大虧損（股票部位）** | 以 $263 進場，止損 $205 → 損失率 22% → 股票部位虧損 **$2,750** |
| **Options premium 全滅** | 虧損上限 $2,500 |
| **總最大虧損上限** | **$5,250**（組合 NAV 1.05%，可接受） |
| **T1 獲利（$300）** | 股票 +$2,237 + options spread $45 → $3,375 回報 |
| **T2 獲利（$342）** | 股票 +$4,940；options 已到期，加碼財報前 |
| **B/A 不對稱比** | 最差 -$5,250 / 現實目標 +$7,175（T1 + T2 split） = **R:R 1.37**，若 T2 全達成 R:R **2.67** |

止損從 $233 放寬至 $205，帳面風險增加但消除了「被正常波動掃損」的廢損風險——那才是真正無謂的本金損耗。
