## Top 3 完整 pipeline 排序

**第一名：2317.TW（鴻海）**
NVDA GB200/GB300 全球唯一 Tier-1 組裝廠地位已由財報數字佐證（2026Q1 Rev +29.7% YoY、三率三升達 9 年高點）。Fwd P/E 13–14x 加計 3.4% 殖利率，估值具安全邊際。Entry zone NT$259–263，止損 MA20 NT$248，R:R ≈1.84（至 T1 NT$285）。唯 RSI 68.6、BB %B 0.84 顯示短線接近過熱，分批進場紀律不可省略。倉位 1.5% NAV，為三者中最大。

**第二名：DELL**
Q1 FY27 EPS +87% YoY、AI 積壓訂單 $43B 為本輪最具份量的可查核硬數據，FY27 全年 AI 營收 $50B 指引有管理層公開背書。然 RSI 78.2、BB %B 1.02、6m +151% 顯示技術面嚴重超買，現價 $305 追高 R:R 不對稱。採條件式進場：等候回落至 $255–$270 並帶量站穩後才執行，倉位 0.5% NAV。SLTA $77M 減持與 UBS PT $243 是兩項需持續追蹤的做空信號。

**第三名：HPE**
6/1 Q2 財報為唯一二元事件，多空均有 7/10 信心。Net Debt/EBITDA 6.7x 是結構性壓制，現金部位幾近耗盡（$0.58 億）。財報前僅允許 0.2% NAV Call Spread（Buy $37/Sell $42 到期 6/19）作事件曝險佔位，財報後視 EPS 及毛利率結果再決定是否升至 0.5% NAV 持股段。整體信心最低（55%），倉位最保守。

## Phase-1-only stragglers

**SMCI**：營收 +123% YoY、$13B Blackwell backlog 具結構性吸引力，但 OCF -$66.2B、淨負債 $74.8B 激增、三名高管面臨出口管制違反訴訟、治理風險評級 10/10，現階段風險複雜度不值得投入完整辯論成本。監控觸發：OCF/FCF 季度回正、訴訟和解、毛利率回升至 12%+。

**2382.TW（廣達）**：Q1 Rev +66.6% QoQ、AI server 佔比 75% 創高，基本面敘事與 2317.TW 相似，但毛利率 6.98% 下滑、FCF -NT$255B、外資 4 日連賣 60K 張、MA20 跌破 + MACD 轉空，技術面明顯弱於 2317.TW。在同為台灣 OEM AI server 受益標的的情況下，2317.TW 具更佳的性價比，廣達暫列觀察名單。監控觸發：MA20 NT$320 突破、外資連 3 日買超。

## Sector themes

**AI server super-cycle 驗證中**：五檔標的 Q1 AI 相關營收均呈雙位數至三位數 YoY 成長（DELL ISG >100%、HPE 資料中心 +382.6%、2317.TW Rev +29.7%、2382.TW Rev +66.6% QoQ、SMCI +123%），印證 NVDA GB200/GB300 供應鏈放量已非預測而是已兌現事實。

**NVDA GB200/GB300 供應鏈集中**：2317.TW（組裝）、2382.TW（伺服器機架系統）、SMCI（液冷機殼）三者均直接暴露於 NVDA 下一代 GPU 訂單，若 NVDA 產品週期或出口管制出現意外，三者同步承壓。

**估值極端分化**：DELL Forward P/E 在半年內從 10x 重新定價至 21–23x，HPE 現價已超越分析師共識目標價 30%（$37.20 vs 均值 $28.64），兩者均存在預期過高的壓縮風險；2317.TW 以 Fwd P/E 13–14x 相對美股同業屬合理偏低，是本批次估值最具安全邊際的選項。

**內部人賣壓**：DELL 關聯實體 SLTA 於 $143–145 已減持 $77M+；HPE 三名高管合計拋售逾 $758 萬，100% 賣方主導，集中在股價高點 $26.50–$30.01 區間。兩者皆為技術過熱疊加內部人賣出的負面籌碼訊號。

## 配對分析

**2317.TW vs DELL：美台 Tier-1 OEM 相對價值**
兩者同屬 AI server 組裝最直接受益者，但估值差距顯著。2317.TW Fwd P/E 13–14x vs DELL 21–23x，同樣 MEDIUM 信心，2317.TW 的 R:R 1.84 優於 DELL 0.88（T1）。若預算有限只選一，2317.TW 的進場 R:R 更佳；若同時持有，須注意兩者受相同 NVDA 供應鏈催化劑驅動，相關性高，合計不宜超過 2% NAV。

**2382.TW vs 2317.TW：台灣 OEM 同業比較**
均為台灣 AI server OEM、均暴露 NVDA GB200 供應鏈，但 2317.TW 技術面（趨勢向上、外資回補）明顯優於 2382.TW（MA20 跌破、MACD 轉空、外資連賣）。同產業相對強弱做法：長 2317.TW / 短或迴避 2382.TW，等待 2382.TW MA20 收復後再行評估。

**SMCI 法律風險隔離**：SMCI 雖有最強的 AI server 成長數據（+123%），但出口管制訴訟（$2.5B 中國轉運）加上治理評級 10/10，屬高度特異性法律風險，與行業整體趨勢脫鉤。不建議以「板塊輪動」理由買入；若現有 SMCI 多倉可考慮以 2317.TW 對沖其法律尾部風險。

## Sector-wide observations

- **共同催化劑**：2026-06-01 HPE Q2 財報（AI server 積壓單趨勢直接影響 DELL/HPE 競爭格局判斷）；2026-06-03 Computex 2026（2317.TW/2382.TW NCP 算力服務最新進展）；2026-06-10 台灣 5 月月營收（驗證 2317.TW/2382.TW AI server YoY 動能延續性）。
- **共同風險**：NVDA 出口管制升級（尤其影響 SMCI 已有法律前例）；CSP 巨頭 H2 2026 資本支出若進入消化期，全板塊同步承壓；TWD 升值持續壓縮台灣 OEM 以美元計價的毛利率。
- **擁擠觀察**：DELL 在過去 6 個月漲幅 +151%，RSI 78.2；HPE +大漲後超越機構目標價 30%；2317.TW 距 52w 高僅 -2.4%。整體板塊偏擁擠，追高風險在任何消息面衝擊下回調幅度可能超市場預期。
- **相關性群組**：2317.TW + 2382.TW 高度同向（同 NVDA 供應鏈、同台灣 OEM 資金輪動）；DELL + HPE 受美國機構法人相同事件驅動（HPE 財報即 DELL 競爭格局讀數）；SMCI 因法律因素走出相對獨立行情。切勿同時建立 2317.TW + 2382.TW 多倉而忽略集中風險。

## Action sequencing

若同時執行多個想法，建議依下列順序：

1. **2317.TW 優先**：R:R 最佳（1.84）、催化劑最近（6/3 Computex + 6/10 月營收）、倉位 1.5% NAV 分批可控，且進場條件 NT$259–263 最明確。
2. **DELL 次之**：須等待回落至 $255–$270 才進場，現價 $305 不追；若 2317.TW 已建倉，DELL 倉位限 0.5% NAV（兩者相關性高）。
3. **HPE 最後**：6/1 財報前僅 0.2% NAV Call Spread 佔位，財報後視結果決定是否啟動持股段，不與前兩者搶資金。

## Sector risk budget

三檔完整 pipeline 標的中：2317.TW（1.5% NAV）+ DELL（0.5% NAV）+ HPE（0.2%→0.5% NAV）合計上限約 **2.5% NAV**（財報前）至 **3.0% NAV**（HPE 財報後升滿）。

鑑於 2317.TW 與 2382.TW 高相關性，若後者進場，整體板塊合計不應超過 **3.5% NAV**。SMCI 在法律風險未解前建議維持零倉位。整體 OEM 板塊建議 NAV 上限 **3.5%**，以避免 NVDA 供應鏈單一事件導致集中性損失。
