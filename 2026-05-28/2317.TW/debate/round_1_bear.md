# Bear case round 1 — 2317.TW

## Thesis（一句話）
鴻海結構性困在 EMS 毛利率天花板之內，AI server 訂單高度依賴單一生態（NVDA）、客戶集中 50%+，電動車持續燒錢拖累資本回報，而現價距 52w 高僅 -2.4%，短期 R:R 嚴重不對稱。

---

## Demand / 市場需求風險

**1. AI Capex 週期反轉風險**
CSP（Meta、MSFT、Google）資本支出「超前建置」模式一旦進入消化期，AI server 出貨量可能季環比轉負。GB200 機櫃單價高、客戶採購動輒億元級，任何預算重新評估或 NVDA Blackwell 良率問題都將直接打擊出貨節奏。歷史上 EMS 廠商在 PC/手機週期反轉時，單季營收可跌 15–25%，AI server 並無免疫性。

**2. 客戶集中度極高，砍單風險集中**
Apple（手機）+ NVDA（AI server 組裝）+ Meta + MSFT 合計貢獻 50%+ 營收。任一主力客戶重新分配訂單（例如 Apple 持續降低鴻海依賴、Meta 轉向 ODM 自建）或資本支出削減，鴻海幾乎無緩衝空間。Apple 多年來刻意扶植立訊精密、和碩分散供應鏈的政策尚未逆轉。

**3. AI server 市占腐蝕壓力**
廣達（2309.TW）AI server 市占約 40%，緯創（2315.TW）積極追趕，且 NVDA 本身有動機維持多供應商政策以防止過度依賴單一代工廠。鴻海「唯一 GB200 代工」的排他性隨 GB300、GB400 新世代出現而面臨重新洗牌，44% 市占並非合約保障。

---

## Margin / 現金流風險

**1. EMS 毛利率結構性天花板 6–8%**
Q1 2026 毛利率 6.18%，雖達 9 年高點，但仍是製造業中最薄的利潤層。AI server 機櫃組裝本質上是高成本零組件（HBM、GPU、NIC）的「手工藝代工」，鴻海的附加價值極薄，定價權在 NVDA 手上。毛利率向 7–8% 的「結構天花板」進一步壓縮空間有限。

**2. TWD 升值直接壓縮 EPS**
鴻海以 USD/JPY 計價訂單收入、以 TWD 報告 EPS。2026 年以來 TWD 已明顯升值，NTD 每升 1%，USD 計價營收折算即縮水，對 EPS 直接侵蝕可達 1–2%。FY2026E EPS NT$19 的市場共識尚未充分反應 TWD 持續走強的不利匯率敞口。

**3. AI server Ramp 帶來工作資本壓力**
存貨與應收帳款快速擴張（fundamentals 報告標記為紅旗）。GB200 機櫃單台組裝成本達數百萬美元，工作資本佔用爆升，FCF 轉換率下降。若出貨時程延誤或客戶驗收拖延，現金流可能急轉直下。

**4. Foxtron 電動車持續燒錢**
EV 部門 2026–2027 年預期仍虧損，波蘭 EMP 合作尚在「評估建廠」階段，距離商業量產至少 3–4 年。全球電動車市場競爭白熱化（BYD、Tesla 價格戰），Foxtron 缺乏品牌溢價，開放平台模式能否獲客仍是未知數，每年虧損拖累整體 ROE 約 1–2 個百分點。

## Valuation 估值風險

| 情境 | P/E 假設 | FY2026E EPS | 目標價 | 較現價 NT$263 |
|---|---|---|---|---|
| 基本熊市 | 12x | NT$17（TWD 升值 + 毛利不及預期） | NT$204 | **-22%** |
| 最壞情境 | 10x | NT$15（AI Capex 週期轉向 + 毛利壓縮） | NT$150 | **-43%** |

- 目前 Trailing P/E ~19–21x 並非便宜；Fwd P/E 13–14x 的「合理」估值完全依賴 FY2026E EPS NT$19 達標。
- EPS 共識建立在：毛利率維持、TWD 不升值、AI server 出貨按計劃、Foxtron 虧損不擴大 — 四個假設同時成立的機率遠低於市場定價隱含水準。
- 若 EPS 僅達 NT$17（下修 ~10%），加上市場給予的倍數從 14x 壓縮至 12x（EMS 代工重新定價），股價下行空間達 **-22%**。

## Competitive / 監管風險

**1. 中美地緣政治與出口管制**
NVDA Blackwell 受美國出口管制限制對中國出口。鴻海在中國仍有大量製造產能（鄭州、深圳），若未來美方擴大限制或台海緊張升溫，供應鏈重組成本巨大，短期利潤衝擊難以迴避。

**2. 墨西哥/德州廠資本支出風險**
為因應「美國製造」要求新建廠房，前期資本支出大、良率爬坡慢，折舊將在 2026–2027 年大幅提升，壓縮短期 EPS。

**3. 監管/稅務風險**
FY2025 稅率從 19% 跳升至 26.7%（+7.7 個百分點），若此為結構性變化而非一次性項目，將長期侵蝕淨利率。

## Tactical 技術面風險

- **現價 NT$263，距 52w 高 NT$269.50 僅 -2.4%**：上檔阻力強，突破壓力大，R:R 嚴重不對稱（漲 2.5% vs 潛在跌 20%+）。
- **RSI14 = 68.6**：接近傳統超買門檻（70），短期動能耗盡訊號明確。
- **BB %B = 0.84**：價格偏向布林上軌，歷史上 %B > 0.8 後多數出現均值回歸。
- **ATR14 = NT$9.19**：波動率 39%，跌破 MA20 NT$248.30 的距離僅 1.5 個 ATR，一旦外資籌碼翻轉，跌至 MA20 的速度可能在 2–3 個交易日完成。
- **關鍵破位點**：NT$248.30（MA20）失守將引發技術性賣壓；NT$222.90（MA50）為真正支撐，跌至此處意味 -15%。
- 情緒面顯示外資「回補」可能為短線錯殺修正而非中期加碼，後繼買力存疑。
