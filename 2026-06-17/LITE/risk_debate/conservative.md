# Conservative risk view — LITE

## Where trader is too aggressive

- **倉位定性勉強合理，但波動乘數效應被低估。** 交易提案雖已自行壓至 0.5% NAV，但 ATR $80.39 佔股價 9.5%、20 日年化波動率 100.4%，意味「小倉」在高波動環境下仍可在單日造成相當於一般股 5 倍的組合衝擊。若組合規模以 $500K 計算，0.5% = $2,500 本金，但每日名義波動幅度 ($80 × 約 3 股) 仍會在盤中製造心理干擾，導致紀律性提前平倉的行為風險。
- **停損距離 -4.9%（$815 → $775）對 ATR $80.39 而言過窄，僅 0.5 ATR。** 一個正常的日內波動即可輕易洗掉停損而不構成真正趨勢反轉。偽性觸損後反彈會誘使二次進場，反而增加總損耗。
- **進場設計未要求量能或動能確認。** 僅以「MACD 直方圖收窄」作觸發，門檻過低——MACD 從 -6.08 收窄至 -4 仍屬深度負值，並不意味賣壓結束。
- **NVIDIA $20 億承諾被視為「需求底倉」，但承諾性質未驗證。** 若屬採購意向而非具法律約束力合約，客戶集中度暴露反而成為最大黑天鵝，而非護城河。

## Tail scenarios

- **Scenario A（發生機率 20%）：2026-08-12 財報 EPS ≤ $2.70，毛利率停滯 ≤ 27%**
  → 市場重新定價，$780 支撐週線跌穿，次位支撐 $548
  → 自進場 $815 計算，下跌 $267，損失約 -32.8%
  → 若持有 0.5% NAV（$2,500）約 3 股，帳面損失 ≈ **$801**（= NAV 0.16%）

- **Scenario B（發生機率 15%）：NVIDIA 宣佈 2026 下半年 AI 基礎建設支出削減或推遲**
  → LITE 客戶集中度立即暴露，EPS 預期下調 20–30%，Forward P/E 壓縮疊加 EPS 下修
  → 股價可能急跌至 $600–650 以下；若停損未能確實執行（跳空），實際損失擴大至 $165–215/股
  → 3 股損失 ≈ $495–645，接近 0.5% NAV 全數蒸發

- **Scenario C（發生機率 10%）：Fed 超預期升息或信用市場收緊**
  → Net Debt $1,730.9M、Net Debt/EBITDA 19.21× 在利率衝擊下再融資成本飆升
  → 高槓桿企業估值倍數壓縮最劇烈，EV/EBITDA 123.6× 根本無緩衝
  → 股價可能回測 $400–450 區間（基本面應值，Forward P/E 35–40×）

## Recommended adjustments

- **Size：維持 Small（0.5% NAV），但首批僅建 25%，財報後再評。**
  理由：100.4% 年化波動率下，0.5% 已非傳統「小倉」；分批可降低單一財報事件風險。
- **Stop：$775 → $765**（週線收盤為準，較原設多一層緩衝，跌穿 $780.48 後給一個確認空間，但不超過第二個收盤日）
  ——但同時接受若連兩週收盤均低於 $780，立即全部清倉，不等待。
- **Entry：等待量能縮量穩定 + MACD 直方圖轉正後才建倉。**
  具體條件：MACD 直方圖從 -6.08 回升並穿越 0 軸，成交量同時低於 10 日均量 30%+ 顯示整理，再進場。這將使進場時點推遲至財報前或財報後。
- **Consider：以 LITE 期權買入 Put（$800 strike，2026-09 到期）作下行保護，對沖 Scenario A/B 的財報跳空風險。** Put 成本為明確的風險上限。

## Position-level $ risk

以提案數字計算（假設組合 NAV = $500K）：

| 項目 | 數值 |
|---|---|
| 倉位 | 0.5% NAV = $2,500 |
| 進場中點 | $815 |
| 估計股數 | 約 3 股 |
| 停損 | $775（原案）|
| 停損距離 | $40/股 |
| **最大損失（正常觸損）** | **$40 × 3 = $120 = 0.024% NAV** |
| 若跳空至 $548（Scenario A 極端）| $267 × 3 = **$801 = 0.16% NAV** |

正常觸損 $120 絕對值極低，可接受。但 Scenario A 跳空情境下損失擴大 6.7 倍，且 Net Debt/EBITDA 19.21× 的財務脆弱性意味跳空風險不可視為低機率事件——**可接受，但前提是嚴格執行停損且不加碼攤平。**

## What I'd push for

現行提案的倉位規模（0.5% NAV）和停損邏輯（$780 支撐週線）方向正確，但執行條件過於寬鬆。我會要求：首批只建目標倉位的 25%（而非 50%），且進場觸發必須等到 MACD 直方圖轉正並伴隨縮量整理，而非僅「收窄」即可；同時以 2026-09 到期的 $800 Put 作財報保護，將已知的最大損失封頂。若 2026-08-12 財報確認 EPS ≥ $3.20 且毛利率突破 32%，再將剩餘 75% 倉位加入，否則視財報結果決定是否完全放棄此交易。內部人 $70M+ 高位拋售加上 FCF 仍負的現實，使我認為等待一個多的確認事件比搶先一步更符合風險報酬。
