1. 報告結構

整份 HTML 從上往下:

  1. Header — 標題 + as-of 日期 + 產生時間
  2. Nav bar (黏在頂部) — 直接點 ticker 跳到對應區塊, 顏色=該股最終判決
  3. Sector overview — 跨股 ranking table、top pick、contrarian、pairs trade、relevant catalysts、correlation cluster、action sequencing、risk budget
  4. 每股 ticker card (8 個, 大色塊):
    • 左半: Plotly K 線圖 (Close + MA20/50/200, 2 年)
    • 右半: Final decision 卡 (Opus 4.7 拍板)
    • 下方摺疊區:
      • Investment plan (research manager)
      • Trade proposal (trader)
      • Phase 1 — 四 analyst 並列 (fundamentals / market / news / sentiment)
      • Phase 2 — Bull vs Bear 辯論並列
      • Phase 4 — 三 risk debator 並列
點任何 ▶ 摺疊符號展開細節。已展開時點再收合。

2. 判決顏色 (Verdict color)

標籤意義實務
BUY看多, 建議建倉做多有明確 entry/stop/target 三點數字
HOLD觀望, 不在此價建倉通常附 conditional triggers (e.g. 跌破 X 翻空, 突破 Y 翻多)
SELL看空, 建議做空 (或減持)有 short entry 與 stop, 對沖部位常見

附加狀態詞 (Portfolio manager 對 trader 提案的處理):

  • APPROVE — 完全採納 trader 提案
  • MODIFY — 結構保留但動 size/stop/tranches (本次 power 8 支大多落這)
  • REJECT — 駁回, 不建倉

範例: VST: HOLD 意思是 $141.90 不建倉, 但短下 $138 翻空、長過 $155.71 (MA20) 翻多, 各 0.75% NAV。

5. K 線圖怎麼看

每股右上 Plotly 互動圖 (2 年):

線顏色意義
Close黑當日收盤價
MA20藍點20 日均線 — 短線趨勢
MA50橘點50 日均線 — 中線趨勢
MA200紅虛200 日均線 — 長線趨勢, 牛熊分界

判讀重點:

  • 多頭排列 (bullish stack): MA20 > MA50 > MA200, 趨勢向上
  • 空頭排列: 反之, 趨勢向下
  • 黃金交叉 (Golden cross): MA50 上穿 MA200
  • 死亡交叉 (Death cross): MA50 下穿 MA200
  • 滑鼠 hover 看具體日期/數值, 雙擊 reset zoom, 框選縮放

6. 基本面術語

縮寫全名意義 / 解讀
P/EPrice / Earnings (本益比)股價 / 每股盈餘。越高 = 越貴或成長預期高。一般 utility 16-20x, growth 30x+。
Trailing P/E過去 12 個月 P/E已實現的 earning
Forward P/E (fwd P/E)未來 12 個月 P/E用 analyst EPS 估值的 P/E, 比 trailing 更前瞻
PEGP/E to GrowthP/E / 預期成長率。<1 偏便宜, >2 偏貴
EV/EBITDAEnterprise Value / EBITDA含負債的全企業估值倍數, 跨資本結構比較
P/BPrice / Book市淨率
P/SPrice / Sales市銷率
FCFFree Cash Flow自由現金流 = 營運現金 - 資本支出。正數健康, 越大越好
OCFOperating Cash Flow營運現金流
FCF/NIFCF / Net Income盈餘現金品質, >0.9 健康, 太低代表 earning 是「帳上」
NINet Income淨利 (扣稅後)
EPSEarnings Per Share每股盈餘
ROEReturn on Equity股東權益報酬率, >15% 算優
ROICReturn on Invested Capital投入資本報酬率, 比 ROE 更純
ND/EBITDANet Debt / EBITDA淨負債倍數, <2x 健康, >4x 高槓桿。TLN 10x 是極端, CEG 0.9x 是模範生
D/EDebt / Equity負債權益比
Net debt淨負債= Total debt - Cash. 規模絕對值
Op marginOperating Margin營業利益率
Gross margin毛利率
CapexCapital expenditure資本支出
Insider內部人公司高管 / 董事 / 10%+ 持股人
10b5-1SEC 規則預先排程的內部人賣股計劃, 法律允許, 訊號偏弱
Insider txn內部人交易Form 4 通報的買賣。買 = 強訊號, 賣 = 弱訊號 (但常因稅、生活、分散而賣)
Backlog訂單積壓已簽未交付營收。GEV $163B, PWR $48.5B 為例
Book-to-bill訂單/出貨比>1 訂單成長, <1 訂單減少

52w high / low52 週高/低過去一年最高/低價

Higher highs連續更高高點, 上行趨勢徵兆

8. 交易語法 (trade proposal)

詞意義
Entry zone進場區間, e.g. $348-355
Stop / Stop-loss停損, 跌到此價無條件出場
Hard stop硬停損, 不可動
Daily-close stop以「收盤價」判, 盤中觸碰不算 (避免 whipsaw)
Two-tier stop兩層停損, e.g. $945 trim / $807 hard exit
T1 / T2Target 1 / Target 2, 第一/第二止盈目標
R:R / RRRisk-Reward ratio = (target - entry) / (entry - stop). >2 才考慮做
NAVNet Asset Value, 你的投組總值。1.5% NAV = 投組 1.5%
Tranche分批, e.g. 50/35/15 = 立即 50% + 觸發 1 加 35% + 觸發 2 加 15%
Scale-in / Ladder分批進場 (沿價位下單)
Stagger分散進場時機
GTCGood-Till-Cancelled (掛單到取消為止)
Horizon持有期間, e.g. 1-3m 表示 1-3 個月
Catalyst催化事件 (財報、PPA 簽約、FERC ruling 等)
Invalidation論述破功的條件 = 出場訊號
Trigger觸發 (進場 / 出場)
Conditional條件式 (e.g. conditional SHORT: 等跌破才空)
Trim減倉
Reclaim(價格) 收復某位
Confirmation確認訊號 (e.g. 2 closes >X 才算)

10. 避險 / Option 工具

工具意義
Call option看多買權, 賺漲
Put option看空賣權, 賺跌 (避險用)
Call spread買低履約價 call + 賣高履約價 call, 上限獲利但降成本。e.g. $160/$185 call spread
Put spread買高履約價 put + 賣低履約價 put, 下行避險
Pairs trade同領域 long X / short Y, 沖掉 sector beta, 玩相對價值。e.g. Long TLN / Short PWR
Sector hedge用 sector ETF 反向部位避險, e.g. XLU (Utility ETF), XLI (Industrial ETF)
Rate hedge利率對沖, 用 TLT (長債 ETF) 或其衍生品
VIX hedge波動率對沖, 用 VXX/UVXY
Anti-beta反市場 beta, BTAL ETF 為例
Beta-neutral淨 beta = 0, 對市場無方向暴露
Cohort hedge同類股對沖
Net exposure淨曝險 = long - short
Gross exposure毛曝險 = long + short
Convexity凸性, 非線性收益 (option 典型特徵, 一面下檔有限上檔開放)
Tail risk尾端風險, 機率小但衝擊大
De-risk降低風險, 通常砍 size 或加避險
Crowding擁擠交易, 太多人同向, 解倉風險高

11. 重要警示

  • 本報告純研究用, 不構成投資建議。任何 BUY/HOLD/SELL 都不是「應該買進」的指令。
  • LLM 推理有不確定性。同 prompt 跑兩遍 verdict 可能不同, 看高一致性的才信。
  • Data 來源 yfinance + 公開 web, 可能有延遲、缺漏、錯位。不要直接拿來下單。
  • Subagent 引用的「analyst target」「PT」是新聞抓的, 跟 Bloomberg/IBES 官方數字可能有差。
  • Insider trade、Reddit 情緒等都是 lagging 訊號, 別過度反應。
  • 避險工具 (option/inverse ETF) 有時間衰減、追蹤誤差, 長期持有不一定划算。
  • Position sizing 是 LLM 建議, 沒考慮你的實際資金、稅務、風險承受能力。
  • Macro/regulatory binary (FERC ruling, IRA cliff, Fed rate) 在事件前後波動極大, 慎入。
  • 結果跟原 TradingAgents 論文聲明一致: "It is not intended as financial, investment, or trading advice."
